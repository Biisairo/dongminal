# 6.1.2 수명주기-서비스-진단

## 목표

start·stop·health·service·uninstall·migrate·doctor 를 옮긴다. 도움말·오류 문구·종료 코드는 바이트 단위로 같아야 한다(rust/parity/SURFACE.md 1절, CLI 차분 시나리오). 특권 헬퍼·launchd 를 건드리는 경로는 시험에서 가짜로 바꾸고, 바이너리 실행은 격리 실행(hermetic.sh)에서만 한다.

## 대상 Go 파일 (internal/ctl/cli, 약 2144줄)

start.go, stop.go, health.go, health_wait.go, staleness.go, session_keep.go, service.go, uninstall.go, migrate.go, doctor.go, doctor_probe.go

## 완료 조건

- 대상 파일의 관측 동작을 dm-ctl-cli 가 동등하게 제공한다 (FR-RSP-1·3)
- 관측 동작을 검증하는 Go 테스트를 옮겨 통과한다 (V-RSP-1)
- fmt·clippy -D warnings·격리 cargo test 통과, OS 의존 코드는 windows·linux 교차 검사
- 작업 전후 prod-pids.sh 출력이 같다

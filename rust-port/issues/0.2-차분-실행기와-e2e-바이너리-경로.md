# 0.2 차분 실행기와 e2e 바이너리 경로

## 목표

V-RSP-2 의 차분 실행기를 `rust/parity/` 에 만든다. 시나리오(YAML 또는 Rust 코드)를 Go 바이너리와 Rust 바이너리에 각각 격리 실행으로 돌리고 CLI 출력·종료 코드·HTTP 응답·홈 파일을 비교한다. 정규화 규칙(시각·PID·임시 경로·무작위 ID)을 시나리오마다 선언할 수 있어야 한다. Go 참조 바이너리는 내 worktree 에서 `go build -o rust/target/go-ref/dongminal ./cmd/dongminal` 로 만든다(저장소 루트에 만들지 않는다). 함께 FR-RSP-31(`DM_E2E_PREBUILT_BIN`)을 `e2e/global-setup.ts` 에 구현한다. 아직 Rust 쪽은 빈 껍데기이므로 `version`·`--help` 같은 최소 시나리오로 실행기 자체를 검증하고, 시나리오 작성 가이드를 `rust/parity/README.md` 에 둔다.

## 완료 조건

- 대상 Go 패키지의 관측 동작을 Rust crate 가 동등하게 제공한다 (FR-RSP-1·3)
- 관측 동작을 검증하는 Go 테스트가 Rust 테스트로 옮겨져 통과한다 (V-RSP-1)
- `cargo fmt --check`, `cargo clippy -D warnings`, 격리 실행 `cargo test` 통과 (NFR-RSP-4)
- OS 의존 코드가 있으면 windows·linux 대상 `cargo check` 통과 (NFR-RSP-5)
- 작업 전후 `rust/scripts/prod-pids.sh` 출력이 같다 (V-RSP-5)
- 진행 기록에 공개 API 요약과 Go 와 다르게 한 내부 결정이 있다

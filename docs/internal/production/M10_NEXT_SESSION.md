### 착수의 첫 실측 (권장 순서)

1. **①을 재라** — 클릭으로 포커스를 가져올 때 실제로 무엇이 일어나는가.
   `resizeCheck` 가 소유를 가르는 자리다 (`term-pane.js:171·671·707·804`).
   포커스 전환이 `resizeCheck` 의 답을 바꾸는가? 바꾼다면 그 뒤에 `doFit()`·
   `Resize` 가 나가는가? **새로고침에서만 되는 이유**가 답의 절반이다
2. **②를 재라** — 스크롤백이 옛 폭으로 남는 것은 xterm 의 버퍼가 그 폭으로
   **이미 리플로우됐기** 때문인가, 아니면 서버의 스냅샷을 옛 폭으로 재생했기
   때문인가. 둘은 고치는 자리가 완전히 다르다
3. **`?diag=1` 을 쓰라** — M9-B2 를 닫은 것이 재현이 아니라 **사용자 로그의 산수**
   였다 (`M9_PROGRESS` §2-20). `diag.js` 에 계측 셋이 이미 심겨 있다
4. 두 클라이언트 실측 방법은 `M9_PROGRESS` **§3-2** 에 있다

**결정이 필요할 수 있다.** D-M9-3 은 "비소유자는 소유자를 따라간다"(사용자 결정)를
정책으로 확정했으나, **돌아온 기기가 소유권을 되가져오는가**는 열려 있다. 그 답에
따라 ①의 고칠 자리가 갈린다 — 물어라.

## 6. 변하지 않는 규약

- **로컬 전량은 `make e2e`** (8샤드 병렬, ~5분). 판정 `unexpected 0`. 겹쳐 돌리지 마라
  — **`pgrep` 으로 폴링 루프를 만들지 마라.** 그 루프의 명령줄이 자기 패턴에 걸려
  다음 `make e2e` 가 `BUSY` 로 시작조차 못 한다 (`M9_PROGRESS` §2-35, P4 가 밟았다).
  `run_in_background` 로 띄우면 끝날 때 하네스가 알린다
- **전량이 도는 동안 제품 소스를 건드리지 마라 — Go 도 포함이다** (§2-9). 문서는 된다
- **`make e2e-rebalance` 는 전량 직후다** (§2-10)
- **flaky 를 판정할 때는 `report.json` 을 먼저 읽어라** (§2-14 ②). `make` 의 종료 코드
  2 는 병렬 하네스가 flaky 를 실패로 올린 것이며 **판정은 `unexpected 0`** (D-M9-11)
- **출력을 자르지 마라.** `LC_ALL=C grep -a` 로 읽어라
- 동작을 바꾸면 근거 문서를 같은 변경에서 고친다 (이전/새/이유)
- **RED 를 실제로 보아라** — `git stash push <바꾼 파일>` → 실행 → `stash pop`.
  **`pop` 을 잊지 마라** (§2-22 — 커밋에서 조용히 빠진다). 그리고 **분할·이동에서는
  원본과 새 파일이 한 쌍이다** — 한쪽만 되돌리면 중복 선언이 난다 (§2-33)
- **계약을 바꾸면 그 값을 `grep` 해라** — 파일이 아니라 **값**이다. 고칠 것은 검사만이
  아니라 그 검사가 딛는 **다른 SRS 의 조항**도 함께다. P10 이 이것을 빠뜨려 전량
  1회차가 `unexpected 1` 이었다
- **검사가 무엇을 *재는지*도 대상이다** (§2-12·§2-29). 증상을 재는 검사는 그 증상을
  없애는 아무 경로에나 초록을 준다. **문서를 재는 검사도 같다** — 명령이 적혀 있는지는
  세면서 그 명령이 말하는 주장이 참인지는 재지 않는다
- **면제는 자기 근거보다 넓어지기 쉽다** (§2-32). 조항에 근거를 적었으면 검사는 그
  **근거의 크기**를 재야 한다
- **새 기능을 얹기 전에 응답을 통째로 덤프하고 키를 세라** (§2-31·§3-7). "이것이
  오는가" 를 문서나 코드에서 추론하지 마라 — 5초면 답이 나온다
- **`goimports -w <디렉터리>` 를 쓰지 마라** — 무관한 파일의 import 를 재정렬한다.
  파일 단위로 걸어라 (§2-33)
- 새 문구는 `t('ns.key')` — ko·en 둘 다 (`check-i18n.mjs`)
- 설정 키는 `SETTINGS_SCHEMA`·`SETTINGS_ACCESS` + `helpers.js` + `index.html` + ko·en
- 오류 코드는 `apierr/codes_core.go`·`codes_doc.go` → `go run ./scripts/gen-errors`
- 스펙에 D-… 를 더하면 `go run ./scripts/gen-decisions` · dmctl 을 바꾸면 `commands.md`
- e2e 의 고정 대기에는 **`TEST-16` 표식과 사유**가 필요하다. "일어나지 않음" 을 재는
  관측 창만 예외다
- **e2e 는 `app.testing.<이름>` 만 쓴다** (`check-e2e-internals`). 주석도 걸린다
- SRS 머리의 문서 상태는 **enum 안**이어야 한다
- z-index 는 층 토큰에서 온다 — 숫자 리터럴 금지
- 커밋 메시지에 AI 서명 금지
- dmctl 주의: `new-tab`/`close-tab` 은 `--help` 를 받지 않는다. **`new-tab` 은 `--at`
  없이 포커스 칸에 연다** — 부르는 쪽의 칸이 아니다 (FR-M9-42)
- **운영 인스턴스는 사용자가 `start --foreground` 로 띄운다.** 재시작이 필요하면 직접
  죽이지 말고 사용자에게 요청하라

# 3.2 git 기록 화면 멈춤 재현과 측정

## 목표

- 3.1 측정에서 커밋 401개 저장소의 git 기록 뷰를 연 뒤 트레이스 종료가 4분 넘게 돌아오지 않았다(`perf/SPA_PROFILE_2026-11-24.md` §2). 메인 스레드가 멈추는지 재현한다.
- 멈추면 결함으로 고친다(원인에 맞게: 가상 목록·나눠 그리기·불필요한 반복 제거 등). 시험 먼저(RED).
- 3.1 에서 재지 못한 단계도 잰다: git diff(큰 파일), 문서 렌더(markdown-it·highlight). 16 ms 를 넘는 작업과 원인 함수를 프로파일 문서에 더한다. Run 그래프·채팅은 데이터 비용이 크면 건너뛰고 이유를 적는다.

## 완료 조건

- 재현 결과(멈춤 여부·원인), 고쳤다면 RED→GREEN 시험(단위 또는 e2e 한두 개), 측정표 갱신. 전체 시험 금지.

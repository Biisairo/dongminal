## 3. 이 세션이 값을 치르고 안 것

### 3-1. "손으로 센 수는 표본" 이 **여덟·아홉·열 번째**다 — 이번엔 세 번이었다

| 센 사람 | 무엇 | 적은 수 | 실측 |
|---|---|---:|---:|
| (앞의 일곱은 이전 인계서 §3-1) | | | |
| **B3 의 FR-CMP-63a** | textarea 복사의 사본 | **2** ("세 번째를 만들 수 없다") | **4** (+ 헬퍼 1) |
| 감사 `AUDIT-go-infra` 4 | `homeLayout()` 누락 | 7 | **11** |
| **이 문서의 초안 §2.5** | 같은 것 | **8** | **11** |
| 감사 `AUDIT-fe-core` M3 | 80줄 초과 함수 | 14 (`core/` 만) | **29** |

**가장 비싼 것은 두 번째 줄이 아니라 첫 줄이다.** B3 은 *"공용 클립보드 헬퍼가
없다"* 고 적고 넘겼는데, 헬퍼는 **엿새 전에 이미 서 있었다**
(`term-clipboard.js` 의 3단, FR-ETR-40). 그 파일의 `_execCopy` 주석은
*"Git 패널의 `_copyFallback` 과 같은 수법"* 이라고 **스스로 적고 있었다** —
알면서 다섯 번째를 만든 것이다.

**원인은 이름이다.** `TermClipboard` 가 "터미널 전용" 으로 읽혀서, 뒤따른 네
자리가 그것을 찾지 않았다. **이름이 범위를 좁게 말하면 그 범위 밖은 그것을 못
본다.** 그래서 B5 는 몸통을 `ui/clipboard.js` 의 `ClipboardWriter` 로 꺼냈다.

세 번째 줄이 규약의 값을 보여 준다. 나는 §2.5 를 손으로 훑어 여덟이라 적었고,
**게이트를 세워 파싱으로 파생하자 열하나**였다. 게이트를 먼저 세우지 않았으면
그 셋(`cache/`·`tool-home/`·`panes.json`)은 이번에도 빠졌다.

> **B6 에 그대로 적용된다.** 성능은 특히 이 함정이 크다 — *"이 자리가 느릴 것
> 같다"* 는 표본이고, `pprof`·카운터가 실측이다. 감사 §4.2 가 이미 그것을 한 번
> 보여 줬다: *"루프 안의 강제 리플로는 **실측에서 찾지 못했다**"*.

### 3-2. 소비자를 읽자 **내 결정이 뒤집혔다** (D-STR-4)

초안은 `git-worktrees/` 를 `Backup: false` 로 정했다. 근거는 *"worktree 의 `.git`
은 절대 경로라 다른 기계에서 풀면 깨진 것이 복원된다 — 담고 거짓말하는 것보다
낫다"* 였고 **그 사실 자체는 지금도 옳다.**

틀린 것은 **`Backup` 이 한 가지 뜻이라는 가정**이었다. 소비자를 읽으니
`uninstall.go` 의 `uninstallPlan` 이 `e.Backup && !purge` 로 거른다 — 그 쪽에서
이 필드는 **"보존하는가"** 다. `false` 로 두면 맨 `dongminal uninstall` 이
사용자가 Git 창에서 만든 worktree 를 **커밋하지 않은 작업과 함께** 지운다.

**뜻이 둘인 필드에서는 되돌릴 수 없는 쪽을 따른다.** 그리고 그 사실을 표의 주석과
결정에 적었다 — 다음 사람이 같은 자리에서 같은 추론을 하지 않도록.

**교훈: 플래그를 읽을 때는 그것을 읽는 쪽을 전부 찾아라.** 이름이 한 가지 뜻을
말해도 소비자가 둘이면 뜻이 둘이다. `find_referencing_symbols` 3분이면 된다.

### 3-3. 게이트의 **오탐을 좁히는 것이 게이트를 세우는 일의 절반**이었다

네 게이트 전부 첫 판이 오탐을 냈고, 좁히는 과정이 그 자체로 발견이었다.

| 게이트 | 첫 판의 오탐 | 좁힌 방법 |
|---|---|---|
| `check-server-target` | **11건** — 샌드박스 마운트(`m.Host+":"+m.Container`) · 도커 포트 매핑(`port+":"+port`) · git 의 `<oid>:<path>` 넷 · refspec · 에이전트 이름 | 접합의 **한쪽이 host 이고 다른 쪽이 port 인** 꼴로 좁혔다. **`:` 은 주소의 것이 아니다** |
| `check-home-layout` | `~/Library/LaunchAgents/` — 같은 디렉터리의 무관한 **대입문**을 상수 정의로 잘못 읽었다 | 값에 `/` 나 `~` 가 있으면 홈 항목의 이름이 아니다 → **해석 실패로 돌려 눈에 보이게** 뒀다 |
| `check-clipboard` | (없음) | 다만 **바닥을 자리 수로 두면 안 됐다** — 옮기고 나면 헬퍼 밖이 0이 되므로 수를 세면 공회전한다. 바닥을 *"헬퍼에 1단·2단이 둘 다 있는가"* 로 바꿨다 |
| `check-file-size` | (없음) | `i18n/*.js` 를 뺐다 — **데이터**라 키가 늘면 줄이 늘고 분할이 뜻을 갖지 않는다 |

**해석하지 못한 것을 버리지 않고 찍는 것**이 `check-home-layout` 의 요점이다.
표 자신을 도는 변수(`filepath.Join(home, e.Name)`)는 해석할 수 없고, 그 수를 매번
찍으면(실측 7자리) 거기 **진짜 상수가 섞였을 때 그 줄로 보인다.** 조용히 건너뛰면
범위가 조용히 좁아진다 (FR-KIT-20c 와 같은 규약).

### 3-4. 분할의 증명은 **"사라진 줄 0"** 이다

`_rLayout`(168줄 → 넷)과 `renderer.js`(1,586 → 다섯) 둘 다 같은 방법으로 증명했다:

```
diff <(grep -vE '^\s*$' <전> | sort) <(cat <후...> | grep -vE '^\s*$' | sed 's/^  },$/  }/' | sort)
```

`^<` 가 **하나도 없어야** 한다. 남는 차이는 **이름이 붙은 것만** 허용한다 —
① 파일 머리말 ② 클래스 본문이 객체 리터럴이 되며 멤버 끝의 `}` 가 `},` 가 되는 것.
`FE_MODULE_BOUNDARY_SRS` §7.2 묶음 D 가 같은 방법을 썼다(*"`static ` 제거 27,
`}` → `},` 45"*).

**함정 하나**: 한 줄짜리 멤버(`_rSidebar(){ this._rLists() }`)는 `  }` 로 끝나지
않아 쉼표가 붙지 않는다. 파싱이 그것을 놓쳐 첫 판이 `SyntaxError` 로 죽었다.
정규식을 하나 더 뒀다.

**함정 둘**: 정렬 후 `diff` 에서 `^<` 만 grep 하면 **짝이 있는 줄도 `<` 로 보인다**
(로케일 정렬이 인접 줄을 다르게 놓으면 변경 블록이 된다). 의심스러우면 그 줄의
**발생 횟수를 양쪽에서 세어라** — 그것이 다중집합 비교의 본뜻이다.

### 3-5. 조용한 실패는 **주석이 예고해도 일어난다**

`app-tool.js` 의 샌드박스 명령 복사 버튼이 그 자리였다:

```js
try{await navigator.clipboard.writeText(cmd); copy.textContent=SBX_RT_COPIED}
catch{}
```

바로 위 주석이 *"복사가 막힌 환경에서도 명령은 화면에 남아 있다 — **실패를 알릴
뿐** 흐름을 막지 않는다"* 라 적었는데 **알리지 않는다.** secure context 밖에서는
`navigator.clipboard` 가 **아예 없어서** 호출이 `TypeError` 로 던지고 빈 `catch`
가 그것을 삼킨다 — 사용자에게는 "버튼을 눌러도 아무 일이 안 일어나는 것" 이다.

같은 모양이 Go 쪽에도 있었다 — `health.go` 의 host 고정(FR-DRC-12)은 *"`localhost`
가 `::1` 로 먼저 풀려 실패한다"* 를 고친 **과교정**이었고, 그 결과
`DONGMINAL_HOST=192.168.1.5` 인스턴스에는 health 가 **언제나** 실패했다.

**요구가 해법을 적으면 그 해법의 사각지대가 요구가 된다.** FR-DRC-12 는
*"`dmenv.DefaultHost` 를 써야 한다"* 로 **수단**을 못박았고, 물음(*"어느 서버를
겨누는가"*)을 적었다면 `DialHost` 가 나왔을 것이다.

### 3-6. `net.JoinHostPort` 사용이 **저장소 전체에 0곳**이었다

`DONGMINAL_HOST=::1` 은 `getting-started.md` 가 **지원한다고 적은 값**인데 그 값으로
서버가 뜨지 않았다. `serverconf.Resolve` 를 통과하고(`checkPort` 는 포트만 본다),
자식이 `net.Listen("tcp","::1:9911")` 에서 *too many colons* 로 죽고, 부모는
`waitReady` 5초 폴링 뒤 **"기동 실패" 만** 낸다 — 어느 값이 문제인지가 없다.

원인은 한 함수가 두 일을 한 것이다. `dmenv.normalizeHost` 가 `[::1]` 의 대괄호를
**뗀다** — 판정(`IsExposedHost`·`DialHost`)에는 그것이 맞고 **조립에는 붙이는 것이
맞는데**, 둘이 같은 출력을 공유했다.

**검사는 값이 아니라 실제 API 로 한다.** `TestListenAddrIsDialable` 이
`net.Listen` 을 실제로 부른다 — 값만 비교하면 다음 사람이 형식을 바꿨을 때
검사가 함께 틀린다.

### 3-7. `make e2e` 의 종료 코드는 여전히 함정이다

이전 인계서 §3-8 그대로다. **샤드별 요약을 직접 세어라:**

```
for i in 1 2 3 4 5 6 7 8; do echo -n "샤드 $i: "; \
  LC_ALL=C grep -a "샤드 $i/8" <로그> | LC_ALL=C grep -aoE '[0-9]+ (passed|failed|flaky)' | tr '\n' ' '; echo; done
```

`✘` 로 grep 하면 **안 잡힌다** (색 코드가 섞인다). `N failed` 를 세라.

이번 회차는 **1회로 끝났다** (1,745 passed · failed 0 · flaky 0). 이전 세션이
겪은 flaky 둘(`git-menu` N3 포함)도 나오지 않았다 — 다만 **부분 실행에서는 한 번
보였다.** 부하 flake 는 사라진 것이 아니라 이번에 안 걸린 것이다.

## 4. 변하지 않는 규약

`CONTRIBUTING.md` 가 원본이다.

1. **SRS → 테스트 → 코드.** RED 를 **실제로** 보고 나서 구현한다. 이미 구현했다면
   `git stash push web/` 로 코드만 되돌려 확인한다
2. **게이트를 느슨하게 만들어 통과시키지 않는다.** 다만 **재는 대상이 달라진 것**은
   느슨하게 만드는 것이 아니다
3. **새 게이트를 세우면 탐침으로 검출을 확인하고 지운다.** 잡아야 하는 것과
   **잡으면 안 되는 것**을 둘 다
4. **동작을 바꾸면 근거 문서를 같은 변경에서 고친다.** 이전 / 새 / 이유 셋
5. **커밋 메시지에 FR 번호를 단다. AI 서명 금지**
6. **생성물을 직접 고치지 않는다** — `docs/external/errors.md` · `docs/internal/decisions.md`
7. **색은 팔레트를 바꾸지 않는다** (FR-TOK-16). 새 hex 를 넣지 마라
8. **낱말·값을 바꾸기 전에 그것을 못박은 요구를 grep 으로 찾는다**
9. **대상 목록을 손으로 적지 않는다** — 파싱으로 파생한다 (§3-1, 열 번 반복됐다)

# 3.5.3 생명주기 적용 — 편집기·문서 렌더

## 목표

- 찾기 나눠 계산(`TIMERS.after`·`defer`, 3.3)·LSP 진단 표시·미니맵 나눠 그리기(3.7)를 잠든 동안 멈추고 깰 때 이어 한다.

## 완료 조건

- RED 단위: 잠든 편집기의 찾기 계산 타이머 0, 깨면 남은 계산을 이어 끝낸다. e2e: 큰 파일 찾기 중 다른 탭으로 바꾸고 2초 뒤 그 편집기 주인의 타이머 0.
- 전체 시험 금지.
- 동작을 바꿨으면 이전 동작 / 새 동작 / 이유를 진행 기록과 커밋 메시지에 적는다.

# 4.5.4 Auto — 자동 전환·알림

## 목표

자동 전환 루프(Auto)와 알림을 옮긴다. 부모 이슈는 4.5 다. 자격증명 값을 로그·대화·문서에 남기지 않는다.

## 대상 Go 코드

- `internal/webserver/domain/claudeacct` 의 autoswitch·alerts (약 1083줄, 4.5.1·4.5.3 으로 옮긴 심볼 제외).

## 완료 조건

- 대상 Go 코드의 관측 동작을 Rust crate 가 동등하게 제공한다 (FR-RSP-1·3)
- 관측 동작을 검증하는 Go 테스트가 Rust 테스트로 옮겨져 통과한다 (V-RSP-1)
- `cargo fmt --check`, `cargo clippy -D warnings`, 격리 실행 `cargo test` 통과 (NFR-RSP-4)

- 작업 전후 `rust/scripts/prod-pids.sh` 출력이 같다 (V-RSP-5)
- 진행 기록에 공개 API 요약과 Go 와 다르게 한 내부 결정이 있다

  - **공개 API**
    - `Auto::new(eng: Arc<Engine>, now: Clock)` 와 pub 필드 `jitter`·`procs: Option<ProcsFn>`(`Fn() -> Result<Vec<String>, String>`)·`notify: Option<NotifyFn>`(`Fn(&Alert)`)·`on_change`.
    - `load()`, `view() -> AutoView`, `put(raw) -> AutoView`, async `tick(&CancellationToken) -> Duration`, async `run(stop)`, `wake()`, `models() -> Vec<String>`, `line_for(&Account) -> f64`.
    - `AutoSettings`(Default = Go DefaultAutoSettings)·`validate`, `AUTO_RANGES`, `AutoState`, `LastSwitch`, `AutoStateView`, `AutoView`, `AUTO_STRATEGY_*`, `AUTO_OFF/ON/UNMANAGED/EXHAUSTED`, `cswap_auto_running(&[String])`.
    - `Alert{kind, name, from, to, trigger, window, resets_at, expires_at, reset_available}::text()`, `ALERT_*`.
  - **5.5(httpapi) 가 알아야 할 것**: Go 는 `Engine.Models = auto.Models`, `Engine.LineFor = auto.LineFor` 로 잇는다. Rust 는 Engine 을 Arc 로 Auto 에 넘기므로 Engine 을 만들 때 `OnceLock<Weak<Auto>>` 를 잡는 클로저를 `models`·`line_for` 에 넣고, Auto 를 만든 뒤 채우면 된다(순환 참조 없음).
  - **Go 와 다르게 한 내부 결정**
    - Go 의 Put 은 map 순회(무작위 순서)로 키를 적용한다. 모르는 키가 여럿이면 어느 키가 문구에 실릴지 Go 는 정하지 않는다. Rust 는 키 이름 순(BTreeMap)이다.
    - `Quarantined`·`Notified` 는 BTreeMap 이다(JSON 출력은 Go map 처럼 키 정렬이라 같다).
    - `rank` 의 정렬은 `sort_by`(안정 정렬)로 Go `sort.SliceStable` 과 같다. 알림 날짜는 `chrono::Local` 로 만든다(Go `time.Local`).
    - Auto 의 `decide` 는 refresh_stale 에 끊는 토큰을 넘기지 않는다(4.5.3 과 같다). 회차 틈의 취소는 Engine tick 이 맡는다.
  - **남은 위험**: async 안의 블로킹(autoswitch.json 저장 때 store 파일 락, 디렉터리 락) — 4.5.3 과 같은 전제(MEDIUM). 알림 날짜 키는 실행 환경의 시간대에 따른다(Go 와 같다).

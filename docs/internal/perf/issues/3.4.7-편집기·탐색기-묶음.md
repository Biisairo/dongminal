# 3.4.7 편집기·탐색기 묶음

## 목표

- `file-editor*`·`cm-*`·`editor-*` 의 화면 부분·`file-tree-*`·LSP, `constants-editor`·`constants-explorer`, `style-editor*.css` 를 `editor` 묶음으로.
- `FileTree` 는 편집기 창이 만든다(`core/editor-open.js:347`). `edOpenFile` 은 이미 async — 첫 줄에서 기다린다.
- CodeMirror vendor 의 `import()` 는 바꾸지 않는다.

## 완료 조건

- RED e2e: 부팅 때 `b/editor.js` 요청이 없다 → 파일을 열면 실리고 편집기가 선다. 복원된 편집기 탭도 선다.
- 게이트 통과, 관련 편집기 e2e 한두 개. 전체 시험 금지.
- 동작을 바꿨으면 이전 동작 / 새 동작 / 이유를 진행 기록과 커밋 메시지에 적는다.

**동작 변경**

- 이전: 편집기·탐색기 스크립트를 부팅 때 모두 실었다.
- 새: 부팅은 싣지 않는다. 탐색기 사이드를 그릴 때, 파일을 열 때, 복원된 편집기 탭을 그릴 때 `b/editor.js` 를 한 번 싣는다. 그동안 그 자리에 "불러오는 중…" 자리표시가 선다. 싣기에 실패하면 `edOpenFile` 이 reject 한다.
- 이유: 부팅 JS 바이트·파싱을 줄인다(FR-SPA-1·2, D-30·D-31).

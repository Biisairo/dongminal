# 3.4.5 언어 파일 한 벌만 싣기 (D-34)

## 목표

- head 인라인이 `otter.locale` 을 읽어 활성 언어 파일 하나만 `document.write` 로 싣는다(`web/index.html` 의 `ko.js`·`en.js` 두 줄 자리). 순서(`i18n.js` 뒤, 상수 앞)를 지킨다.
- 언어 바꾸기는 지금처럼 새로고침이다(D-B-1).
- 동작 변경: 영어일 때 카탈로그에 없는 키는 한국어 폴백 대신 키가 보인다(`check-i18n` 이 키 집합 일치를 막으므로 실제로는 생기지 않는다). 이전/새/이유를 진행 기록에 적는다.

## 완료 조건

- RED e2e: `locale=en` 이면 `ko.js` 요청이 없고 화면이 영어다. `ko` 이면 `en.js` 요청이 없다. 설정에서 언어를 바꾸면 새로고침 뒤 바뀐 언어 파일 하나만 실린다.
- `check-i18n`·`check-i18n-html` 통과. 전체 시험 금지.
- 동작을 바꿨으면 이전 동작 / 새 동작 / 이유를 진행 기록과 커밋 메시지에 적는다.

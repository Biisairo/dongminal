# 2.2.1 와이어·순수 판정

## 목표

chatwire(채팅 와이어)와 toolipc(데몬 IPC 메시지·오류 코드·파일 이름)를 옮긴다. toolipc 가 쓰는 toolhub 의 와이어 타입(ToolInfo, ToolSnapshot, TermModes, BackgroundEntry, AgentState, ShellState, ActivitySnap, ExitInfo)과 PTY 없이 판정되는 순수 함수(터미널 모드 스캔, 주의 신호·cwd 보고 탐지, AgentTurn, 셸 판정, 히스토리 경로·환경, WebSocket op 코드·SizePayload·ParseSize)를 함께 옮긴다. JSON 바이트는 Go 와 같아야 한다 (FR-RSP-3 ④).

## 대상 Go 코드

- `internal/shared/chatwire` (218줄)
- `internal/shared/toolipc` (약 530줄)
- `internal/shared/toolhub` 의 hub.go 타입, termmodes.go 순수 부분, attention.go, agentturn.go, shellprobe.go 판정, history.go, tool_env.go, tool_exitinfo.go, tool_records.go 타입, conn.go 상수 (약 900줄)

## 완료 조건

- 대상 Go 코드의 관측 동작을 Rust 가 동등하게 제공한다 (FR-RSP-1·3)
- 관측 동작을 검증하는 Go 테스트가 Rust 테스트로 옮겨져 통과한다 (V-RSP-1)
- `cargo fmt --check`, `cargo clippy -D warnings`, 격리 실행 `cargo test` 통과 (NFR-RSP-4)
- OS 의존 코드가 있으면 windows·linux 대상 `cargo check` 통과 (NFR-RSP-5)
- 작업 전후 `rust/scripts/prod-pids.sh` 출력이 같다 (V-RSP-5)
- 진행 기록에 공개 API 요약과 Go 와 다르게 한 내부 결정이 있다

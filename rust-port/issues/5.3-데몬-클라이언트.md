Go 시험 중 가짜 데몬으로 관측 동작을 재는 것은 모두 옮겼다(요청 바이트 골든, hello 협상·판 불일치, 알림·강등, busymany·shellprobe, 목록 캐시·세대, push 배선 경합·exit 재생, 재동기 3종, 생존 확인 3종, 시한, create 동시성). 실제 데몬(`ipc.PanedServer`·`ToolManager`, 3.x)이 필요한 시험(TestToolClientReconnect·AutoReconnect·Connected·ForegroundNameOverIPC·UnknownToolErrors, attention·chat·records·report 시험)은 같은 관측 동작을 가짜 데몬으로 잰 시험으로 대신했다. 더한 것: 백오프 수열 1·2·4·8·16·30, 재기동 3·6번째 실패, 기능별 RPC 요청 바이트, 연결 끊김·닫힘 때 대기 호출의 오류 문구. 값 오류 응답 문구(`json: cannot unmarshal string into Go struct field wireMsg.error.code of type int`)와 `tools:null` 의 RawMessage 가 `null` 4바이트임은 go1.27.2 로 실측해 대조했다.

  **Go 와 다르게 한 내부 결정**
  - 동시성: goroutine 대신 전용 스레드(연결마다 읽기 스레드, 감독 스레드 하나). select 대신 호출마다 `sync_channel(1)` + `recv_timeout`, 감독은 Condvar. 연결은 세대 번호로 가른다(Go connDone).
  - 읽기: Go `json.Decoder` 스트림 대신 줄 단위(`read_until('\n')`) + gocompat `Decoder`. 값 오류(`ErrorKind::Type`, base64 포함)면 그 줄에서 id·event 만 다시 건져 Go 의 부분 채움을 대신한다(D-4).
  - `ToolHub` trait·`Placement`·`Tool`·`ErrToolCap`·`ErrToolNotFound` 가 toolhub(2.2.3, todo)에 아직 없어, trait 없이 고유 메서드로 두고 `Placement`·`ToolIdentity`·오류 문구 상수(`ERR_TOOL_CAP`·`ERR_TOOL_NOT_FOUND`)를 이 crate 에 임시로 둔다. 2.2.3 이 이것들을 만들면 그쪽으로 옮기고 trait 을 구현해야 한다. `SaveAll`·`LoadAll`(무동작)은 trait 이 없어 옮기지 않았다.
  - `list_ok` 는 결과를 `BTreeMap<String, RawMessage>` 로 풀어 `tools` 키를 꺼낸다. gocompat 이 구조체 필드의 `null` 을 없는 필드로 다뤄(1.1, `8b2feb7b`) `RawMessage` 필드로는 Go 의 `"null"` 과 "키 없음" 을 가를 수 없기 때문이다.
  - 닫은 뒤의 호출은 곧바로 `toolclient closed` 다(Go 는 닫힌 소켓 쓰기 오류 문구가 먼저 나올 수 있다). 서버 종료 경로라 관측 영향은 없다.
  - 이쪽이 끊은 연결(시한 초과·hello 실패)의 읽기 로그는 Go 문구 `read unix ->{sock}: use of closed network connection` 으로 맞춘다(shutdown 뒤 EOF 를 그대로 적지 않는다).

  **남은 위험**
  - (MEDIUM) gocompat 1.1: 구조체 필드 `RawMessage` 의 `null` 이 빈 값이 된다. Go 는 `null` 4바이트를 담는다. 이 crate 는 우회했지만, `null` 과 "없음" 을 가르는 다른 소비자가 있으면 같은 문제가 난다. 조정자에게 알린다.
  - (LOW) 한 줄에 값 둘 이상이나 값 뒤 쓰레기가 오면 Go(스트림 오류로 끊음)와 다르게 앞 값만 읽고 잇는다. 데몬은 언제나 `json.Encoder` 한 줄 한 값이라 실사용에서는 생기지 않는다.
  - (LOW) 구독 채널이 닫힌 순간 종료 토큰도 같이 바뀔 수 있으므로, 소비자는 채널 `None` 을 받으면 토큰을 확인해야 한다(위 공개 API 참고). 5.5(WS 중계)가 지켜야 한다.

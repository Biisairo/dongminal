# Git 창 수동 검증 체크리스트 (GIT_SRS V14 · V60)

자동 테스트가 잡지 못하는 것만 남긴다 — 눈으로 봐야 아는 것(배치·색·읽힘),
실기기(모바일 터치), 실제 저장소에서만 드러나는 것.

**준비**

```bash
e2e/git_fixture.sh /tmp/dm-git-fixtures   # 저장소 10종
./scripts/build.sh && ./dongminal start   # dongminal
```

각 항목은 `☐` → `☑`(정상) / `✗`(결함, 사유 기록) / `–`(미실시) / `※`(개정으로 문면이
바뀐 항목). 대상 저장소는 두 종류다: **dongminal 자기 저장소**(실사용)와
**픽스처**(엣지 케이스).

**1회차에서 나온 것**

- **결함 2건**: G5.9(LFS 메타 미표시) · G5.11(diff 색이 테마를 따르지 않음).
  **2회차에 둘 다 고쳤다** — 아래 표의 결과 칸에 적었고, 회귀는 e2e D11~D13 이 막는다.
- **로그 위생 1건**: 새로고침 때 브라우저가 취소한 요청을 서버가 `/api/git/*`
  **500** 으로 마감해 로그에 남긴다. 같은 순간 셸에서 60회 폴링은 전부 200 이라
  화면에는 영향이 없지만, 진짜 장애와 구분되지 않는다. **고쳤다** — 취소는
  `ErrCanceled` 로 갈라 **499** 로 마감한다 (FR-GIT-217).
- **문면이 낡은 항목 7건**: `GIT_UI_REVISION_SRS.md` 로 Git 창이 **닫힌 창**이
  되면서, 또 M1 시점 문면이 그대로 남아 있어서 —
  G1.1·G2.4·G2.5·G2.7·G2.8·G3.12·G3.14. 아래 표에 `※` 로 적었다.

> **자동으로 덮인 것은 여기 없다.** V1~V59·V62~V90 은 Go 단위/통합 테스트와
> Playwright **374개**가 덮는다 (`go test ./... -race`, `npm run e2e`).
> **수동만 남은 것은 V14·V60·V61 이다** — 화면 배치·색·읽힘, 모바일 실기기,
> 성능·보안 기준의 실사.

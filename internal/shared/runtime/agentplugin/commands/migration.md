# migration

이 세션이 하던 일을 **다음 세션이 그대로 잇게** 한다.

**인자**: `$ARGUMENTS` — 비어 있으면 기본값이다. 되묻지 마라.

여러 에이전트를 동시에 돌리는 일은 `/dongminal:team`, 저장된 팀 구성의 반복 실행은
`/dongminal:workflow` 다. 이 명령은 **한 세션을 다음 한 세션으로** 넘기는 일만 한다.

---

## 절대 원칙 (다섯)

1. **인계는 두 벌이다.** 긴 맥락은 **문서**가, "그 문서를 읽어라" 는 짧은 지시는 **엔벨로프**가 나른다. 엔벨로프 하나에 다 담으면 메시지 길이에 매이고 인계 기록이 남지 않는다.
2. **문서의 경로는 이 명령이 정하지 않는다.** 진행 중인 작업에 규약이 있으면 **그것**을 쓴다. 없을 때만 이 명령이 한 장을 만든다.
3. **새 탭은 `--at <자기 탭 uuid>` 로 연다.** `--at` 을 빼면 **포커스 칸**에 선다 — 부르는 쪽의 칸이 아니다. 넘기는 세션의 탭이 포커스가 아니면 엉뚱한 자리에 탭이 생긴다.
4. **각 걸음은 스스로를 증명한다.** 명령을 보냈다는 것과 그것이 먹혔다는 것은 다르다. 단계마다 **기대 출력**을 눈으로 확인하고, 확인되기 전에는 다음으로 가지 않는다.
5. **닫기에는 전제가 있다.** 새 세션이 **일하고 있음을 확인한 뒤에만** 자기 탭을 닫는다. 확인하지 못하면 **닫지 말고 사용자에게 말한다** — 인계는 되돌릴 수 없다. 닫힌 뒤에는 고칠 사람이 없다.

---

## 옵션 (사용자가 말하지 않으면 기본값)

| 옵션 | 기본값 | 뜻 |
|---|---|---|
| 에이전트 | **`claude`** | 새 탭에 띄울 에이전트. 사용자가 다른 이름을 말하면 그것 (`codex` · `omp` …) |
| 표면 | **`cli`** | `cli`(=tui): 터미널 탭에 기동줄을 친다 · `gui`: 에이전트 도구 탭을 연다 |

인자는 `$ARGUMENTS` 로 온다 — `codex`, `gui`, `codex gui` 처럼 순서와 무관하게 읽는다.
`cli`·`gui` 가 표면이고 나머지 낱말이 에이전트 이름이다. **인자가 없으면 묻지 말고
`claude` · `cli` 다.** 사용자가 본문에서 *"gui 로 열어줘"* 처럼 말했으면 그것도 따른다.

## 식별자 — 어느 자리에 무엇을 넣는가

**이것을 틀리면 엉뚱한 탭이 닫힌다.** `dmctl who-am-i` 는 값을 **셋** 낸다.

| 값 | 어디서 | 어디에 쓰나 |
|---|---|---|
| `uuid` | `who-am-i` 의 `uuid=` · `new-tab` 응답의 `newTabs[0].uuid` | **탭 uuid.** `--at` 이 받는 값이다 — `new-tab` · `rename-tab` · `send-input` · `wait` · `status` · `close-tab` |
| `toolId` | `who-am-i` 의 `toolId=` · `newTabs[0].toolId` | **도구 id.** `dmctl msg --to` 가 받는 값이고, 엔벨로프 헤더의 `from=`·`to=` 에 실리는 값이다 |
| `paneUuid` | `who-am-i --json` 의 `paneUuid` | **쓰지 않는다.** `--at` 은 칸 uuid 를 받지 않는다 — 넣으면 "대상 없음" 이다 |

`--to` 는 탭 uuid 도 받아 준다(서버가 둘 다 해석한다). 그래도 **`toolId` 를 쓴다** — 답장할 때 상대가 헤더에서 읽을 값과 같아야 한다.

## 절차

### 0. 넘길 것을 정한다

넘기는 것은 **지금까지의 서술**이 아니라 **다음 세션이 할 일**이다. 최소한 이 여섯이 문서에 있어야 한다.

- 어디까지 왔나 (끝난 것 · 그 근거가 되는 커밋 해시)
- 남은 일과 **순서**
- 먼저 읽을 것 (경로와 절 번호까지)
- 이 세션이 값을 치르고 배운 것 — 다음 세션이 같은 값을 다시 치르지 않게
- 변하지 않는 규약 (전량 검사·게이트·금지 사항)
- 사용자 결정 중 아직 유효한 것

### 1. 자기 좌표를 먼저 적는다

```
dmctl who-am-i
```

기대 출력 — `uuid=` 와 `toolId=` 가 있다.

```
  label=W1.P1.T1  uuid=d34957de-…  short=d34957de  toolId=01a09fcc-…  …
```

**이 두 값을 지금 적어 둔다.** `uuid` 는 마지막에 **자기 탭을 닫을 때** 쓰고, 새 탭을 여는 `--at` 에도 쓴다. 뒤에서 다시 조회하면 그 사이 화면이 바뀌어 다른 것을 가리킬 수 있다.

### 2. 문서 한 장

진행 중인 작업의 규약을 먼저 본다.

- 규약이 있으면 그 파일을 **다음 세션의 착수 문서로 다시 쓴다** (예: 단계별 진행 문서를 다음 단계의 착수 프롬프트로)
- 없으면 한 장을 만든다. 자리는 저장소 안이고, 이름은 이어갈 일을 말한다

작업 트리가 더러우면 **여기서 커밋한다.** 넘긴 뒤에 커밋할 사람이 없다.

### 3. 새 탭 — 자기 칸에

**cli (기본)**

```
dmctl new-tab -n --at <자기 탭 uuid>
```

**gui**

```
dmctl new-tab -n --at <자기 탭 uuid> --agent <에이전트 id>
```

`-n` 은 포커스를 그대로 둔다 — 사용자가 보고 있는 자리를 빼앗지 않는다.

기대 출력 — `ok:true` · `timedOut:false` · `newTabs` 가 하나.

```
{"action":"newTab","delivered":3,…,"newTabs":[{"uuid":"…","toolId":"…"}],"ok":true,"timedOut":false}
```

**`newTabs[0].uuid` 와 `newTabs[0].toolId` 를 적는다.** `list-workspace` 로 다시 찾지 않는다 — 새 탭이 여럿이면 어느 것이 방금 만든 것인지 알 수 없다.

실패 갈래:

- `delivered:0` → 구독 중인 브라우저가 없다. 사용자에게 페이지를 새로고침해 달라고 말하고 **멈춘다**
- `timedOut:true` → 만들어지지 않았을 수 있다. `dmctl list-workspace` 로 확인하고, 없으면 다시 한 번
- `대상 없음` → `--at` 에 칸 uuid 를 넣었다. **탭 uuid** 여야 한다

### 4. 탭 이름

```
dmctl rename-tab --at <새 탭 uuid> "<이어갈 일의 이름>"
```

이름은 **이어갈 일**을 말한다 (`M9-P4`, `리팩터-2단계`). 사용자가 화면에서 어느 탭이 무엇인지 알아야 한다.

### 5. 에이전트를 띄운다

**gui 로 열었으면 이 단계는 없다** — 탭 자체가 이미 그 에이전트다. 6으로 간다.

**cli:**

```
dmctl send-input --at <새 탭 uuid> --execute "cd '<작업 디렉터리>' && <에이전트 명령>"
```

- `<에이전트 명령>` 은 기본이 `claude` 다. dongminal 셸이 훅·플러그인을 얹어 래핑하므로 **인자를 직접 붙이지 않는다**
- 다른 에이전트면 그 이름이다 (`codex` · `omp`)
- `<작업 디렉터리>` 는 지금 세션의 작업 디렉터리다. 따옴표를 빼지 마라 — 공백이 든 경로가 끊긴다

기대 출력:

```
입력 주입 완료: target=<새 탭 uuid> textLen=… 모드=paste + 자동 엔터
```

### 6. 준비를 두 번 확인한다

**첫째 관문** — 서버가 아는 상태:

```
dmctl wait --at <새 탭 uuid> --for ready --timeout-ms 180000
```

기대 출력은 `status=ready` 다.

> **`ready` 는 "떴다" 이지 "입력을 받을 준비" 가 아니다.** claude 의 `SessionStart` 훅은 기동하자마자 `idle` 을 보고하므로 이 명령이 `waitedMs=0` 으로 즉시 돌아올 수 있다(실측). 그 시점의 TUI 는 아직 입력을 받지 못할 수 있고, 그때 보낸 엔벨로프는 **사라진다**.

**둘째 관문** — 화면이 실제로 무엇을 보이는가:

```
dmctl read-screen --at <새 탭 uuid>
```

에이전트의 **입력 프롬프트가 보여야** 한다. 아직이면 몇 초 두고 다시 읽는다. 셋째 읽기에도 프롬프트가 없으면 아래 갈래로 간다.

#### `wait` 가 `rc=5` 이거나 화면에 프롬프트가 없을 때

`read-screen` 이 **무엇을 묻는지** 보고 처리한다. 흔한 갈래 넷:

- 신뢰·권한 확인을 묻는다 → `dmctl send-input --at <새 탭 uuid> --execute "<답>"` 뒤 6을 다시
- 셸이 아직 프롬프트를 내지 않았다 → 몇 초 두고 다시 읽는다
- `command not found` → 에이전트 명령이 틀렸다. 사용자에게 확인한다
- 화면이 비어 있다 → 5의 `send-input` 이 닿지 않았다. 5를 다시 한다

**준비되지 않은 탭에 엔벨로프를 보내지 않는다.** 보낸 메시지는 셸의 입력줄에 문자열로 남고, 그 뒤 에이전트가 뜨면 그것을 보지 못한다.

### 7. 엔벨로프

```
dmctl msg --to <새 탭 toolId> -
```

본문은 짧다. 문서를 가리키고, 어디서부터인지 말하고, 근거 해시를 준다.

```
[HANDOFF <이 세션의 이름> → <다음 세션의 이름>]
<문서 경로> 를 읽고 진행하라. 그 안의 착수 블록이 이번 세션의 지시 전부다.
직전 커밋: <해시>. 작업 트리는 깨끗하다 — `git status` 로 확인하라.
먼저 <남은 일의 첫 항목> 부터 시작하라.
[/HANDOFF]
```

기대 출력:

```
에이전트 메시지 전송 완료: from=… → to=<새 탭 toolId>, 본문 N 자
```

### 8. 닿았는지 확인한다 — 안 닿았으면 다시 보낸다

```
dmctl status --at <새 탭 uuid>
```

기대 출력은 `state=working` 이다.

```
toolId=…  live=true  state=working  tool=Read  detail=…  quietMs=…
```

- `state=idle` 이 계속되면 → `dmctl read-screen --at <새 탭 uuid>` 로 본다
  - 엔벨로프가 **입력줄에 문자열로 남아 있다** → 에이전트가 아직 안 떴던 것이다. 6부터 다시 한다
  - 엔벨로프가 **아예 없다** → 7을 다시 한다
  - 엔벨로프는 들어갔는데 제출되지 않았다 → `dmctl send-input --at <새 탭 uuid> --execute ""` 로 한 번 깨운다
- **세 번 시도해도 `working` 이 아니면 멈춘다.** 자기 탭을 닫지 말고 사용자에게 무엇이 막혔는지 말한다

### 9. 자기 탭을 닫는다

**8이 `working` 을 준 뒤에만 온다.** 이 순서를 바꾸지 마라 — 확인 없이 닫으면 인계가 통째로 사라지고, 그 사실을 볼 사람이 없다.

```
dmctl who-am-i                        # uuid= 를 다시 읽어 1에서 적은 값과 같은지 본다
dmctl close-tab --at <자기 탭 uuid> --force
```

- **`--at` 에 넣는 것은 `who-am-i` 의 `uuid` 다.** `toolId` 도, 방금 만든 새 탭의 uuid 도 아니다
- **`--force` 를 빼지 마라.** 그 탭에는 방금까지 에이전트가 돌고 있었으므로 확인창("프로세스가 있습니다")이 뜨고, **그 창에 답할 사람이 이미 없다** — 인계가 거기서 멎는다. 도구를 살려 두고 싶으면 `--background` 를 쓴다(둘은 함께 쓸 수 없다)

기대 출력은 `ok:true` 이고 `location` 이 **자기 탭**을 가리킨다.

**이것이 이 세션의 마지막 명령이다.** 닫기 전에 사용자에게 보고할 것이 있으면 먼저 보고한다.

---

## 이 명령이 하지 않는 것

- **일을 대신 하지 않는다.** 인계는 다음 세션이 무엇을 할지 정하는 것까지다
- **문서를 대신 요약하지 않는다.** 줄인 인계는 다음 세션이 같은 조사를 다시 하게 만든다 — 값을 치르고 안 것은 길어도 그대로 넘긴다
- **확인 없이 닫지 않는다.** 막혔으면 멈추고 말한다. 그것이 조용히 사라진 인계보다 낫다

### 공개 API 요약 (2.4.3 node·채팅이 쓴다)

- `Mesh::new(Options) -> Mesh` (tokio 런타임 안에서 부른다. `Clone`), `node()`, `set_upper(Arc<dyn Upper>)`, `close()`
- `handler() -> dm_shared_edge::Handler` (Go `Handler()`), `attach(fp, Conn, dialed)`, `open(fp, Vec<Vec<u8>>)`, `broadcast(&Frame, skip)`, `send(fp, &Frame)`
- `run(CancellationToken)` async (Go `Run(ctx)`), `notify(&CancellationToken, fp) -> Result<(), MeshError>` async, `hello_all(&Hello, Duration)` async
- `drop_link(fp)` (Go `Drop`), `mark_outdated`, `outdated`, `linked`, `announce`, `reachable() -> Arc<HashSet<String>>`, `mutual`, `name_of -> Option<String>`, `nodes() -> Vec<NodeInfo>`, `view() -> View`, `send_invite(to, code, OffsetDateTime)`
- `Options::new(identity)` + 콜백 필드(`name`·`hello`·`edges`·`dial`·`on_hello`·`on_hello_sent`·`on_invite`·`on_not_edge`·`on_changed`·`now`)
- `DialFn = Arc<dyn Fn(Target) -> BoxFuture<Result<Conn, CallError>>>`, `Conn { io: BoxStream, remote_host }`
- `trait Upper { frame, linked, changed }` — 모두 동기. `linked` 는 spawn_blocking 스레드에서 불린다(막혀도 된다)
- `MeshError` + `ErrorKind`(Go `errors.Is(err, ErrXxx)` → `err.kind() == ErrorKind::Xxx`). `Display` 는 Go 문구(`%w: %w` 포함)
- `Frame`, `encode`, `sign`, `verify`, `sign_frame`, `public_key`, `parse_key`, `FRAME_*`, `PATH`, `PROTO`, `HELLO_WAIT`, `Hello`, `Invite { expires: OffsetDateTime }`, `NodeInfo { self_ }`

### Go 와 다르게 한 내부 결정

- 동시성: goroutine·채널 대신 tokio task(읽기·쓰기 각 하나) + `std::sync::Mutex` 상태 + `CancellationToken`(연결 끊기, hello 완료, 걸기 완료). 보낼 줄은 `mpsc::channel(1024)` + `try_send`(가득 차면 끊음)
- 연결을 닫으면 읽기·쓰기 task 가 끝나며 두 반쪽을 놓아 스트림이 닫힌다(Go `conn.Close()` 대응)
- ECDSA 서명은 RFC6979 결정적 서명이다(Go 는 무작위). 서명 바이트가 달라도 둘 다 서로의 서명을 확인한다. 관측 표면 아님
- 공개키는 P-256 만 받는다(Go `ParsePKIXPublicKey` 는 다른 곡선의 ECDSA 키도 받는다). 노드 신원은 늘 P-256 이라 드러나지 않는다
- 시험이 Go 처럼 `opts` 를 바꾸는 대신 시험 쪽 콜백이 교체 가능한 슬롯을 거친다(프로덕션 구조 변경 없음)

### 남은 위험 / 조정자 확인 필요

- **출발지 IP**: Rust `dm-shared-edge` Listener 는 요청 extensions 에 상대 주소를 싣지 않는다. `Mesh::handler()` 는 extensions 의 `std::net::SocketAddr` 를 읽도록 했으나, 지금은 늘 빈 값이다 → Go `OnHello(remoteHost)` 가 쓰는 출발지 IP 가 비어 들어간다(edgenode onHello 의 주소 학습에 영향 가능). 2.3 crate(edge) 에서 `req.extensions_mut().insert(peer_socket_addr)` 를 더해야 한다. 내 crate 밖이라 고치지 않았다
- 건 연결(dial)의 `remote_host` 는 `DialFn` 이 `Conn` 에 채워야 한다(Rust `Client::upgrade` 는 상대 주소를 돌려주지 않는다). node(2.4.3)가 정한다
- IPv6 링크 로컬 주소의 zone(`%en0`)은 Go 처럼 붙이지 않는다(Rust `SocketAddrV6` 는 scope id 숫자만 가진다)
- 2026-11-23 조정자: rust-port 에 병합(027e59cc). Go 노드와 mesh 상호 운용 확인. edge Listener 의 상대 SocketAddr 누락은 2.4 에이전트가 port(2.3) 로 고친다.

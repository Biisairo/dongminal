# SRS: 모바일 UX 개편 — IEEE 29148

> **문서 상태**: 승인·구현완료

요구사항 식별자 접두어: `FR-MUX-`

## 1. 개요 (Introduction)

### 1.1 목적 (Purpose)

접수한 말:

> **"모바일 uxui 개선작업이야. 지금의 모바일 환경도 잘 만들어져있지 않아. 가능한 모든 방법을 통해 개선해봐."**

모바일 모드(`body.mobile`)의 화면을 실측해 결함을 찾고, 그 결함을 고치며, 전역 화면
(서랍·Activity·설정)의 구조를 모바일에 맞게 다시 짠다.

### 1.2 범위 (Scope)

**포함:** `web/**` 의 모바일 모드 레이아웃·CSS·크롬(상단바·상태바·키바)·서랍·Activity
패널·설정 모달·편집기 미니맵.

**미포함:** §6 비목표. 데스크톱 모드의 동작은 바뀌지 않는다 (C-1).

### 1.3 정의 (Definitions)

| 용어 | 정의 |
|---|---|
| **모바일 모드** | `body.mobile`. `displayMode`·`mobileBreakpoint` 가 정한다 |
| **키바** | `#mobile-keybar`. 터미널에 Esc·Ctrl·화살표 등을 보내는 하단 줄 |
| **시트** | 모바일에서 화면 전체 높이를 덮는 전역 화면. 서랍(`#sidebar`)·Activity(`#agents-panel`)·설정 모달 |
| **터미널 칸** | 포커스 칸의 활성 탭이 터미널인 상태 (`App.focusedTerminal()` 이 값을 돌려준다) |

| # | 제약 |

## 3. 요구사항 (Specific Requirements)

### 3.1 결함 교정

**FR-MUX-1 (B1)** — 모바일에서 탐색기는 사이드 자리의 **전체 폭**을 쓴다.

**FR-MUX-2 (B2)** — 키바는 모바일이고 **터미널 칸**일 때만 보인다. 터미널 칸이 아니면
키바가 감춰지고, 본문은 그 높이만큼 아래로 늘어난다. 칸·탭을 바꿔 터미널 칸이 되면
다시 보인다.

> 이전 동작: 모바일이면 언제나 키바가 보였다 (MOBILE_KEYBAR_ALWAYS_VISIBLE).
> 새 동작: 터미널 칸일 때만 보인다.
> 이유: 키바의 모든 키는 터미널에만 간다. 편집기·탐색기·Git 에서 키바는 눌러도 아무
> 일이 없는 50px 이다. 상시 노출 요구의 근거(키보드가 올라와야만 보이던 결함)는
> 터미널 칸에서 그대로 지켜진다.

**FR-MUX-3 (B2)** — 키바가 보이거나 감춰지면 보이는 터미널의 크기를 다시 맞춘다(fit).

**FR-MUX-4 (B3)** — 모바일에서는 편집기 미니맵을 그리지 않는다. 사용자의 미니맵 설정
값(`editorMinimap`)은 바꾸지 않는다 — 데스크톱으로 돌아가면 설정대로 다시 그린다.

**FR-MUX-5 (B6)** — 모바일 칸 순회(`‹ n/m ›`)는 순회할 자리가 **둘 이상**일 때만 보인다.

**FR-MUX-6 (B6)** — 상단바의 새 탭 버튼(`#m-add-tab`)을 없앤다. 모바일 전용 단추였으므로
데스크톱에는 영향이 없다. 새 탭은 탭바의 `+` 로 만든다.

### 3.2 전체 높이 시트 (D-2)

**FR-MUX-10** — 모바일 서랍(`#sidebar`)은 화면 **왼쪽**에서 들어오는 전체 높이 시트다.
폭은 `min(86vw, 360px)` 이고, 시트 밖은 배경 막(`#drawer-backdrop`)이 덮는다. 배경 막을
누르면 닫힌다.

**FR-MUX-11** — 서랍의 하단 버튼 줄(`#sb-bottom`: 새로고침·설정)은 시트의 **맨 아래**에
붙는다.

**FR-MUX-12** — 모바일 Activity(`#agents-panel.open`)는 화면 전체를 덮는 시트다.

**FR-MUX-13** — 시트(서랍·Activity·설정)가 열려 있는 동안 키바와 상태바를 감춘다.
시트가 닫히면 FR-MUX-2 의 규칙대로 되돌린다.

**FR-MUX-14** — 서랍과 Activity 시트는 Escape 로 닫힌다. 설정이 열려 있으면 설정의
Escape(FR-MUX-23)가 우선한다. 데스크톱의 Escape 동작은 바꾸지 않는다.

**FR-MUX-15** — 모바일로 앱을 열 때 Activity 의 열림 상태(세션 저장값)를 되살리지 않는다.
데스크톱은 종전대로 되살린다.

> 실측: 한 번 Activity 를 열어 둔 채 새로고침하면, 모바일 앱이 전체 화면 Activity 로
> 시작해 작업 화면을 덮었다.

**FR-MUX-16** — 서랍 머리의 Activity 단추는 그 줄의 폭을 다 쓴다.

**FR-MUX-17 (B23)** — 모바일 Activity 의 머리 단추는 닫기(`×`, `Close the panel`)다.

> 이전 동작: `chevron-up` (위에서 내려오는 띠를 위로 접는다, UX_BATCH13_SRS FR-ACB D-1).
> 새 동작: `x`. 이유: 시트가 화면 전체를 덮으므로 접히는 방향이 없다.

### 3.3 설정 (D-3)

**FR-MUX-20** — 모바일 설정 모달은 화면 전체(안전 영역 포함)를 덮는다.

**FR-MUX-21** — 모바일에서 설정을 열면 **섹션 목록**이 먼저 보인다. 목록은 탭 하나를
한 줄(터치 하한 이상의 높이, 오른쪽에 `›`)로 세로로 늘어놓는다. 이때 패널은 보이지 않는다.

**FR-MUX-22** — 목록에서 섹션을 누르면 그 섹션의 **상세**(패널)로 들어간다. 상세의
머리에는 뒤로 버튼과 섹션 이름이 선다. 뒤로 버튼은 목록으로 돌아간다.

**FR-MUX-23** — 상세에서 Escape 는 목록으로 돌아간다. 목록에서 Escape 는 설정을 닫는다.

**FR-MUX-24** — 섹션 전환은 기존 탭 전환 함수를 그대로 부른다 — 패널을 고르는 진실은
한 자리다. 데스크톱의 탭 동작은 바뀌지 않는다.

**FR-MUX-25** — 모바일 설정의 행에서 라벨은 줄 단위로 읽히는 폭을 갖는다. 라벨이 한 글자씩
줄바꿈되지 않는다.

**FR-MUX-26 (B10)** — 모바일의 설정·대화상자·Git 뷰·사이드 안의 선택 상자와 입력칸은 높이가
터치 하한 이상이고 글자는 `--fs-xl`(기본 18px)이다 — iOS 는 16px 아래 입력에 포커스하면 화면을 확대한다.

### 3.4 상태바 (D-4)

**FR-MUX-30** — 모바일 상태바는 **연결 상태**와 **cwd** 항목만 보인다. 나머지 항목은
감춘다. 사용자의 상태바 항목 설정 값은 바꾸지 않는다.

### 3.5 Repo 창·편집기 (D-6)

**FR-MUX-40 (B11)** — Changes 의 파일·폴더 행과 Changes/Explorer 전환 탭은 터치 하한 이상이다.

**FR-MUX-41 (B12)** — Git 뷰 도구 줄은 좁은 폭에서 다음 줄로 접힌다.

**FR-MUX-42 (B11)** — 모바일에서 행·그룹 동작은 hover 없이 늘 보이며, 흐름 안에 선다(겹·페이드 없음).

**FR-MUX-43 (B17)** — 모바일 편집기·diff 는 설정과 무관하게 줄을 바꿔 보인다. `editorWordWrap`
값은 바꾸지 않는다. 모드가 바뀌면 열린 편집기가 따라간다.

**FR-MUX-44 (B19)** — 터미널 찾기 막대에서 닫기 단추가 화면 안에 있고, 입력 글자는 `--fs-xl` 이다.

**FR-MUX-45 (B17)** — 모바일 `미리보기` 단추는 오른쪽 아래에 선다.

**FR-MUX-46 (B18)** — 모바일 돋보기는 지금 칸의 찾기를 연다: 터미널 칸이면 터미널 검색, 편집기·diff
칸이면 그 파일의 찾기 패널이다.

**FR-MUX-47 (B19)** — 편집기 찾기·줄 이동 패널은 칸의 폭 안에 선다.

**FR-MUX-48 (B20)** — 모바일 Stash 는 목록과 미리보기를 위아래로 쌓는다. Stash·브랜치 행은 터치 하한 이상이다.

### 3.6 메뉴·알림·대화상자 (D-6)

**FR-MUX-50 (B13)** — 모바일에서 한 손가락으로 `MOBILE_LONG_PRESS_MS` 동안 누르면 그 자리에
`contextmenu` 를 보낸다. `MKB_TAP_SLOP_PX` 를 넘게 움직이면 취소한다. 터미널·편집기·입력칸
(`MOBILE_LONG_PRESS_SKIP`)은 제외한다.

**FR-MUX-51** — 한 번의 누름에 메뉴는 한 번만 열린다(브라우저가 스스로 보내는 것과 겹치지 않는다).
메뉴를 연 누름은 뒤따르는 click 을 내지 않는다. 길게 눌러 메뉴를 여는 자리에서는 iOS 의 글자 선택·콜아웃을 막는다.

**FR-MUX-52** — 데스크톱의 `contextmenu` 동작은 바뀌지 않는다.

**FR-MUX-53 (B14)** — 모바일 메뉴 항목은 터치 하한 이상이고, 메뉴는 화면을 넘지 않고 스스로 구른다.

**FR-MUX-54 (B15)** — 모바일 토스트는 화면 폭을 쓰고 줄을 바꾼다.

**FR-MUX-55 (B16)** — Git 대화상자·사이드의 체크박스·라디오는 20px, 그 줄은 40px 이상이다.

**FR-MUX-56 (B21)** — 서랍의 `+ 추가` 는 터치 하한, `Box` 는 32px 이상이다.

**FR-MUX-57 (B22)** — 모바일 알림 센터는 좌우 8px 를 남기고 화면 폭을 쓴다.

### 3.7 가로 휴대폰 (D-6)

**FR-MUX-60 (B24)** — `displayMode=auto` 에서 화면 높이가 `MOBILE_LANDSCAPE_MAX_H` 보다 낮고
주 포인터가 coarse 이면 폭과 무관하게 모바일이다.

> 이전 동작: Auto 는 폭(`mobileBreakpoint`)만 보았다.
> 새 동작: 폭 조건 또는 (낮은 높이 + 터치) 조건.
> 이유: 가로로 돌린 휴대폰이 데스크톱 화면이 되어 손으로 쓸 수 없었다.

**FR-MUX-61** — 높이가 넉넉한 터치 기기(태블릿)와 마우스 기기는 종전대로다.

## e2e — 무엇을 신호로 쓰나

**샤드를 시간으로 가른다.** `make e2e` 가 `scripts/e2e-shard.mjs` 로 목록을
파생한다 — CI(`e2e.yml`)도 **같은 자리**를 쓴다. 시간표(`e2e/shard-timings.json`)는
생성물이고 `make e2e-rebalance` 가 다시 만든다. `make e2e-plan` 으로 균형을 본다.

    벽시계 ~4.3분 · 불균형 1.00배 · 항목 1,600

**flaky 는 0 이 아니다** (회차당 0~4건). 흔들린 이름이 회차마다 거의 겹치지
않고 전부 단독 반복에서 통과한다 — **얇게 퍼진 시간 민감성**이다
(`M7_PROGRESS.md` §5-4).

**그러므로 판정은 `unexpected 0` 으로 한다.** 흔들린 것은 **단독 반복
(`--repeat-each=2`)으로 확인**해라. 같은 이름이 두 회차 연속 흔들리면 그때는
그 검사를 본다.

**새 스펙은 목록에 손으로 넣지 않는다** — `e2e-shard.mjs` 가 `e2e/` 에서
파생하고, 시간표에 없는 파일은 **가장 무겁게** 쳐서 배치한다.

  쓰거나 **검사가 자기 전제를 스스로 세우게** 하라

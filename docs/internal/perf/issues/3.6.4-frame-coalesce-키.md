# 3.6.4 frame coalesce 키 충돌

## 목표

3.6.3 에서 발견(3.6.1 이전부터 있던 결함): `frame` 의 coalesce 키가 `'frame:'+owner+':'+이름` 이라 주인이 객체면 모두 "[object Object]" 로 같아진다. 서로 다른 DiffView·문서 뷰가 같은 coalesce 이름(예: diff-fold)을 한 프레임에 쓰면 뒤의 것이 버려진다. 주인별로 구별되게 고친다(예: 주인 객체별 키 공간). 기존 호출 동작은 같은 주인 안에서 그대로.

## 완료 조건

- RED: 두 주인이 같은 이름으로 같은 프레임에 걸면 둘 다 돈다. 같은 주인은 여전히 하나로 합쳐진다. 프론트 단위 전체·tsc·check-timers. 전체 시험 금지.

# 2.8.1 read-screen 을 화면 상태로 (FR-TRM-8, D-22)

## 목표

`GET /api/tools/output?strip=1` 의 출처를 데몬 에뮬레이터의 화면 글자(화면 + 최근 기록, `bytes` 상한 유지)로 바꾼다. `read-output`(ANSI 그대로)은 링에서 계속 준다. 도움말·MCP `read_screen` 설명·helper 골든(`helper_scenarios.jsonl`)을 함께 고친다.

동작 변경(D-22) — 이전: 링 마지막 16 KB 에서 ANSI 를 걷은 글자. 새: 화면 격자 글자. 이유: 이전 답은 TUI 에서 지운 글자가 섞였다.

## 완료 조건

- RED: TUI 화면(vim·top)에서 read-screen 이 실제 화면 글자와 같다.
- RED: 잠든 터미널(브라우저 구독 0)에 답한다. 출력 없음·없는 도구의 답은 지금과 같다.
- 바꾼 부분의 시험(단위·관련 e2e 한두 개)·fmt·clippy·관련 게이트 통과. 전체 시험은 마일스톤 끝에서 한 번만(2.10).
- 시험을 먼저 쓰고 RED 를 확인한 뒤 구현한다.
- 동작을 바꿨으면 이전 동작 / 새 동작 / 이유를 진행 기록과 커밋 메시지에 적는다.

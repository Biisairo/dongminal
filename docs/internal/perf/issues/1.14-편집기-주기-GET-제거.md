# 1.14 편집기·탐색기의 3초 주기 GET 을 토픽으로

## 목표

탐색기(편집기)가 보이는 동안 `editor-pane.js:29` 의 `visiblePoll(gitReposInterval)` 이 `_edTick` 을 돌려 열어 둔 파일의 stamp 조회(`edStampTick`)와 감시 집합 안전망(`edWatchSync`)을 한다. D-9(상태용 주기 GET 전부 제거, 사용자 결정 2026-11-24 재확인)에 따라 이것을 없앤다.

- 서버의 파일 감시(`fs_watch`, `fs` 사건 토픽)가 열린 파일·감시 디렉터리의 변경을 민다. 브라우저는 그 사건으로 stamp 를 다시 본다(사건에 1:1 인 요청은 폴링이 아니다).
- 감시 집합(어떤 디렉터리를 볼지)은 탐색기 상태가 바뀔 때 보내고, 안전망 주기는 두지 않는다. 채널이 다시 붙으면(`chan:open`) 한 번 맞춘다.
- `gitReposInterval` 설정이 이 틱만 정하고 있었다면, 이 일이 끝난 뒤 그 설정이 아직 무엇을 정하는지 확인해 진행 기록에 적는다(삭제는 사용자 결정).
- 남는 서버 내부 주기가 있으면 이유와 주기를 `CHANNEL_PROTOCOL.md` 에 적는다(FR-SRV-2).

## 완료 조건

- 시험 먼저(RED 확인). 바꾼 crate 단위 시험, 관련 node 시험, 편집기 stamp·외부 변경 반영 e2e 한두 개, fmt·clippy·관련 게이트. 전체 시험 금지.
- 동작 변경은 이전/새/이유로 기록.

## 진행 기록

2026-11-24 (pf/1.14):
- 바꾼 것: `EditorPane._edStartGitPoll`(visiblePoll(gitReposInterval) 로 3초마다 `_edTick`) → `_edStartSync`(버스 구독 둘: `life:visible` → `_edTick` 한 번, `chan:open` gen>1 → `_edTick` 한 번). `_edTick` 은 이제 사건마다의 맞추기다(숨은 동안 쌓인 git 신호 갚기·gitDue 관측·스탬프·감시 등록). overflow 계기(`_onFsChanged`)는 그대로.
- 틱이 하던 git 토픽 구독 맞추기(`_edGitWatchSync`)는 보이는 집합이 바뀔 때마다 도는 `EditorWatch.edWatchSync` 의 프레임(`_edWatchFrame`)으로 옮겼다 — 감시 등록이 아직 서지 않았어도 돈다.
- 동작 변경 — 이전: 탐색기가 보이는 동안 3초(gitReposInterval)마다 `/api/fs/stamps`(+ 관측 없으면 git status)를 물었다. 새: 묻지 않는다. 변화는 서버 감시가 `fs`·`git:<root>` 토픽으로 밀고, 숨김 복귀·채널 재연결·overflow 에서만 한 번 맞춘다. 이유: D-9·FR-CON-8(상태용 주기 GET 을 남기지 않는다). 남는 서버 내부 주기는 없다(새로 만든 것 없음).
- 지운 것: `app._edGitPoll`, 시험 계약 이름 `_edGitPoll`(144 → 143).
- `gitReposInterval` 은 아직 쓰인다: `editorGitBackoffMs`(탐색기 git 관측 실패 백오프 = gitReposInterval × EDITOR_GIT_BACKOFF_FACTOR). Polling 화면의 "탐색기" 주기 설명은 이제 맞지 않는다 — 지우거나 이름을 바꿀지는 사용자 결정.
- 시험: 새 단위 시험 `editor-sync.test.mjs` 3건 + `editor-fs-watch.test.mjs` 1건, 구현 전 RED 4건 확인. 프론트 단위 1613 통과, jsconfig 타입 검사·eslint·check-timers·check-fetch·check-html·check-legacy-names 통과.
- e2e(바이너리 otterminal-pf1.14 한 번 빌드): editor-traffic·editor-explorer·notes-live-explorer·editor-live-reload·editor-ops 93 통과. 주기 틱을 기다리던 7건(X7·X12·V-ELR-10·11·12·V-21·트래픽 30초)은 같은 성질을 실제 계기(`resyncEditor` = visibilitychange)로 재도록 고쳤다. 트래픽 30초는 "stamps·status 0" 으로 강화했다.

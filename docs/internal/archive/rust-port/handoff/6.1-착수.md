## 이 세션이 배운 것 (5.2 를 하며)

- int(rust-port 브랜치)에서 이슈 파일을 고친 뒤 **커밋하지 않는다.** 이 세션이 한 번 실수로 커밋했다가 `reset --soft` 로 되돌렸다
- Go 인터페이스가 Rust 에 아직 없으면(예: `toolhub.ToolHub`) 소비자 쪽에 쓰는 메서드만 담은 좁은 trait 를 정의한다(2.2.3 결정). toolclient(5.3)는 동기 스레드 기반이라 async 문맥에서는 `spawn_blocking` 으로 감싼다
- Go `map[string]any` JSON 은 키 이름순 — 필드를 이름순으로 둔 struct 로 맞춘다. gocompat marshal 은 HTML 이스케이프(`<`)를 한다
- heredoc 으로 테스트를 쓰면 `<` 같은 이스케이프가 망가질 수 있다 — 쓴 뒤 grep 으로 확인한다
- 작업 디렉터리가 사라지면(worktree 이동) 셸 명령이 실행되지 않는다 — 절대 경로로 `cd` 부터 한다
- 테스트 옮길 때 "이미 취소된 ctx" 같은 경계 사례가 실제 결함을 잡는다(5.2 에서 하나 잡았다)

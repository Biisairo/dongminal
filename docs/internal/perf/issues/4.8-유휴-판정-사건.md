- 동작 변경
  - 이전: 데몬이 임계 0(기본)이어도 1초마다 깨어나 판정을 돌았다. 임계가 있으면 판정이 최대 1초 늦었다. 서버는 1초(L2)·2초(전경) 틱 작업을 늘 돌렸다.
  - 새: 임계 0 이면 데몬 판정 작업은 깨지 않는다. 임계가 있으면 마감에 맞춰 깬다. 서버는 이 두 틱을 만들지 않는다. 데몬이 판정하지 않는 동안(옛 데몬·연결 끊김) 서버 혼자 하던 L2 유휴 판정은 돌지 않는다.
  - 이유: 유휴 깨어남 0 (FR-SRV-2·3, NFR-PRF-5, D-58·D-59).

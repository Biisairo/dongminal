# 1.4.2 platform 뼈대·파일·경로

## 목표

platform crate 의 lib.rs(모든 모듈 선언과 Platform 구조체 필드 전부, current())를 먼저 세워 1.4.3~1.4.6 이 각자 모듈만 고치게 한다. 그리고 OS 종류·경로·원자적 쓰기·상태 파일 세대·파일 락·디렉터리 fsync·junction·크래시 마커를 옮긴다. testdata/file_uri_vectors.json 벡터를 그대로 쓴다. 공개 API 는 부모 이슈 1.4 의 진행 기록 "공개 API 안" 을 따른다. 바꿔야 하면 조정자에게 먼저 알린다.

- 대상 Go 코드의 관측 동작을 Rust 가 동등하게 제공한다 (FR-RSP-1·3)

- 진행 기록에 공개 API 요약과 Go 와 다르게 한 내부 결정이 있다

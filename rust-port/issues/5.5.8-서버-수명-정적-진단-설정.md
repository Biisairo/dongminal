### Go 와 다르게 한 결정 (DIFF 후보 표시)
- **DIFF 후보** `/api/diag` 의 `goroutines` 는 살아 있는 tokio task 수, `allocMB` 는 늘 0(GC 힙 계수 없음, RSS 는 unsafe OS 호출이 필요한데 platform 에 API 없음).
- **DIFF 후보·위험** `Run` 주소의 호스트가 비면(`:port`) `0.0.0.0` 에 리슨한다 — Go 는 이중 스택 `[::]`. IPv6 로 붙는 클라이언트가 갈린다. 합성 루트가 넘기는 주소 모양을 5.5/6 에서 확인할 것.
- **DIFF 후보** mime 형식: Go 는 호스트 mime 표(/etc/apache2/mime.types·Windows 레지스트리)도 읽는다. Rust 는 Go 내장 표만 — 내장 표 밖 확장자는 호스트에 따라 갈린다.
- Go 원시 400(Host 없음·잘못됨·여럿)은 상태 줄·Content-Type·Connection·본문이 같고, hyper 가 `content-length`·`date` 를 더하고 머리 이름을 소문자로 쓴다.
- 강제 종료는 업그레이드된 WebSocket 을 끊지 않는다(Go 하이재킹 연결과 같다). accept 오류는 모두 일시 오류로 보고 5ms→1s 물러선다.
- fs 감시 이벤트는 std 스레드에서 오므로 `new_fs_watch` 가 런타임 Handle 을 잡아 `kick` 한다 — 합성 루트는 tokio 런타임 안에서 `Server::new` 를 불러야 한다.
- 정적 자산 판은 `Server::new` 때 한 번 계산(Go 는 첫 사용 — 값 같음). q 값 해석은 Go ParseFloat 의 16진 부동소수를 받지 않는다.
- 시험 리슨 포트는 60147 미만 금지 규칙 때문에 127.0.0.1:0 대신 65000~65499 의 빈 루프백 포트를 고른다.

# 4.5.1 기반 — 자격증명·저장소·경로·API 클라이언트

## 목표

Service·Engine·Auto 가 쓰는 바탕을 옮긴다. 부모 이슈는 4.5 다. 실제 계정·네트워크에 접근하지 않는다(가짜 HTTP 서버는 60147 이상 포트). 자격증명 값을 로그·대화·문서에 남기지 않는다.

## 대상 Go 코드

- `internal/webserver/domain/claudeacct` 의 creds·oauth·api·usage·resets·pace·lines·policy·paths·dirlock·claudecfg·backup·live·store·history·waker·foldcase_* (약 1938줄). `AutoRange`(autoswitch.go)는 store.go 의 `AccountRanges` 가 쓰므로 여기서 옮긴다. `Resets.Usable`(alerts.go)도 resets 와 함께 옮긴다.
- 옮길 Go 시험: creds·oauth·api·usage·resets·pace·policy·paths·dirlock·claudecfg·backup·live·store·history·waker·account_ranges

## 완료 조건

- 대상 Go 코드의 관측 동작을 Rust crate 가 동등하게 제공한다 (FR-RSP-1·3)
- 관측 동작을 검증하는 Go 테스트가 Rust 테스트로 옮겨져 통과한다 (V-RSP-1)
- `cargo fmt --check`, `cargo clippy -D warnings`, 격리 실행 `cargo test` 통과 (NFR-RSP-4)
- OS 의존 코드가 있으면 windows·linux 대상 `cargo check` 통과 (NFR-RSP-5)
- 작업 전후 `rust/scripts/prod-pids.sh` 출력이 같다 (V-RSP-5)
- 진행 기록에 공개 API 요약과 Go 와 다르게 한 내부 결정이 있다

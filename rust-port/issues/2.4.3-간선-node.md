  - **Go 와 다르게 한 결정**
    1. **notify 실패의 분류**: Go 는 `%w` 사슬로 mesh 오류 안의 edge 오류(지문 불일치·거절·RemoteError 코드)를 가려낸다. Rust `MeshError`(2.4.1)는 원인을 문구로만 들어서, 지문 불일치·거절은 edge 의 고정 문구로 가리고 그 밖은 `edge_unreachable` 로 둔다. 상대의 RemoteError 코드는 전달되지 않는다. → 2.4.1 의 MeshError 가 `CallError` 를 들게 하면 고칠 수 있다(조정자에게 알림).
    2. `do_op` 은 async 다. 이름·주소가 바뀌면 HelloAll 을 기다린 뒤 답한다(Go 와 같은 순서).
    3. Go 의 recoverHandler(패닉 복구 500)는 옮기지 않았다(패닉으로 흐름을 잡지 않는다).
    4. pair 의 출발지 주소는 2.3 후속 수정의 `edge::client_addr`(요청 extensions 의 SocketAddr)에서 읽는다.

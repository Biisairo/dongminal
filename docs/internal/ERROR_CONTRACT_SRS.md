## 1. 개요 (Introduction)

### 1.1 목적 (Purpose)

오류에 **이름이 없다.** `http.Error(w, "bad request", 400)` 이 65곳이고, 그 문자열은
사람이 읽는 말이지 클라이언트가 분기할 수 있는 것이 아니다. 같은 400 이 열 가지
이유로 나며 브라우저는 그중 어느 것인지 알 길이 없다.

문서도 없다. 코드 47개 중 **문서에 있는 것은 7개**다.

### 1.2 범위 (Scope)

| 묶음 | 내용 |
|---|---|
| **C** 코드화 | `http.Error` 전부가 코드를 갖는다. `codes.go` 에 등록된다 |
| **H** 전달 | 코드와 요청 ID 를 **헤더**로 싣는다 — 본문을 바꾸지 않는다 |
| **K** 카탈로그 | `errors.md` 가 `codes.go` 에서 **생성**된다. CI 가 불일치를 잡는다 |
| **X** 전수성 | `apierr` 의 전수성 검사가 새 코드까지 덮는다 |

**미포함:** §6 비목표.

### 1.3 정의 (Definitions)

| 용어 | 정의 |
|---|---|
| **방언** | 오류 본문의 모양. 이 서버에 넷이 있고 각각이 **공개 계약**이다 |
| **코드** | 클라이언트가 분기하는 안정된 문자열. 사람이 읽는 문구와 다르다 |
| **핵심 표면** | `/api/*` 중 git·fs·runs 가 아닌 것. `http.Error` 가 사는 자리 |

  않는다**는 공개 계약 결정. 이 문서가 그것을 지킨다
- [`./DEEPENING_REFACTOR_SRS.md`](./DEEPENING_REFACTOR_SRS.md) 묶음 A — `apierr`

## 2. 현재 상태 (조사로 확정한 사실)

### 2.1 `http.Error` 가 65곳이고 전부 한 패키지에 있다

> 로드맵은 63곳이라 적었다. 실측은 **65** 다.

전부 `internal/webserver/httpapi` 다 — git·fs·runs 표면은 이미 `apierr` 를 지난다.
**그래서 이 작업의 범위가 로드맵이 말한 것보다 좁고 또렷하다**: 핵심 표면 하나다.

### 2.2 `http.Error` 는 `text/plain` 을 쓴다 — 다섯 번째 방언이다

`net/http` 의 `Error` 는 `Content-Type: text/plain` 에 문구 한 줄을 쓴다.
`architecture.md` 의 방언 표에 이것이 없다 — **표가 넷을 세는 동안 실물은
다섯이었다.**

### 2.3 그래서 "코드를 붙이면서 본문을 지킨다" 는 물음이 선다

로드맵은 둘을 함께 요구한다 — 모든 오류가 코드를 갖고, **기존 방언은 유지**한다.
평문 본문을 JSON 으로 바꾸면 그것이 곧 파괴적 변경이다.

**답은 헤더다** (§3.2). 본문은 한 바이트도 바뀌지 않고, 코드는 `X-Error-Code` 로
간다. 지금 본문을 읽는 코드는 그대로 돌고, 새 코드는 헤더를 읽는다.

### 2.4 코드 47개 중 7개만 문서에 있다

그리고 그 문서는 손으로 적혀 있다 — **조용히 낡는 구조**다.

## 3. 요구사항 (Requirements)

### 3.1 묶음 C — 코드화

**FR-ERR-1** 핵심 표면의 오류 응답은 `httpErr` 한 자리를 지난다.
`http.Error` 를 직접 부르지 않는다.

**FR-ERR-2** 모든 코드는 `apierr/codes.go` 에 등록된다. 리터럴을 호출부에 적지
않는다.

**FR-ERR-3** `scripts/check-http-error.sh` 가 핵심 표면의 `http.Error` 직접 호출을
잡는다. 예외는 `httpErr` 자신뿐이다.

### 3.2 묶음 H — 헤더로 싣는다

**FR-ERR-4** 오류 응답에 `X-Error-Code` 가 실린다.

**FR-ERR-5** **본문을 바꾸지 않는다.** `httpErr` 이 쓰는 본문은 `http.Error` 가
쓰던 것과 바이트 단위로 같다.

> 이것이 이 묶음의 전부다. 방언을 통일하지 않는다는 결정(`architecture.md`)은
> **"본문은 공개 계약이다" 라는 뜻**이고, 헤더는 그 계약 밖이다. 통일을 미루면서
> 코드를 얻는 유일한 길이다.

**FR-ERR-6** 오류 응답에 `X-Request-Id` 가 실린다 (`FR-OBS-8` 의 미들웨어가 이미
모든 응답에 싣는다 — 여기서는 **그 사실을 카탈로그가 안내한다**).

**FR-ERR-7** 기존 방언 넷의 렌더러도 `X-Error-Code` 를 싣는다. 본문의 코드와
같은 값이다 — 두 자리가 갈리면 헤더 쪽이 거짓말이 된다.

### 3.3 묶음 K — 카탈로그

**FR-ERR-8** `docs/external/errors.md` 는 `codes.go` 에서 **생성**된다.
손으로 고치지 않는다.

**FR-ERR-9** 각 코드에 **의미와 복구 안내**가 있다. "무엇이 잘못됐는가" 만으로는
부족하다 — 사용자가 다음에 할 일이 적혀 있어야 한다.

**FR-ERR-10** 안내문의 원천은 `codes.go` 옆의 표(`CodeDoc`)다. 코드를 더하고
안내를 적지 않으면 **생성이 실패한다.**

**FR-ERR-11** CI 가 생성물과 코드 목록의 불일치를 잡는다
(`scripts/check-error-docs.sh`).

### 3.4 묶음 X — 전수성

**FR-ERR-12** 핵심 표면의 새 코드도 `apierr` 의 전수성 검사가 덮는다.

**FR-ERR-13** 코드 문자열이 겹치면 검사가 실패한다 — 같은 문자열이 두 이름을
갖지 않는다 (기존 `V6` 의 확장).

## 4. 검증 (Verification)

| ID | 확인 |
|---|---|
| TC-ERR-1 | `httpErr` 의 본문이 `http.Error` 와 **바이트 단위로 같다** |
| TC-ERR-2 | 오류 응답에 `X-Error-Code` 가 있다 |
| TC-ERR-3 | 핵심 표면에 `http.Error` 직접 호출 0곳 |
| TC-ERR-4 | 탐침 — 새 `http.Error` 를 넣으면 게이트가 **실패한다** |
| TC-ERR-5 | 모든 코드에 안내문이 있다 (없으면 생성 실패) |
| TC-ERR-6 | 생성물이 `codes.go` 와 일치한다 |
| TC-ERR-7 | 탐침 — 코드를 더하면 문서 대조가 **실패한다** |
| TC-ERR-8 | 코드 문자열이 겹치지 않는다 |
| TC-ERR-9 | git·fs·runs 방언의 응답에도 `X-Error-Code` 가 있고 본문의 값과 같다 |
| TC-ERR-10 | 오류 응답에 `X-Request-Id` 가 있다 |

## 5. 결정 (Decisions)

| ID | 결정 | 근거 |
|---|---|---|
| **D-ERR-1** | 코드를 **헤더**로 싣는다 | 본문은 공개 계약이고 헤더는 그 밖이다. 방언을 통일하지 않으면서 코드를 얻는 유일한 길 |
| **D-ERR-2** | 본문을 **한 바이트도** 바꾸지 않는다 | `architecture.md` 의 "통일은 리팩터가 아니라 파괴적 변경" 을 그대로 지킨다 |
| **D-ERR-3** | 카탈로그를 **생성**한다 | 손으로 적은 문서는 조용히 낡는다 — 이 마일스톤이 반복해 만나는 자리다 |
| **D-ERR-4** | 안내문이 없으면 **생성이 실패**한다 | 코드만 늘고 안내가 없는 문서는 없는 것보다 나쁘다 — 있다고 믿게 만든다 |
| **D-ERR-5** | 평문 방언을 **다섯 번째로 인정**하고 표에 적는다 | 실물이 다섯인데 표가 넷을 세는 것이 결함이다. 지우는 것이 아니라 세는 것이 먼저다 |

## 6. 비목표 (Non-goals)

1. **방언 넷(다섯)의 통일.** `G6-4` 이고 `architecture.md` 가 공개 계약으로
   못박았다 — 뒤집을 근거가 리포트에 없다.
2. **오류 문구의 한국어 제거.** M9 `G7-4` 다.
3. **클라이언트가 헤더로 분기하도록 고치는 것.** 표면이 생겼다는 것과 그것을
   쓰는 것은 다른 일이고, 이 마일스톤은 앞의 것만 한다.
4. **상태 코드의 재분류.** 지금 나가는 상태 코드는 그대로다 — 바꾸면 그것도
   파괴적 변경이다.

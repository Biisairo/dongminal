# Git 창 수동 검증 체크리스트 (GIT_SRS V14 · V60)

자동 테스트가 잡지 못하는 것만 남긴다 — 눈으로 봐야 아는 것(배치·색·읽힘),
실기기(모바일 터치), 실제 저장소에서만 드러나는 것.

**준비**

```bash
scripts/git_fixture.sh /tmp/dm-git-fixtures     # 저장소 10종
scripts/start.sh                                # dongminal
```

각 항목은 `☐` → `☑`(정상) / `✗`(결함, 사유 기록). 대상 저장소는 두 종류다:
**dongminal 자기 저장소**(실사용)와 **픽스처**(엣지 케이스).

# SRS: 찾은 것을 바꾸고, 고른 것을 들고 들어간다 — IEEE 29148

> **문서 상태**: 승인·구현완료

## 1. 개요 (Introduction)

### 1.1 목적 (Purpose)

접수한 요구는 둘이다.

> 1. **"editor 글자 검색 후 한번에 수정하기 기능 추가."**
> 2. **"전체 문서에서 검색 시 글자 드레그 선택한 상태로 들어가면 일반 검색처럼
>    해당 글자 미리 채워놓기."**

둘은 화면이 다르지만 **같은 결핍**이다 — 찾기가 거기서 끝난다. 찾은 것을 고칠
길이 없고(①), 고를 것을 이미 골라 두었는데 다시 쳐야 한다(②).

### 1.2 범위 (Scope)

| 묶음 | 내용 |
|---|---|
| **R** 바꾸기 | 편집기 찾기 패널(`.fe-find`)에 바꾸기 줄. 하나씩·모두 |
| **S** 씨앗 | 전체 검색(`grep`)을 열 때 **편집기의 선택**을 질의로 싣는다 |

**미포함:** §6.

### 1.3 정의 (Definitions)

| 용어 | 정의 |
|------|------|
| **찾기 패널** | 편집기 우상단 오버레이 `.fe-find` (`EDITOR_FIND_PANEL_SRS`) |
| **전체 검색** | `Mod+Shift+F` 의 `grep` 모드. 패널은 `.ed-find` 이며 네 모드가 **공유한다** |
| **현재 일치** | 이전/다음이 가리키는 하나 (`_findCur`) |
| **씨앗** | 패널을 열 때 질의 칸에 미리 실리는 글자 |

- [`./EDITOR_FIND_PANEL_SRS.md`](./EDITOR_FIND_PANEL_SRS.md) — 이 문서가 그
  **비목표 1**(바꾸기·전부 바꾸기)을 연다. 옵션 셋·일치 계산·하이라이트는 그쪽

- `FR-EFP-9` — 편집기 찾기는 **이미** 한 줄 선택을 질의로 싣는다. 묶음 S 는 그

## 2. 현재 상태 (조사로 확정한 사실)

### 2.1 바꾸기는 **막혀 있다**

`EDITOR_FIND_PANEL_SRS` 가 Monaco 의 find 위젯을 걷어내며 바꾸기 키까지 함께
닫았다 — `Mod+H`(Windows·Linux)와 `Mod+Alt+F`(macOS)가 `file-editor-find.js:36`
에서 막힌다. 그래서 지금 편집기에는 **바꾸는 길이 하나도 없다.** 비목표 1 은
*"사용자가 고른 범위 밖"*(D-6)이었고, 이번 접수가 그 범위를 넓혔다.

### 2.2 일치는 이미 손에 있다

`_findRun` 이 `model.findMatches(...)` 로 범위를 모아 `_findHits` 에 든다. 바꾸기가
새로 계산할 것은 없다 — **치환 문자열과 편집 한 번**이 더해질 뿐이다. 다만 캡처
그룹을 쓰려면 `findMatches` 의 여섯째 인자(`captureMatches`)를 켜야 한다. 지금은
`false` 다.

### 2.3 전체 검색은 질의 칸을 **비운다**

`_edPanel` 이 열릴 때마다 `q.value=''` 한다 (`app-edsearch.js:141`). 편집기에서
글자를 고르고 `Mod+Shift+F` 를 눌러도 빈 칸이 뜬다 — **같은 앱의 `Mod+F` 는 그
선택을 싣는데**(FR-EFP-9) 여기만 다르다. 접수한 말의 *"일반 검색처럼"* 이 그
대비를 가리킨다.

### 2.4 그 패널은 넷이 공유한다

`_edPanel(mode, root)` 의 `mode` 는 `find`(파일 이름) · `grep`(본문) ·
`refs` · `defs` 넷이다. 씨앗을 패널에 걸면 **파일 이름을 찾는 칸에 본문 조각이
들어간다.** 모드를 가려야 한다.

## 3. 요구사항 (Requirements)

### 3.1 바꾸기 (묶음 R)

**FR-ERS-1.** 찾기 패널은 두 줄이 된다. 둘째 줄(바꾸기)은 **토글로 여닫고 기본은
접힘**이다 — 찾기만 할 때 편집 화면을 덜 가린다 (사용자 선택 2026-09-20).

**FR-ERS-2.** 토글 상태는 옵션 셋과 **같은 자리에 보존된다.** 열어 둔 사람에게
매번 접힌 패널을 주지 않는다.

**FR-ERS-3.** 바꾸기 줄은 입력 칸 하나와 버튼 둘(`바꾸기` · `모두 바꾸기`)이다.

**FR-ERS-4.** `바꾸기` 는 **현재 일치 하나**를 치환하고 다음 일치로 옮긴다.

**FR-ERS-5.** `모두 바꾸기` 는 모든 일치를 **한 번의 편집**으로 치환한다 —
`undo` 한 번에 전부 돌아온다. 여러 번으로 나누면 되돌리기가 사용자의 일이 된다.

**FR-ERS-6.** 정규식 옵션이 **켜져 있을 때만** 바꿀 말의 `$1`~`$9` 와 `$&` 를
캡처로 치환한다. 꺼져 있으면 `$` 는 글자 그대로다 (사용자 선택 2026-09-20).

**FR-ERS-7.** 일치가 없거나 질의가 비면 두 버튼은 **비활성**이다.

**FR-ERS-8.** 치환한 뒤 일치를 다시 세고 화면 표시를 갱신한다.

**FR-ERS-9.** 바꾸기 칸의 `Enter` 는 `바꾸기` 다. `Escape` 는 패널을 닫는다 —
찾기 칸과 같은 규약이다.

### 3.2 씨앗 (묶음 S)

**FR-ERS-20.** 전체 검색을 열 때 **활성 편집기의 선택**을 질의 칸에 싣는다.

**FR-ERS-21.** **한 줄 선택만** 싣는다. 여러 줄은 싣지 않는다 — 근거는 FR-EFP-9
와 같다: 줄바꿈이 든 질의는 grep 한 줄과 맞지 않아 결과가 0 이 된다.

**FR-ERS-22.** 실린 글자는 **전체 선택된 상태**다. 한 번의 타이핑으로 다른 말로
갈아 칠 수 있어야 한다 (FR-EFP-9 와 같은 규약).

**FR-ERS-23.** `find`·`refs`·`defs` 모드는 **종전대로 비운다** (§2.4).

**FR-ERS-24.** 선택이 없거나 편집기가 없으면 종전대로 빈 칸이다 — 씨앗이 없는
것은 오류가 아니다.

## 4. 결정 (Decisions)

| # | 결정 | 근거 |
|---|---|---|
| **D-1** | 바꾸기 줄은 **토글**이다 (항상 두 줄이 아니라) | 사용자 선택. 패널이 편집기 우상단 오버레이라 두 줄이 늘 떠 있으면 본문을 그만큼 덮는다 |
| **D-2** | 캡처 그룹 `$1`·`$&` 를 **쓴다** | 사용자 선택. 정규식 찾기가 이미 있으므로 그 짝이다 — `(\w+)_(\w+)` → `$2_$1` 을 한 번에 한다 |
| **D-3** | `모두 바꾸기` 는 **편집 한 번**이다 | `undo` 가 한 번이어야 한다 (FR-ERS-5). Monaco 의 `executeEdits` 가 목록을 통째로 받는다 |
| **D-4** | 씨앗은 **`grep` 에만** 건다 | 패널을 넷이 공유한다 (§2.4). 파일 이름 칸에 본문 조각을 넣으면 그 모드가 못 쓰게 된다 |
| **D-5** | 씨앗의 규칙을 FR-EFP-9 **그대로** 쓴다 | 같은 앱에서 같은 동작이 두 규칙을 가지면 사용자가 어느 쪽인지 외워야 한다 |

## 6. 비목표 (Non-goals)

- **전체 검색 결과를 여러 파일에서 한 번에 바꾸기.** 이 문서의 바꾸기는 **열린
  파일 하나** 안이다. 여러 파일 치환은 되돌리기·충돌·미열림 파일의 저장까지
  걸리는 별도 작업이다
- **선택 영역 안에서만 바꾸기** (`EDITOR_FIND_PANEL_SRS` 비목표 2 와 같다)
- **바꾸기 이력**
- **터미널·다른 표면의 선택을 씨앗으로 쓰는 것.** 씨앗의 출처는 편집기다

## 7. 리스크 (Risks)

| 리스크 | 등급 | 완화 |
|---|---|---|
| `모두 바꾸기` 가 상한(`ED_FIND_MAX_HITS`)에 걸려 **일부만** 바뀐다 | **MEDIUM** | 상한은 찾기가 이미 쓰던 값이고 수 표시도 그 상한을 따른다. 사용자가 보는 수와 바뀌는 수가 **같다** — 보이지 않는 차이를 만들지 않는 것이 이 자리의 규약이다 |
| 캡처 치환이 `$` 를 삼켜 리터럴 `$` 를 못 넣는다 | **LOW** | 정규식이 **꺼져 있으면 치환하지 않는다** (FR-ERS-6). 켠 상태에서 리터럴 `$` 가 필요한 경우는 `$$` 로 적는 관례를 따른다 |
| 씨앗이 이전 질의를 덮어 사용자가 쓰던 말을 잃는다 | **LOW** | 실린 글자는 **전체 선택** 상태이므로 한 글자만 쳐도 사라진다 (FR-ERS-22). 선택이 없으면 종전대로 빈 칸이다 |

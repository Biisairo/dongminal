# 7.1 웹 자산 임베드(dm-web-assets)

## 목표

1.3 의 settingsschema 가 `web/js/core/settings-schema.js` 를 읽어야 해서, 이슈 7 의 일부인 웹 자산 임베드를 먼저 낸다 (FR-RSP-12).

## 진행 기록

- 2026-11-23 조정자: rust-embed(debug-embed·include-exclude)로 Go `//go:embed *.html *.css *.webmanifest vendor/* js/*/*.js js/core/base/*.js assets/*` 와 같은 집합을 싣는다. 디렉터리 패턴 아래의 `.`·`_` 이름은 Go 처럼 뺀다.
- 공개 API: `get(path) -> Option<Cow<'static, [u8]>>`, `paths() -> Vec<String>`(사전순), `read_dir(dir) -> Option<Vec<DirEntry{name, is_dir}>>`.
- Go embed 테스트 3개(아이콘·vendor 디렉터리·기반 클래스)와 settings-schema·.go 제외 시험을 옮겼다. 5개 통과.
- 실린 파일 목록을 go1.27.2 의 `fs.WalkDir(web.FS())` 결과와 대조했다. 448개로 같다.
- debug-embed 를 켜서 debug 빌드도 디스크가 아니라 바이너리에서 읽는다(빌드 판에 따라 동작이 갈리지 않게).

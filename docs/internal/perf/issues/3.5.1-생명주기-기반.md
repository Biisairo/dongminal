# 3.5.1 생명주기 기반 (D-36·D-37·D-38)

## 목표

- 계약 `mount`·`wake`·`sleep`·`unmount`(기반 클래스 강제 없음, `View` 에 기본 구현). `Component` 에 `awake(fn)` — 깰 때 건 구독·타이머·관측을 `sleep` 때 걷는다. 비 Component 주인용 도우미 `Awake`.
- 렌더러가 그릴 때마다 붙은 본문 집합을 지난 집합과 견주어 전이를 건다. `sleep` 은 2초(`SCREEN_SLEEP_MS`) 뒤, 그 안에 다시 보이면 취소.
- 브라우저 탭 숨김 신호는 `TimerHub` 의 하나뿐인 `visibilitychange` 에서 받는다(새 리스너 없음). 규칙 적용은 3.5.4.
- 시험용 관측 `app.testing.sleepers()`. 화면은 아직 옮기지 않는다.
- 렌더러 파일 병합 순서: **3.5.1** → 3.4.3 → 3.6.2. 2.5 는 이 위에 터미널 쪽만 채운다(D-38).

## 완료 조건

- RED(하네스 단위): 전이 `mount→wake→sleep→wake→unmount`. `sleep` 두 번 → 한 번만 걷음. `awake` 안의 구독·타이머가 `sleep` 뒤 0, `wake` 뒤 다시 1. 2초 안에 다시 보이면 `sleep` 없음. 잠든 상태의 `unmount` 도 모두 놓음.
- 단위: 렌더러가 본문이 빠지면 `sleep` 예약, 다시 붙으면 취소. 전체 시험 금지.
- 동작을 바꿨으면 이전 동작 / 새 동작 / 이유를 진행 기록과 커밋 메시지에 적는다.

**2.5·3.5.2·3.5.3 이 쓸 표면**

1. **전이 대상이 되는 법**: 탭 본문 주인에 `wake()`·`sleep()` 을 둘 다 둔다(있으면 `mount(host)`·`unmount()` 도 부른다). 그것만으로 렌더러가 부른다 — 처음 보이면 `mount(host)` → `wake()`, 가려지면 2초 뒤 `sleep()`(그 안에 다시 보이면 취소), 잠든 뒤 다시 보이면 `wake()`. `sleep` 은 한 번만 온다.
2. **깬 동안만 사는 것**:
   - `Component` 하위(`ChatViews` 등): `this.awake(a => { a.every(...); a.on(...); a.sub('git:'+root, fn); a.listen(...); a.observe(...) })` 로 걸고, `wake(){ this._awake.wake() }`·`sleep(){ this._awake.sleep() }` 를 둔다(View 하위는 기본 구현이 있다).
   - `Component` 가 아닌 주인(`TerminalTool`·`FileEditor`·`DocRender`·`GitPanel`·`RunsPanel`): `this._life=new Awake({parent:this})`(시간은 `TIMERS`, 채널은 `window.app.channel`. 따로 주려면 `{timers, bus, channel}`)을 들고 `wake`/`sleep` 에서 그것의 `wake`/`sleep` 을, 파괴에서 `dispose` 를 부른다.
3. **주인이 사라질 때**: 걷는 자리가 `app.renderer.life.unmount(owner)` 를 부른다(예약 취소 + 잊기 + `owner.unmount()`). 렌더러 안의 편집기 두 자리는 이미 부른다. **아직 부르지 않는 자리**(계약을 다는 이슈가 더한다): 터미널 `core/ws-sync-controller.js:345`·`core/tool-life.js:145`·`core/slot-ops.js:314`(2.5), 편집기 `core/slots-controller.js:96`·`core/repo-preview.js:65`·`core/slot-ops.js:320`(3.5.3), git 패널 `core/git-surfaces.js:231`·`core/repo-win-controller.js:169`(3.5.2). 부르지 않으면 `ScreenLife` 가 그 주인을 잡고 있고, 잠든 뒤에는 `sleepers()` 에 남는다.
4. **Run·채팅**: `_mountTabBody` 의 Run·채팅 갈래는 지금 주인이 `null` 이다(본문 요소만 받는다). 3.5.2 가 주인 객체를 돌려받아 `owner=` 를 채운다.
5. **브라우저 탭 숨김**: `app.renderer.life.pageHidden`(TimerHub 신호). 규칙(D-M3-8)은 3.5.4.
6. **관측**: `app.testing.sleepers()` → `[{kind, timers, subs}]` — 잠든 주인마다 그 주인 또는 그 `Awake`(`parent===주인`)가 주인인 남은 `TimerHub` 일 수와 채널 토픽 구독 수.
7. **3.4.3 자리표시**: `_mounted.set(자리표시, null)` 이면 전이 대상이 아니다.

# 1.3 설정·HTTP 보조 묶음

## 목표

JSON·HTTP 응답 보조 패키지를 옮긴다. httpresp·httpreq·sse·httproute 는 HTTP 프레임워크(hyper/axum) 선택의 기준이 되므로, 고른 타입(요청·응답·바디 타입)을 진행 기록에 분명히 적는다. 이후 webserver 이슈들이 그 결정을 따른다.

## 대상 Go 코드

- `internal/shared/runfile`
- `internal/shared/release`
- `internal/shared/httpresp`
- `internal/shared/httpreq`
- `internal/shared/statusline`
- `internal/shared/settingsschema`
- `internal/webserver/sse`
- `internal/webserver/httproute`

프로덕션 코드 약 1197줄.

## 완료 조건

- 대상 Go 패키지의 관측 동작을 Rust crate 가 동등하게 제공한다 (FR-RSP-1·3)
- 관측 동작을 검증하는 Go 테스트가 Rust 테스트로 옮겨져 통과한다 (V-RSP-1)
- `cargo fmt --check`, `cargo clippy -D warnings`, 격리 실행 `cargo test` 통과 (NFR-RSP-4)
- OS 의존 코드가 있으면 windows·linux 대상 `cargo check` 통과 (NFR-RSP-5)
- 작업 전후 `rust/scripts/prod-pids.sh` 출력이 같다 (V-RSP-5)
- 진행 기록에 공개 API 요약과 Go 와 다르게 한 내부 결정이 있다

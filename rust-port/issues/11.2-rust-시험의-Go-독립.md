# 11.2 R2 rust 시험의 Go 독립

## 목표

docs/internal/GO_REMOVAL_SRS.md 의 G-4·G-58~G-66·G-68 를 요구 동작·수락 시험대로 바꾼다. 4절 조정자 결정과 3.10 묶음 순서를 따른다. Go 판과 사용자가 보는 동작(명령·인자·출력·산출물 이름·위치·종료 코드)이 같아야 한다.

## 진행 기록

### 2026-11-24 (73424cd3) — review, 커밋 4a8ecff1 (병합 6c140542)

**운영 PID**: 시작 `38173 start --foreground` · `58470 d --handover-fd` / 끝 같음.

**자리별 처리**
- G-4: Go 의 TC-AVS-9(`?v=__ASSETV__`)가 Rust 에 없어 `dm-web-assets` 에 `index_declares_no_literal_version`(+정규식 대응 `asset_versions_catches_literal`)으로 옮겼다. Go `\s` 에 맞춰 ASCII 공백만 끊는다. 나머지 세 임베드 시험은 이미 있었다. **`git rm web/*.go` 는 하지 않았다** — FR-GRM-17 이 `web/*.go` 를 R10 대상으로 두고, C-GRM-3(R10 전에는 Go 빌드가 돌아야 함)과 충돌한다. R10 에서 지운다.
- G-58·G-59: 벡터 두 개를 `rust/crates/shared/platform/testdata/`·`rust/crates/webserver/gitapi/testdata/` 로 **복사**하고 경로를 바꿨다. Go 원본은 Go 시험이 쓰므로 R10 에서 지운다.
- G-60: `matches_go_baseline_constants` 를 지웠다. 대신 `all_values_are_unique` 를 두었다.
- G-61: `paths_match_server_routes` 가 `crates/webserver/{httpapi,gitapi}/src/**/*.rs`(`tests/` 디렉터리·`tests.rs` 제외)의 `"/api/…"` 리터럴을 훑는다. 58개 상수 모두 걸린다. 0건이면 실패한다.
- G-62: runtime 자산 시험의 Go 트리 비교 갈래를 지웠다(`asset_list_matches_disk`).
- G-63: go_parity 둘은 `DM_GO_REF_SRC` 가 있을 때만 돈다. 없으면 `DM_GO_REF_SRC 가 없어 건너뛴다` 한 줄(FR-GRM-12).
- 새 스크립트 `rust/scripts/go-ref.sh <출력> <패키지> [go build 인자]`: `DM_GO_REF_SRC`(main worktree)에서 빌드한다. `rust/…` 패키지(testdata/go*)는 `go build -overlay` 로 main 트리에 얹어 빌드한다 — main 트리에 파일을 쓰지 않는다. 없으면 종료 2. 다섯 testdata 와 `./cmd/dongminal` 모두 빌드 확인.
- G-64: go_interop 넷·ipc·boot·gopeer 주석의 빌드법을 go-ref.sh 로 바꿨다. testdata/go*/main.go 는 남겼다(Q-GRM-4).
- G-65: `parity/run.sh` 첫 인자 `--go-bin <경로>`/`--go-bin=<경로>`, 없으면 `DM_GO_REF_SRC` 로 빌드, 둘 다 없으면 `parity: Go 참조가 없다 — …` 종료 2. 경로 누락·바이너리 없음도 종료 2. README·SPEC(FR-PAR-41·50, V-PAR-3) 갱신. FR-PAR-50 은 R8 과 겹치지 않게 "기본 빌드(G-53)" 로만 적었다.
- G-66: interop README 의 빌드법을 main worktree + go-ref.sh 로.
- G-68: hermetic.sh 의 Go 캐시 블록은 **남겼다** — go-ref.sh 를 격리 실행으로 돌릴 때 필요하다(SRS 의 "필요하면 남긴다"). 주석만 고쳤다.
- G-74(조정자 추가): web/js/test 네 벡터를 Rust 사본으로, remote-actions 는 `rust/crates/webserver/hub/src/commands.rs` 의 `CMD_ACTIONS` 를 파싱한다. Go `cmdActions` 와 27개 집합 일치를 확인했다. 시험 이름은 그대로다.

**검증**
- fmt·clippy(-D warnings, 바꾼 13개 crate) 통과. 교차 clippy 는 바꾼 것이 시험·주석뿐이라 돌리지 않았다.
- Go 트리(`internal/`·`cmd/`·`go.mod`·`go.sum`·`web/*.go`)를 잠시 치우고 PATH 에 go 가 있는 상태: `cargo test --workspace --no-fail-fast` 3880 통과·실패 0·무시 2 (FR-GRM-11).
- `npm run unit`: Go 있는 상태로 바꾸기 전과 통과·실패 목록이 같다(1534 중 통과 1524·실패 9·건너뜀 1; 실패 9건 fn-size·TC-DLG-4·e2e-isolate-flaky·e2e-shard-run·FR-FLK-10 은 바꾸기 전부터 있음). Go 트리를 치우면 FR-DFP-2 다섯 건이 더 실패한다 — `scripts/test/daemon-fingerprint.test.mjs` 가 `internal/` 을 센다. R1(G-6) 범위다.
- `DM_GO_REF_SRC` 를 주면 go_parity 둘 통과, edgemesh go_interop(go-ref 로 만든 meshpeer) 통과, `parity/run.sh --go-bin … --self-test` 종료 0.

**남은 위험**: 벡터 파일이 R10 까지 두 벌(internal/·rust/)이다. 그 사이 한쪽만 고치면 Go 시험과 Rust·JS 시험이 다른 표본을 본다.

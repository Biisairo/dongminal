# M11 세 번째 물결 — 착수 프롬프트

**세 번째 물결의 절반이 끝났다** — 접수 열여덟을 닫았다. 남은 **열**은 성격이 다르다:
지금까지가 *자리를 고치는 일*이었다면, 남은 것은 **새 기능**이다 (큐잉·diff·이미지·
자유 답). 그리고 그 앞에 **재는 일**이 있는 것이 넷이다.

**먼저 읽어라: `docs/internal/M11_SRS.md` §2.10** — 실제 claude 를 띄워 잰 화면이
거기 있다. **그것이 명세다.**

## 0-0. **전량 e2e 가 아직 돌지 않았다** — 초록을 전제하지 마라

직전 커밋은 **전량 없이** 올렸다. 사용자 지시다 — *"e2e 하지말고 넘기라고 구현
완료되면 그때 e2e 할꺼라고."* 남은 열을 구현한 **뒤에** 전량을 돌린다.

확인된 것은 여기까지다:

    make gates        ok
    make unit         186 passed
    go build ./...    ok
    agent-tool.spec   부분 실행으로 V-M11-32~51 GREEN (묶음마다 RED 도 확인)

**확인되지 않은 것**: 나머지 일곱 샤드. 이 세션은 `agent-pane.js`·`renderer.js`·
`style.css`·`constants.js`·`i18n` 과 **fakeagent(Go)** 를 건드렸으므로, 다른 스펙이
그 계약에 기대고 있었다면 거기서 떨어진다. **구현을 마치면 가장 먼저 전량을 돌리고,
떨어지는 것을 "계약이 바뀐 것" 으로 읽어라** — 이 세션에서만 아홉 번 그랬다.

## 0. 가장 먼저 — 이 두 줄이 이번 단계의 전부다

**D-M11-3 (사용자 지시):** *"모든 동작을 기존 에이전트와 동일하게 하라는거야. 하나도
안되어있거든. 그러면서 편의성으로 gui 를 만들어둔거야."* · *"실제 에이전트의 사용
패턴, 동작을 그대로 옮겨적으면 돼."*

  종전: 접수마다 갈래를 세우고 각자 고친다
  새로: **원본을 재고**, 그 동작을 명세로 옮기고, 그대로 구현한다

접수 열아홉(B18~B36)을 각각 다른 요구로 읽지 마라. **전부 한 문장이다 — 원본에
있는데 여기 없다.** `SRS §2.10` 이 그 원본을 이미 적어 두었다.

**"편의성" 은 더하는 것이지 대신하는 것이 아니다.** 실제로 그 예가 하나 섰다: 원본은
게이지를 컨텍스트에만 두는데, 사용자가 *"limit 에 추가한건 좋은거같아 진행해"* 로
주기별 게이지를 **유지**하라고 했다 (§2.10 (1) 의 인용).

## 2. 원본을 재는 손 (이 세션이 쓴 그대로)

    dmctl new-tab -n --name "probe"        # -n 이 포커스를 뺏지 않는다
    dmctl send-input --at <uuid> --execute "cd <폴더> && claude"
    dmctl read-screen --at <uuid> --bytes 30000

**주의 셋** (값을 치르고 배웠다):

- **`dmctl send-input` 은 제어키를 보내지 못한다.** bracketed paste 로 감싸므로
  `\033[B`(화살표)·`\017`(ctrl+o)가 **리터럴로 찍힌다**. 화살표·ctrl 조합이 필요한
  실측은 이 손으로 할 수 없다 — 사용자에게 눌러 달라고 하라
- **신뢰 대화상자**는 `~/.claude.json` 의 `projects.<경로>.hasTrustDialogAccepted`
  를 미리 `true` 로 두면 건너뛴다 (백업: `/tmp/claude.json.bak-dmprobe`)
- **`read-screen` 은 공백을 뭉갠다** (TUI 가 커서 이동으로 칸을 건너뛰기 때문).
  구조는 보이지만 정렬은 믿지 마라

## 4. 변하지 않는 규약

- **로컬 전량은 8샤드.** `run_in_background` 는 **세션 경계에서 죽는다 — 세 번 겪었다.**
  반드시 세션에서 떼어내라:

      nohup env PW_WORKERS=1 sh -c 'seq 1 8 | xargs -P 4 -I{} scripts/e2e-shard-run.sh {} 8' \
        > /tmp/dm-e2e.log 2>&1 &

  **샤드 리포트가 부분 완주를 살린다** — 죽어도 `test-results/s<N>/report.json` 에
  남은 샤드는 다시 돌리지 않아도 된다 (소스가 그대로라면)
- **판정은 `unexpected 0`.** flaky 는 **사유로** 가른다 — 상한을 소진하고 재시도에
  즉시 서면 부하성
- **RED 를 실제로 보아라.** `if(1||…) // TEMP-PROBE` 로 고침을 무력화한 뒤 되돌리고
  `grep -c TEMP-PROBE` = 0 을 확인한다
- **§2-2 의 함정**: 맨 위(0)에서 스크롤을 재면 고침 없이도 초록이다. **중간**으로
  올려라. 같은 이유로 "따라감"과 "지킴"을 **둘 다** 재라
- **동작을 바꾸면 기존 검사가 떨어진다 — 같은 변경에서 고쳐라.** 이 세션에서만 아홉
  번 겪었다 (계약이 바뀐 것이지 검사가 틀린 것이 아니다)
- 색·글꼴·z-index 는 **토큰에서** 온다 · 새 문구는 `t('ns.key')` ko·en 둘 다
- 스펙에 `D-…` 를 더하면 `go run ./scripts/gen-decisions`
- 커밋 메시지에 AI 서명 금지
- **운영 인스턴스는 사용자가 `start --foreground` 로 띄운다** — 직접 죽이지 말고 요청하라
- `dmctl` 은 `DONGMINAL_PORT` 를 본다 (`PORT` 가 아니다). 격리로 쏠 때는 `DONGMINAL_HOST`·
  `DONGMINAL_PORT`·`DONGMINAL_HOME` 셋을 박고, 쏜 뒤 운영이 그대로인지 확인하라

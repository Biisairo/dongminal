# 모델 선택

역할별로 어떤 모델을 붙일지만 다룬다. 팀을 **어떤 모양으로 묶을지**는
`patterns.md` 가 단일 출처다 — 같은 내용이 두 곳에 있으면 갈라진다.

**이 스킬은 에이전트에 종속되지 않는다.** `--agent` 가 받는 값은 여럿이고 앞으로 더
늘어난다. 그래서 아래의 본체는 **모델 급(級)** 이며, 구체 모델명은 그 급을 어떤
에이전트에서 어떻게 지목하는지의 **예시**다.

## 본체 — 급으로 고른다

| 급 | 어떤 자리에 | 왜 |
|----|------------|-----|
| **상** | 종합·판정·최종 합의. 여럿의 산출물을 하나로 만드는 자리 | 그 자리가 가장 어렵다. 입력이 서로 어긋날 때 무엇을 버릴지 정해야 한다 |
| **중** | 찾아오는 자리 — 조사·리뷰·중간 합성 | **기본값이다.** 대부분의 역할이 여기다 |
| **경량** | 단순 분류·추출, 보조 비평 | 판단이 아니라 변환에 가까운 일 |

- 한 창 전체를 상급으로 돌리면 **비용·지연이 크다.** 반대로 단순 역할에 경량을 쓰면
  품질이 떨어진다. 역할별로 고르는 이유가 그것이다
- 역할 차이가 크지 않으면 **전원 같은 급으로 두는 것도 정상**이다. 나눠 봐야 관리할
  것만 는다
- **팀장(본인)은 현재 모델을 유지한다** — 스킬이 바꿀 수 없다

이 기준은 세대가 바뀌어도, 에이전트가 바뀌어도 그대로다. 아래 표들은 바뀐다.

## 모델을 지목하는 경로

모델은 기동 시점에 붙는다:

```bash
dmctl run launch --member "$M" --model "$MODEL" | dmctl send-input --at "$T" --execute -
```

**`--model` 이 실제로 전달되는지는 에이전트마다 다르다.** 어댑터가 모델 플래그를
선언한 경우에만 기동줄에 실린다.

| `--agent` | 모델 플래그 | `--model` 을 주면 |
|---|---|---|
| `claude` | `--model` | 기동줄에 실린다 |
| `codex` | **없음** (확인되지 않았다) | **조용히 생략된다** |

> ⚠️ **모델 플래그가 없는 에이전트에서는 `--model` 이 조용히 생략된다.** 오류가 나지
> 않는다 — 조정자는 모델을 지정했다고 믿는데 실제로는 그 에이전트의 기본 모델이
> 돈다. 급을 나눠 배분하는 설계가 그 멤버에서만 무효가 되므로, **모델 지정이 결과에
> 중요한 역할은 모델 플래그가 확인된 에이전트에 준다.**

## `--agent claude` 일 때의 값

아래는 **claude 어댑터에 한정된** 예시다. 다른 에이전트에는 그대로 적용되지 않는다.

| 급 | 별칭 | 모델 | full model ID |
|----|------|------|---------------|
| 상 | `opus` | Opus 5 | `claude-opus-5` |
| 중 | `sonnet` | Sonnet 5 | `claude-sonnet-5` |
| 경량 | `haiku` | Haiku 4.5 | `claude-haiku-4-5-20251001` |
| — | `fable` | Fable 5 | `claude-fable-5` (역할 성격 **확인 필요**) |

`--model` 에 넣는 것은 **별칭**이다. 별칭은 세대가 올라가면 가리키는 모델이 바뀌므로,
특정 모델에 고정해야 하면 full model ID 를 쓴다.

실제 사용 가능한 값은 **그 에이전트의 `--help`** 로 확인한다 (claude 면 `claude --help`)
— 위 표보다 그쪽이 최신이다.

## 에이전트가 늘어나면

`--agent` 가 받는 값의 진실은 **`agentadapter` 레지스트리**다. 새 에이전트를 붙이는
일은 거기에 선언 한 줄을 더하는 것이고, 모델 플래그·프롬프트 주입 방식·종료 지시가
그 선언에 함께 들어간다. 위의 두 표는 그 선언을 사람이 읽게 옮겨 적은 것이므로,
어긋나면 **레지스트리가 맞고 이 문서가 틀린 것**이다.

알 수 없는 `--agent` 값은 명확한 오류로 거부된다 — 기본 에이전트로 조용히
폴백하지 않는다.

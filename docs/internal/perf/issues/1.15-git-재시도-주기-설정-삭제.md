# 1.15 gitStatusInterval·gitReposInterval 설정 삭제

## 목표

M1 이후 두 설정은 주기 조회를 정하지 않고 git 관측 실패 때의 재시도 간격(`git-poll.js` 의 실패 회복 타이머, 탐색기 `editorGitBackoffMs`)에만 쓰인다. 사용자 결정(2026-11-24): 둘 다 지우고 기본값을 이름 있는 상수로 둔다.

- `agentsPollInterval`(dfa74eff)·`gitConsoleInterval`(1.9) 과 같은 방식: 설정 표·Polling 화면·기본값·settings-table·i18n·`RETIRED_KEYS`·otterctl 골든·settingsschema 시험·프론트 시험·e2e(poll-interval.spec.ts 등, `scopedSettings({gitReposInterval|gitStatusInterval: …})` 를 쓰는 스펙은 재시도 간격을 시험용으로 줄이던 것이면 다른 주입 방법을 찾거나 상수를 쓴다).
- 백오프·주기 0·잠금 계약(event-timer-hub-contract T-5~11)은 그대로 잰다.

## 완료 조건

- 시험 먼저(RED). settingsschema·ctl-cli 시험, 관련 node 시험, 바꾼 e2e 스펙만, check-settings-docs 등 관련 게이트. 전체 시험 금지. 동작 변경은 이전/새/이유.

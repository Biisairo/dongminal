# 2.10 M2 전체 시험·재측정·문서 정합

## 목표

Rust workspace 전체 시험과 e2e 전량을 M2 끝에서 한 번만 돌린다(사용자 지시). `scripts/perf/scenario.mjs` 로 NFR-PRF-6·7·8·9·10·14 를 재고 SRS §7 에 M2 표를 더한다. `CHANNEL_PROTOCOL.md` 에 M2 프레임(`SEQ` 의 `SNAP` 깃발, `term.history`)을 더하고, 하위 이슈의 "코드와 어긋난 문서" 목록을 모아 사용자에게 묻는다.

## 완료 조건

- 전체 시험 통과(실패는 하위 이슈로 나눈다). 측정 표가 SRS §7 에 있다.
- 문서 정합 목록을 사용자에게 물었다.
- 바꾼 부분의 시험(단위·관련 e2e 한두 개)·fmt·clippy·관련 게이트 통과. 이 이슈가 마일스톤 끝의 전체 시험 1회다.
- 시험을 먼저 쓰고 RED 를 확인한 뒤 구현한다.
- 동작을 바꿨으면 이전 동작 / 새 동작 / 이유를 진행 기록과 커밋 메시지에 적는다.

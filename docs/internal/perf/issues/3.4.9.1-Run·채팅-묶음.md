# 3.4.9.1 Run·채팅 묶음

3.4.9 에서 나눴다. 설정·간선은 3.4.9.2 다. 브랜치는 3.4.9 의 것(`pf/3.4.9`)을 그대로 쓴다.

## 목표

- Run 탭의 뷰(`run-dashboard`·`run-tree`·그래프·복구, `style-runs.css` 의 뷰 부분)를 `run` 묶음으로.
- 채팅 탭의 뷰(`chat-views.js`)를 `chat` 묶음으로. 목록·저장소·사람 동작·채팅 창은 부팅에 남는다.

## 완료 조건

- RED e2e: 부팅 때 `b/run.js`·`b/chat.js` 요청이 없다 → 각각 처음 열 때 실리고 그려진다. 부팅 때 복원된 Run 탭은 바로 싣는다(D-31).
- 게이트 통과, 프론트 단위 전체. 전체 e2e 금지.

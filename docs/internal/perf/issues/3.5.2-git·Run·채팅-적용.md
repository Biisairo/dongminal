# 3.5.2 생명주기 적용 — git·Run·채팅

## 목표

- `git:<root>`·`gitconsole:<root>`·`run:<id>` 구독과 화면 타이머를 `awake` 로 옮긴다. git 의 `pollOkAny` 판정을 생명주기 신호로 바꾼다.
- 깰 때 토픽 재구독으로 최신 값을 받고 한 번 그린다(FR-CON-4).

## 완료 조건

- RED e2e: git 창을 열었다가 다른 탭으로 바꾸고 2초 뒤 그 패널 주인의 타이머 0, 채널의 `git:<root>` 구독 0(다른 칸에서 보지 않을 때). 다시 열면 상태가 서버와 같다. Run 화면도 같은 꼴 하나.
- 전체 시험 금지.
- 동작을 바꿨으면 이전 동작 / 새 동작 / 이유를 진행 기록과 커밋 메시지에 적는다.

**동작 변경**

- 이전: 창의 어느 pane 에든 git 탭이 있으면, 다른 탭 뒤에 가려져도 패널이 관측기의 `git:<root>` 구독과 회복 주기를 쥐었고 mark 가 오면 수집했다. 가려진 Run 탭은 `run:<id>` 를 쥐고 바뀔 때마다 `/graph` 를 다시 받아 그렸다. 가려진 채팅 탭은 방이 바뀔 때마다 다시 그렸다.
- 새: 가려지고 2초 뒤 잠들면 놓는다. 다시 보이면 다시 구독해 최신을 받고 한 번 그린다. Repo 창 사이드가 Changes 이면 git 패널은 사이드 표면으로 계속 관측한다.
- 이유: FR-SPA-3·D-36.

**완료 조건과 다른 점 (조정자 판단 필요)**

- 이슈의 "채널의 `git:<root>` 구독 0" 은 Repo 창 안에서는 닿지 않는다. Repo 창의 사이드는 Changes 나 Explorer 둘 중 하나이고, 둘 다 `git:<root>` 를 본다(Changes = git 패널, Explorer = 탐색기의 git 색 `editor-pane.js` `_edGitWatchSync`). 그래서 e2e 는 패널 쪽의 것을 잰다: 관측기의 구독(`_topicRoot` 가 빈다), 패널의 타이머 0(`sleepers()`), 콘솔의 `gitconsole:<root>` 0, 잠든 동안 수집 없음 → 깨면 HEAD 가 서버와 같다. 채널 토픽 자체가 0 이 되는 것은 Repo 창이 가려질 때(창 전환)이며, 이것은 전부터 그랬다.

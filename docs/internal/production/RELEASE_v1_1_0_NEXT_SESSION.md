## 2. 이 판이 무엇인가

`v1.0.12`(2026-09-08) 이후 8일치다 — M9~M12 와 이번 세션의 정리가 함께 나간다.

기본 기동과 서비스 등록은 해당하지 않는다.

## 3. 값을 치르고 안 것 — 다시 치르지 마라

### 흔들림(flaky)은 이제 실패가 아니다

`CI_GATES_SRS §3.1` 이 2026-09-16 에 개정됐다. 이 조항은 **두 번 뒤집혔고 두 번 다
근거가 있었다.** 지금 남은 흔들림은 CI 에서만, 매 회차 다른 항목이 뜬다 — 로컬
전량은 두 회차 연속 0 이었다. 재현할 길이 CI 왕복뿐인 것을 실패로 올리면 게이트가
"무엇이 깨졌는가" 를 말하지 못한다.

**되뒤집을 조건이 그 절에 적혀 있다**: 같은 항목이 회차를 건너 되풀이되거나 로컬
전량에서 재현되면 그것은 부하가 아니라 결함이다. `DM_E2E_STRICT_FLAKY=1` 이 옛
판정을 그 자리에서 되살린다.

### 로컬 전량은 리포터 옵션 없이 돌린다

`npx playwright test --reporter=line` 은 설정의 리포터를 **대체한다.** 그러면
`parity-reporter` 가 아예 돌지 않아 CI 와 다른 게이트를 재게 된다. 진행 표시가
없는 것이 정상이다 — 설정 리포터(`html`+`parity`)는 끝에 한 번 찍는다.

### 재려는 사실을 대리로 재지 마라

이번 세션에서 **네 번** 같은 부류를 만났다. 대리는 다른 이유로도 움직인다.

| 검사 | 재려던 것 | 대리로 쟀던 것 |
|---|---|---|
| `tool-list-unknown` TC-TLU-9·10 | 인스턴스가 파괴됐는가 | 소켓이 갈렸는가 |
| `TestCreate_CommandIsTheProcess` | 샌드박스로 오인했는가 | `SetBackground` 가 참인가 |
| `term_resume` NoDuplicate | 중복이 왔는가 | 아무것도 안 왔는가 |
| `term-reclaim` TC-M10-2 | 새 폭의 줄이 있는가 | 첫 줄의 길이 |

### 판 의존을 호스트 규약으로 판정하지 마라

`filepath.IsAbs`·`filepath.Join` 은 **호스트** 규약을 쓴다. 제공자 검사는 가짜
env 로 어느 판에서나 도므로, POSIX 호스트가 `C:\...` 를 상대경로로 읽고 Windows
호스트가 `/home/...` 를 그렇게 읽는다. **양방향으로 한 번씩 데었다.**

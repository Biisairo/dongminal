# UI/UX 진단 — unslop (2026-11-19)

> 고치지 않고 찾기만 한 결과입니다. 항목마다 관측과 제안을 적었고, 받아들일지는 사용자가 정합니다.
> 이미 정한 사용자 결정(하단 탭 내비 없음 D-2, 칸 스와이프 없음 D-5, 패널 템플릿 PANEL_TEMPLATE_SRS)과 부딪히는 제안은 넣지 않았습니다.

## 0. 진단 방법

- 격리 인스턴스(`DONGMINAL_HOME=/tmp/dm-mobile/home`, 포트 61990), 이 저장소를 Repo 창으로 열었습니다
- 데스크톱 1440×900과 모바일 412×839(터치)에서 같은 12개 화면을 찍었습니다: 홈, 서랍, Activity, 설정(목록·상세), Repo(Changes·Explorer·편집기·diff), 메뉴, 토스트
- 화면 전체의 계산값 분포(글자 크기·굵기·모서리·단추 높이·행 높이)를 쟀습니다
- 기준은 unslop의 신호 목록과, 앞서 확인받은 방향입니다(조용함·정확함·손에 맞음 / 야간 관제실의 계기판 / 시그니처는 살아 있는 상태 점)

**전체 판정: 가벼운 슬롭입니다.** 보라색 그라데이션·글로·이모지 같은 큰 신호는 없습니다. 대신 **말·밀도·위계의 일관성**과 **제품다움(시그니처)** 쪽에 개선 여지가 많습니다.

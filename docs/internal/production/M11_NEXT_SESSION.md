## 1. 남은 접수 여섯 (M11-B10~B15) — 이 순서로

근거와 갈래는 `docs/internal/M11_SRS.md` **§2.8** 에 표로 있다.

| 순서 | ID | 접수 (원문) |
|---|---|---|
| ① | **B13** | *"첫 메세지를 보내기전에는 기본값 설정하고 이후 맞추면 되잖아. 없애지 말고 모르는걸로 해서 보여줘"* |
| ② | **B12** | *"하단 내용의 크기를 그리고 좀 키워줘 너무 작아"* |
| ③ | **B14** | *"gui 에서 다른곳에 다녀오면 스크롤이 최상단으로 이동해. 유지해야해"* |
| ④ | **B10** | *"'에이전트로'버튼이 새로고침하면 사라졌다가 다음 이벤트가 있을때 다시 버튼이 뜨네"* |
| ⑤ | **B11** | *"여전히 /model, /config 같은 tui 들은 사용이 불가"* |
| ⑥ | **B15** | *"프롬프트를 연달아 보낼때의 동작도 실제와 달라"* |

①②③ 은 자리가 분명하고 서로 붙어 있다(`web/js/ui/agent-pane.js` · `web/style.css`).
④ 는 **재현이 이미 서 있다**. ⑤⑥ 은 "실제와 다르다" 가 무엇인지 **먼저 재야 한다**.

### ① B13 — 결정 번복이다. 조심해서 읽어라

앞선 인터뷰에서 사용자는 *"있는 것만 더 그린다"* 를 골랐고, 그 근거로
`FR-M9-40`(모르면 그리지 않는다)을 지켰다. **이번 지시는 정반대다.**

자리는 **항상** 서고, 값이 없으면 **"모름"** 으로 말한다. 이것은 `FR-CBG-5`(모른다 ≠ 0)를
어기지 않는다 — 0 으로 채우는 것이 아니라 모름을 모름이라고 적는 것이다. 오히려
빈 자리를 `:empty` 로 지우던 종전 동작이 *"그런 항목이 없다"* 로 읽힌 것이 접수다.

**손댈 자리**: `agent-pane.js` 의 `_setUsage`·`_renderLimits`·`_setModel`·`_setPerm`·
`_setAccount` 가 값이 없으면 빈 문자열을 쓴다. `web/style.css` 의
`.agp-dash>span:empty{display:none}` 이 그것을 지운다.

**닫을 수 없는 것을 기억하라** (`M11_SRS` §2.5 의 실측): `initialize` 응답에 비용·
토큰·한도의 수가 **아예 없다**. 그 수는 턴의 결과 프레임에만 온다. 그러므로 B13 은
"값을 구해 오는 일" 이 아니라 **"모름을 말하는 일"** 이다.

### ② B12 — `agp-dash` 의 글꼴

`style.css` 의 `.agp-dash` 는 `--fs-xs` 계열이다. 크기는 **토큰에서** 온다
(`font-size` 게이트가 리터럴을 잡는다 — `make gates` 가 말해 준다).

### ③ B14 — GUI 스크롤 복원

`agp-log` 의 스크롤 위치가 탭 전환으로 살아남지 않는다. **터미널 쪽에는 이미 같은
규약이 있다** — `renderer.js` 의 `_moved`·`_termScrollOf` 가 "떼기 전에 잰 것을 쓴다"
(FR-M9-28). 새 관용구를 만들지 말고 **그 손을 보고 따라가라.**

### ④ B10 — 재현이 이미 서 있다

`e2e/lift-button-reload.spec.ts` 의 **V-M11-30 이 `test.fixme` 다.**
`fixme` 를 지우는 것이 첫 걸음이고, 그때 빨갛게 떨어지는 것이 고칠 대상이다.
(V-M11-31 은 "올릴 수 없는 도구에는 서지 않는다" 를 지키는 짝이며 지금 초록이다.)

원인의 후보는 적어 두었다 — 진입점을 묻는 계기가 `renderer.js` 의 **이동**(`moved`)과
`app-agents.js` 의 **활동 신호** 둘뿐이고, 새로 뜬 화면에는 둘 다 없다. 첫 마운트에
`term` 이 아직 없어 그 호출이 건너뛰어지는지는 **확인하지 않았다.**

### ⑤ B11 — 먼저 재라

`/model`·`/config` 는 프로토콜에서 어떤 응답을 주는가? `initialize` 응답의 `commands`
목록에는 들어 있다(실측 — §2.5 의 표). 그러나 그 답이 **대화가 아니라 화면**이면
우리 뷰에는 그릴 자리가 없다.

**재는 손**: 임시 프로브로 그 명령의 응답 원문을 한 번 찍어라 (§3-4 의 방법과 같다).
되돌린 뒤 `grep -c TEMP-PROBE` 로 0 을 확인하는 것을 잊지 마라.

### ⑥ B15 — 먼저 재라

TUI 는 프롬프트를 연달아 치면 **큐에 쌓아 순서대로** 처리한다. GUI 가 무엇을 하는지
아직 재지 않았다. `agent-pane.js` 의 `send()` 와 서버의 `agentsess` 큐를 함께 봐야
한다. **무엇이 다른지 적기 전에는 고치지 마라.**

## 2. 이 세션이 값을 치르고 배운 것 — 같은 값을 다시 치르지 마라

### 2-1. `dmctl` 은 `DONGMINAL_PORT` 를 본다 — `PORT` 가 아니다

**이 세션이 여기서 사고를 냈다.** 격리 인스턴스를 띄워 놓고 `PORT=39447` 로 dmctl 을
불렀는데 그 이름은 무시되고 **기본 포트(58146 = 운영)** 로 붙었다. 결과:

- 운영 워크스페이스에 창이 **9개** 생겼다 (`alpha`·`beta`·`Window`×7)
- `focus`·`window-next`·`close-window --force` 가 **사용자의 브라우저 셋에** 나갔다
- 사용자가 접수한 *"화면이 막 맘대로 바껴"* 의 상당 부분이 그것이다

격리 인스턴스에 쏠 때는 **반드시** 이렇게 한다:

    DONGMINAL_HOST=127.0.0.1 DONGMINAL_PORT=<포트> DONGMINAL_HOME=<홈> <홈>/bin/dmctl …

그리고 쏜 뒤 `curl -s http://127.0.0.1:58146/api/state` 로 **운영이 그대로인지** 확인하라.

### 2-2. 검사가 고침 없이도 통과하면 **재는 대상이 틀린 것**이다 — 두 번 겪었다

- **V-M11-7**(색): `border-left-color` 가 1px 테두리 색으로 이미 달라서 초록이었다.
  띄의 **굵기**와 **도구 카드와의 구별**로 바꾸니 RED 가 섰다
- **V-M11-26·27**(시선): 폴백이 우연히 제자리로 떨어져 초록이었다. **아무도 보고
  있지 않은 셋째 창**을 닫게 바꾸니 판정이 갈렸다

**RED 는 조각마다 따로 확인하라.** `git stash push <파일 하나>` 로 물리면 어느 조각이
어느 검사를 초록으로 만드는지 갈린다 — FR-M11-10·11 에서 실제로 그렇게 갈랐다.

### 2-3. 재현하지 못한 것을 "없다" 로 접지 말고 **무력화로 갈라라**

M11-B1(렌더 잔재)은 여섯 배치에서 한 번도 나지 않았다. 거기서 멈추면 결론이
*"못 찾았다"* 뿐이다. **고침 하나만 무력화**하니(`_refreshForWidth` → `return false`)
잔재가 났고, 대조군은 깨끗했다. 그때서야 물음이 *"무엇이 잔재를 만드나"* 에서
**"그 재생이 언제 안 걸리나"** 로 바뀌었다.

**순서가 요점이다.** 자연 경로부터 찾았으면 그 갈래를 떠올리지 못했다.

### 2-4. 겉모습이 맞는 재현을 근거로 세울 뻔했다 — `_seq` 한 칸이 막았다

서버만 재시작하고 그 틈에 폭을 바꾸니 증상도 조건도 맞아 보였다. 그런데 `_seq` 가
그대로였다 — **고치려는 코드를 지나가지도 않은 경로**였다.

**재현의 겉모습이 아니라 그 경로가 고치려는 코드를 지났는지 확인하라.**

### 2-5. 고침 하나가 반대편을 드러낸다 — 셋이 연쇄였다

    FR-M11-7  신원을 보내게 했다   → 그래도 안 떴다
    FR-M11-8  같은 요청에 실었다    → 떴다. 그런데 **꺼도 안 사라졌다**
    FR-M11-9  끝남을 표시했다       → 강제 종료엔 안 걸렸다
    FR-M11-12 전경도 함께 본다      → 닫혔다

**하나를 고치면 그 자리를 다시 재라.** 이 세션은 매번 운영에서 다시 재어 다음 갈래를
찾았고, 재지 않았으면 셋 다 놓쳤다.

### 2-6. 규약은 대개 **이미 있고 한 자리가 안 쓴다**

- 스크롤(B4): `.ui-scroll` 이 `style-kit.css` 에 있었고 GUI 만 안 썼다
- 접기(B6): `agp-raw` 가 이미 `details` 를 쓴다
- 모델 사다리(FR-M11-6): `recordLocked` 가 이미 `opts` 로 떨어진다
- 복원(FR-M11-11): 공통 경로에 있었고 `force` 갈래만 안 지났다

**고치기 전에 같은 일을 하는 자리를 먼저 찾아라.** 새로 만들면 두 벌이 되고, 두 벌은
한쪽만 고쳐진다.

### 2-7. 동작을 바꾸면 **기존 검사가 떨어진다** — 같은 변경에서 고쳐라

이번에 세 번 겪었다: `TC-AGT-9`(도구 카드가 접힘) · `TestCommandPost_NoExecutorFor…`
(지명 목록이 넓어짐) · `TestApiAgentSessionOf`(전경 판정이 더해짐). 셋 다 **계약이
바뀐 것**이지 검사가 틀린 것이 아니므로, 새 계약으로 고치고 **반대 방향을 지키는 짝**을
함께 세웠다.

## 3. 실측 방법 (이 세션이 쓴 것)

- **버퍼인가 렌더인가**: `term.buffer.active` 의 줄과 `.xterm-rows` 의 DOM 텍스트를
  한 번에 비교한다. 여덟 배치 전부 일치 → 렌더 갈래를 지웠다
- **TUI 가 칸을 건너뛰는가**: `dmctl read-output --at <탭> --bytes 400000 | cat -v` 에
  `^[[2C`·`^[[19G` 가 보이면 그렇다. `grep -c '1049'` 로 대체 화면 여부도 같은 바이트에서
- **소켓 없는 구간 만들기**: `dongminal stop --port <n> --home <홈>` (`--all` 없이 —
  dongminald 와 세션은 산다)
- **프로토콜 원문 보기**: 임시 `dmlog.Infof(… "TEMP-PROBE …")` → 실행 → `git checkout`
  → `grep -c TEMP-PROBE` = 0 확인
- **두 브라우저 실측**: Playwright `browser.newContext()` 둘. `clientId` 가 격리되어
  크로스 기기와 동등하다

## 4. 변하지 않는 규약

- **로컬 전량은 `make e2e`.** `E2E_JOBS × E2E_WORKERS ≤ ⌈코어/3⌉` — 이 기계는 상한 4,
  기본 `4 × 1`. 벽시계 13~17분. **`run_in_background` 로 띄워라** (`pgrep` 폴링 루프는
  자기 패턴에 걸려 다음 실행을 `BUSY` 로 막는다)
- **판정은 `unexpected 0`** (D-M9-11). flaky 는 `test-results/s<N>/report.json` 을 읽고
  **사유로** 가른다 (D-M10-7) — 상한만큼 걸렸다 재시도에 즉시 서면 부하성
- **전량이 도는 동안 제품 소스를 건드리지 마라 — Go 도 포함.** 문서는 된다
- **`make e2e-rebalance` 는 전량 직후다**
- **RED 를 실제로 보아라.** `git stash push <파일>` → 실행 → `stash pop`(잊으면 커밋에서
  조용히 빠진다). 프로브(`if(1) return; // TEMP-PROBE`)는 **조각을 가를 때** 쓴다
- **상태를 올릴 때 근거를 그 자리에 적고, 검증 갭은 갭으로 적어라** (D-M10-5)
- 새 문구는 `t('ns.key')` — ko·en 둘 다. CSS `content` 에 문구를 두면 i18n 게이트가 잡는다
- 색·글꼴·z-index 는 **토큰에서** 온다 — 리터럴 금지 (`make gates`)
- 스펙에 `D-…` 를 더하면 `go run ./scripts/gen-decisions`
- 커밋 메시지에 AI 서명 금지
- **운영 인스턴스는 사용자가 `start --foreground` 로 띄운다.** 재시작이 필요하면
  직접 죽이지 말고 **요청**하라

## 5. 사용자 결정 (유효)

- **(B13, 번복)** 하단은 **자리를 항상 세우고 모름을 모름으로 보인다.** 앞선
  *"있는 것만 더 그린다"* 를 대체한다
- **(M11-B2)** 전환하면 반대쪽은 **닫힌다.** 다만 죽는 것은 **에이전트**이고 터미널
  **탭**은 남는다 (거기에는 사용자의 셸이 산다 — D-M9-20)
- **(M11-B1)** 렌더 잔재는 **재현 추적을 잇는다.** 진단만 심고 기다리는 길은 고르지
  않았다. **아직 닫히지 않았다** — FR-M11-1 은 잔재를 만들 수 있는 홀 하나를 닫았을 뿐
- (D-M9-1 · 결정 9) **인증은 하지 않는다**
- (D-M10-8) 인수인계는 **`/dongminal:migration` 명령**이다
- 출력에 이모티콘을 쓰지 않는다
- 자격증명이 없으면 무모델까지만 실측 — 사용자에게 자격증명을 묻지 않는다

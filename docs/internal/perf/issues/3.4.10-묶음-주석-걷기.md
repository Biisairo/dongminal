# 3.4.10 묶음의 주석 걷기 (조건부, D-35)

## 목표

- 3.4.6~9 뒤 3.4.1 의 지표로 다시 재서 부팅 JS 가 1.5 MB 를 넘을 때만 한다. 넘지 않으면 이유와 숫자를 적고 done 으로 닫는다.
- 서버 묶음에서 주석을 걷는다. 줄바꿈은 남겨 줄 번호(소스맵)를 지킨다. 정규식 리터럴·템플릿 문자열 안의 `//`·`/*` 는 건드리지 않는다.

## 완료 조건

- RED: 묶음마다 걷은 묶음과 원본 이음의 토큰 열(espree)이 같다(e2e 또는 서버를 띄우는 node 시험). 정규식·템플릿·문자열 안의 주석 모양 고정 예제.
- 부팅 JS 1.5 MB 이하. 전체 시험 금지.
- 동작을 바꿨으면 이전 동작 / 새 동작 / 이유를 진행 기록과 커밋 메시지에 적는다.

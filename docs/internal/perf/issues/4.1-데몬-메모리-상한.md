# 4.1 데몬 메모리 상한 (NFR-PRF-10)

## 배경 (2026-11-25 분석, 조정자 위임 에이전트)

- NFR-PRF-10(`PERF_OPTIMIZATION_SRS.md:179`, 터미널당 평균 8 MB 이하, 이후 증가 없음) **위반**. 120×40, 5만 줄 포화 뒤 도구당 측정용 짧은 줄 약 8.6 MB, 코드 120자·색 6구간 약 11.1 MB, 한글 120자 약 14 MB.
- 주원인: alacritty 그리드가 기록 저장 공간을 1,000행 단위(`MAX_CACHE_SIZE`, `alacritty_terminal-0.26.0/src/grid/storage.rs:13,107-113,126-137`)로 늘리고 줄일 때도 1,000행을 여분으로 남긴다. `EMU_KEEP` 1,000(`termstate/src/emu.rs:100`, 상한 keep+2×256+rows = `:120-122`)이라 실제 저장 공간은 화면+2,000행 = 120열에서 6.27 MB(행당 malloc 3,072 B).
- 누수 아님: 도구를 닫으면 살아 있는 힙 128.4 → 21.0 MB. RSS 가 남는 것은 macOS malloc 지연 반납(footprint 47 MB).
- 줄 저장소 줄당 크기(deflate 뒤): 짧은 줄 약 24 B, 코드 120자·색 6구간 약 73 B(실측), 한글 120자 약 131 B.
- 원본: `/private/tmp/pfmem-*`(측정 로그·heap·vmmap), 스크립트 `/private/tmp/pfmem-scripts/`. 측정 방법: 격리 인스턴스, 탭 16개, agent-sim 60줄 12개, 30초 RSS 샘플, 닫은 뒤 `heap`·`vmmap`.

## 목표 (사용자 결정 2026-11-25: A·B·E)

- **A** 에뮬레이터 기록 상한(keep + slack)을 alacritty 저장 공간 한 단위(화면 + 1,000행) 안에 들게 낮춘다(예: keep ≤ 448 — 정확한 값과 넓은 줄 걸침 조건(SLACK)은 설계에서 정한다). 기대: 도구당 약 −3.1 MB.
- **B** 출력이 **5분** 없는 도구는 에뮬레이터 기록을 모두 줄 저장소로 옮기고 그리드 저장 공간을 줄인다(`update_history(0)` → shrink, `storage.rs:111`). 다시 출력이 오면 평소대로 잡는다. 스냅숏·검색·위로 받기·인계(handover)가 옮긴 뒤에도 같은 결과를 내야 한다. 기대: 조용한 도구당 약 −6 MB.
- **E** `termHistoryLines` 기본값 50,000 → **20,000**(범위 1,000~200,000 그대로). 이미 저장된 사용자 설정값은 바꾸지 않는다. D-7·D-25 개정.

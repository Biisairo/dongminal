설계와 다르게 한 것
- `.git`·common_dir 를 따로 감시하지 않았다. 워크트리 root 를 재귀로 보므로 일반 저장소의 `.git` 은 그 안이다. 다만 `.git` 아래 사건은 kick 이 원래대로 거른다 — `git status` 가 `.git/index` 를 고쳐 다시 kick 하는 되먹임을 막고, signature 회차(1초, git 실행 없음)가 `.git`·common_dir 의 변화를 이미 본다. linked worktree 의 common_dir 도 signature 가 읽는다.
- macOS FSEvents 를 notify 로 쓰지 못했다: workspace 의 notify 9 는 `macos_kqueue` 기능이 켜지면(fswatch 가 화면 감시용으로 켬) `FsEventWatcher` 를 빼므로 한 빌드에 둘이 설 수 없다. 새 crate 를 들이지 않으려고(DEPENDENCIES.md) CoreServices·CoreFoundation·libdispatch 를 `extern "C"` 로 직접 불렀다(unsafe FFI 약 120줄).

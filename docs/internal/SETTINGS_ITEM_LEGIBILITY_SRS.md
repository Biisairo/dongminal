# SRS: 설정 항목은 덩어리로 읽힌다 — IEEE 29148

> **문서 상태**: 승인·구현완료

## 1. 개요 (Introduction)

### 1.1 목적 (Purpose)

접수한 말은 한 줄이다.

> **"setting 창에 탭 내에서 각각 항목에 대한 구분이 힘듬. 가시성 ui 개선 필요."**

### 1.2 범위 (Scope)

**포함**

| 묶음 | 내용 |
|---|---|
| **I** 항목 블록 | 이름·컨트롤(`.ds-row`)과 그 설명(`.ds-hint`)이 **한 덩어리**로 보인다 |
| **S** 그룹 소제목 | 관련 항목을 소제목(`.ds-sec`)으로 묶는다 |

**미포함:** §6.

### 1.3 정의 (Definitions)

| 용어 | 정의 |
|------|------|

| **그룹** | 같은 대상을 다루는 항목 몇. 화면에서는 `.ds-sec` 소제목 아래의 연속 |

## 2. 현재 상태 (조사로 확정한 사실)

### 2.1 모든 경계가 같은 굵기다

`.ds-row` 는 저마다 `border-bottom:1px solid var(--border)` 를 달고, 컨테이너
`.display-settings` 는 `gap:10px` 로 **모두를 똑같이** 벌린다. 그래서 화면에는
굵기가 같은 가로선이 일정 간격으로 늘어선다 — **항목 사이와 그룹 사이가 구별되지
않는다.**

### 2.2 설명이 자기 항목에 붙어 있지 않다

`.ds-hint` 는 `.ds-row` 의 **형제**이고 그 사이에도 같은 `gap:10px` 이 선다.
설명은 위 항목의 것인데 아래 항목과 **같은 거리**에 있다. 실측: `.ds-row` 38개 ·
`.ds-hint` 33개 — 대부분의 행이 설명을 달고 있으므로 이 모호함이 화면 전체에 깔린다.

### 2.3 묶는 수단이 구분선뿐이다

`.ds-sec` 같은 소제목은 없고 `.ds-sep`(가로선)만 있다. 선은 **가르기만 하고 이름을
주지 않으므로**, 나뉜 두 덩어리가 각각 무엇인지는 항목을 읽어야 안다.

## 3. 요구사항 (Requirements)

### 3.1 항목 블록 (묶음 I)

**FR-SIL-1.** 한 항목은 **왼쪽 세로선 하나를 공유한다.** `.ds-row` 와 그 뒤의
`.ds-hint` 가 같은 `border-left` 와 같은 들여쓰기를 갖는다.

**FR-SIL-2.** `.ds-row` 의 `border-bottom` 을 **걷는다.** 항목의 경계는 세로선과
여백이 말하고, 가로선은 그룹에만 남긴다 (§2.1).

**FR-SIL-3.** 한 항목 **안**(`.ds-row` ↔ 그 뒤 `.ds-hint`)은 붙이고, 항목 **사이**는
컨테이너의 `gap` 이 가른다. 판정은 인접 선택자 `.ds-row + .ds-hint` 다 — 앞에
`.ds-row` 가 없는 `.ds-hint`(패널 전체를 설명하는 자리)는 종전대로 둔다.

### 3.2 그룹 소제목 (묶음 S)

**FR-SIL-4.** `.ds-sec` 이 그룹의 이름을 준다. 문구는 i18n 카탈로그에서 오며
(`html.dssec_*`), 한글 리터럴을 마크업에 적지 않는다 (`i18n` 게이트).

**FR-SIL-5.** 소제목은 **항목이 많아 덩어리가 필요한 탭**에 둔다. 모든 탭에 억지로
넣지 않는다 — 항목이 둘셋인 탭에서는 소제목이 내용보다 많아진다.

### 3.3 공통 (묶음 C)

**FR-SIL-6.** 적용 범위는 `.display-settings` 아래 **전부**다. 탭마다 다른 규칙을
두면 같은 화면 안에서 항목의 모양이 갈린다.

**FR-SIL-7.** 색과 크기는 토큰에서 온다 — `hardcoded-color`·`font-size` 게이트가
그것을 지킨다.

## 4. 결정 (Decisions)

| # | 결정 | 근거 |
|---|---|---|
| **D-1** | 항목을 **세로선**으로 묶는다 (테두리 상자가 아니라) | 상자는 38개가 늘어서면 화면이 격자가 된다. 세로선은 **시작과 끝만** 말하므로 밀도를 올리지 않는다 |
| **D-2** | 마크업을 **감싸지 않는다** — 래퍼 `<div>` 를 넣지 않는다 | 38행을 감싸면 `aria-labelledby` 를 구조에서 파생하는 `_settingsA11y`(FR-A11Y-13)의 전제(`.ds-row` 의 첫 자식이 이름)가 흔들린다. 인접 선택자로 같은 결과를 얻는다 |
| **D-3** | 소제목은 **탭을 골라** 넣는다 (FR-SIL-5) | 전 탭 일괄은 항목 둘인 탭에 이름만 늘린다. CSS 는 전역이므로 소제목이 없는 탭도 §2.1·2.2 는 해소된다 |

| V-SIL-3 | e2e | row 와 그 뒤 hint 의 **왼쪽 경계 x 가 같다** — 세로선이 이어진다 | 1 |

## 7. 리스크 (Risks)

| 리스크 | 등급 | 완화 |
|---|---|---|
| 들여쓰기가 늘어 좁은 폭에서 컨트롤이 밀린다 | **LOW** | 왼쪽에 더하는 것은 `10px` 하나다. `.ds-row` 는 이미 라벨을 줄바꿈으로 받는다 (FR-UIK-14) |
| 세로선이 테마 54종에서 안 보이거나 너무 튄다 | **LOW** | 색은 `--border` 로, 이미 같은 자리에 쓰이던 값이다 — 새 색을 만들지 않는다 |
| 소제목이 없는 탭과 있는 탭의 인상이 갈린다 | **MEDIUM** | D-3 이 고른 결과다. 항목 블록(CSS)은 전역이므로 **덩어리로 읽히는 것은 모든 탭이 같다** |

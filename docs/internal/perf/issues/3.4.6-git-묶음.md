# 3.4.6 git 묶음

## 목표

- `js/git/*` 화면 코드, `constants-git*.js`(이름 그대로 묶음 맨 앞, D-32), `style-git*.css` 를 `git` 묶음으로 옮긴다.
- 진입점(렌더러 git 탭, git 창 열기, git 모달·메뉴·단축키)에 `Screens.load('git')`. 부팅 목록 패널이 쓰는 git 코드는 부팅에 남긴다(게이트가 알려 준다).
- 처음 여는 지연을 로컬·remote 로 잰다(D-31 재검토 근거).

## 완료 조건

- RED e2e: 부팅 때 `b/git.js` 요청이 없다 → git 창을 열면 실리고 그려진다. 부팅 때 복원된 git 탭은 자리표시 뒤 그려진다.
- `check-lazy-boundary`·`check-load-order` 통과, 관련 git e2e 한두 개. 전체 시험 금지.
- 동작을 바꿨으면 이전 동작 / 새 동작 / 이유를 진행 기록과 커밋 메시지에 적는다.

**바꾼 것**

- `web/bundles.txt` 에 `[git]` 을 더했다. 상수 일곱(`constants-git-changes·commit·diff·history·refs·remote·actions`)이 맨 앞이고, 그 뒤가 `js/git/*` 54개, CSS 넷(`style-git*.css`)이다. index.html 의 `style-git*.css` 링크 넷을 지웠다.
- 부팅에 남긴 것(게이트가 가리킨 부팅 의존):
  - `js/git/api.js`(gitFetch·gitPost)와 `js/git/status-hub.js` — Repo 목록·탐색기 색·편집기 변경 표시가 쓴다.
  - `constants-git.js`(골격)와 `constants-git-detect.js`(작고 반이 부팅에서 쓰인다).
  - 부팅 코드가 읽는 상수 19개는 `constants-git-changes·actions` 에서 `constants-git.js` 끝으로 옮겼다(이름·값 그대로, D-32). 목록: GIT_GROUP_SRC, GIT_AXIS, GIT_ERR_NOT_REPO, GIT_ERR_GIT_MISSING, GIT_RMS_PIN_REASON, GIT_TREE_INDENT, GIT_TREE_PAD0, GIT_ST_CLASS, GIT_SUB_* 넷, GIT_WRITE_ERR, GIT_HEAD_TAB_SUFFIX, GIT_PATCH_STAGE·UNSTAGE·REVERT.
- 등록: `git-controller.js` 끝 `Screens.register('git',{css:true,tab:(at)=>at.type===TAB_TYPE_GIT})`.
- 진입점:
  - 렌더러 git 탭 본문은 3.4.3 의 자리표시를 그대로 쓴다. Repo 창 Changes 사이드는 `_screenHold(name,key)`(`_screenWait` 에서 갈라 냄)로 자리표시를 두고, 기다리는 동안 진입점 줄(History 등 여섯)을 두지 않는다.
  - `openGitWindow`·편집기 `+ Add`(`_edAdd`)·탐색기 행 메뉴(`_onCtx`, `GitMenu`)·업로드 실패 대화상자(`_askUploadFailure`)는 `await Screens.load('git')`.
  - `gitPanelAt`·`gitObs`·`gitDiffPanelFor` 는 실리기 전 null. `lazy-entries.txt` 에 셋과 `applyThemeObj`(History 레인 색) 을 적었다. `_initGitSection` 은 패널이 없으면 `poll.init()` 을 건너뛴다.
- CSS: 부팅 화면이 쓰는 규칙은 부팅에 남겼다. `.pn-tab.git` 커서·전역 폼 컨트롤 테마(checkbox·radio·select)는 `style-system.css` 끝, Repo 목록 표식(`.ed-entry.norepo`·`.git-badge.stale`·`.git-repo-*`)은 `style-sidebar.css` 앞이다. 앞의 것은 옛 자리와 캐스케이드 순서가 같다. 뒤의 것은 사이에 `style-runs.css` 가 끼지만 그 파일은 이 선택자를 다루지 않는다. 남은 git CSS 와 뒤쪽 부팅 CSS(runs·sidebar·editor·docrender·panel) 사이에 같은 요소를 같은 특이도로 다투는 규칙이 없음을 스크립트로 확인했다.

**지운 것**: `_askUploadFailure` 의 `typeof GitDialog` 가드(묶음 싣기로 대체), `theme-vars` 의 `typeof GitHistory` 가드(`Screens.ready` 로 대체).

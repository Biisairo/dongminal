# 7.2 역할 판정·데몬 기동·홈 주입

## 목표

7 의 하위 이슈. `cmd/dongminal/main.go` 의 역할 판정과 데몬 기동을 옮긴다.

- 헬퍼 이름 분기(runtimebin) → `dmlog::init`(stderr TextHandler) → 데몬 진입점(`d`·argv[0] dongminald, `--handover-*`, 홈 해석 0700) → `cli::dispatch`.
- `start_daemon`·`dial_or_start_daemon`(3s 바쁨 대기, 20×100ms 준비 대기, 오류 문구). ServeTarget.tool_home 을 데몬 환경 `DONGMINAL_TOOL_HOME` 으로 넘긴다.
- toolhub 에 홈 주입 공개 자리(환경 덮개)를 만들고 6.1.2 doctor 와 데몬 부팅이 그것으로 홈을 넘긴다(Go 의 `os.Setenv(DONGMINAL_HOME)` 자리).
- `version` 셋째 칸 재검토, platform `hostname()` 사용 확인.

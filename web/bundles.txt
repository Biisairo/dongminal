# 서버가 설 때 [이름] 아래 .js 를 이 순서대로 이어 붙여 /b/<이름>.js 로 낸다
# (rust/crates/webserver/httpapi/src/bundles.rs). 순서가 곧 로드 순서다 — 예전에
# web/index.html 의 <script> 순서가 지던 계약을 이 파일이 진다. 순서 검사는
# scripts/check-load-order.mjs 가 이 파일을 읽어 한다.
#
# 형식: '#' 줄과 빈 줄은 건너뛴다. .css 줄은 그 묶음의 CSS 다(서버가 이어 붙여 /b/<이름>.css 로 낸다).
# 한 파일은 한 묶음에만 둔다. 파일 경로는 web/ 기준이다.
#
# index.html 이 싣는 차례: vendor → b/pre.js → 활성 언어 파일 하나(js/i18n/<locale>.js) → b/boot.js.
# 언어 파일은 I18N.register 를 부르므로 pre(i18n.js) 뒤, 상수(boot) 앞이다.

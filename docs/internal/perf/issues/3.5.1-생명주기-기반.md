# 3.5.1 생명주기 기반 (D-36·D-37·D-38)

## 목표

- 계약 `mount`·`wake`·`sleep`·`unmount`(기반 클래스 강제 없음, `View` 에 기본 구현). `Component` 에 `awake(fn)` — 깰 때 건 구독·타이머·관측을 `sleep` 때 걷는다. 비 Component 주인용 도우미 `Awake`.
- 렌더러가 그릴 때마다 붙은 본문 집합을 지난 집합과 견주어 전이를 건다. `sleep` 은 2초(`SCREEN_SLEEP_MS`) 뒤, 그 안에 다시 보이면 취소.
- 브라우저 탭 숨김 신호는 `TimerHub` 의 하나뿐인 `visibilitychange` 에서 받는다(새 리스너 없음). 규칙 적용은 3.5.4.
- 시험용 관측 `app.testing.sleepers()`. 화면은 아직 옮기지 않는다.
- 렌더러 파일 병합 순서: **3.5.1** → 3.4.3 → 3.6.2. 2.5 는 이 위에 터미널 쪽만 채운다(D-38).

## 완료 조건

- RED(하네스 단위): 전이 `mount→wake→sleep→wake→unmount`. `sleep` 두 번 → 한 번만 걷음. `awake` 안의 구독·타이머가 `sleep` 뒤 0, `wake` 뒤 다시 1. 2초 안에 다시 보이면 `sleep` 없음. 잠든 상태의 `unmount` 도 모두 놓음.
- 단위: 렌더러가 본문이 빠지면 `sleep` 예약, 다시 붙으면 취소. 전체 시험 금지.
- 동작을 바꿨으면 이전 동작 / 새 동작 / 이유를 진행 기록과 커밋 메시지에 적는다.

# 1.1 dm-gocompat: Go 출력 규칙

## 목표

Go 표준 라이브러리의 관측 규칙을 흉내 내는 공통 crate 를 만든다 (FR-RSP-32). 최소 범위: ① encoding/json 호환 직렬화(serde Serializer 또는 전용 인코더) — HTML 이스케이프(`<`,`>`,`&`,U+2028,U+2029), 잘못된 UTF-8 의 U+FFFD 치환, map 키 정렬, 구조체 필드 선언 순서, `omitempty`, `MarshalIndent` 들여쓰기, Encoder 의 끝 줄바꿈, float 형식(`strconv.FormatFloat(f, 'g'…)` 규칙에 맞는 json 의 숫자 표기), `[]byte` 의 base64, nil slice → `null` ② json 디코딩에서 Go 와 다른 관측 차이(대소문자 무시 필드 매칭, 알 수 없는 필드 무시, 오류 문구) ③ time: RFC3339·RFC3339Nano 포맷·파싱, `time.Duration.String()` ④ `strconv.Quote`/`%q`, `%v` 의 기본 형식 중 저장소에서 실제로 출력에 쓰는 것 ⑤ Go `flag` 패키지의 파싱 규칙과 오류·사용법 문구(저장소가 flag 를 쓰는 곳을 grep 으로 확인하고, 쓰지 않으면 생략). 저장소 전체에서 관측 출력에 쓰이는 Go 표준 규칙을 grep 으로 조사해 범위를 확정하고, 조사 결과를 진행 기록에 남긴다.

### 범위 조사 결과 (Go 기준선 grep)

- 기준선 바이너리는 go1.27.2 로 빌드됐고 GOEXPERIMENT JSONv2 가 기본이다. 그래서 `encoding/json` 은 v1 코드가 아니라 v2 위의 v1 호환층이다. 기준값은 모두 같은 툴체인 실측으로 만들었다(조정자 확정).
- json: Marshal 64·MarshalIndent 16·NewEncoder 14(SetIndent 1·SetEscapeHTML(false) 1)·Unmarshal 190·NewDecoder 15(DisallowUnknownFields 1)·RawMessage 139·Valid 8·Compact 1. MarshalJSON·UnmarshalJSON·Number·`,string` 는 쓰지 않는다.
- time: RFC3339 형식 5곳(로컬 시간대 포함), RFC3339Nano 파싱 1곳, `time.Time` JSON 필드 7곳, Duration `%v`·String 5곳.
- strconv: Quote 2곳 + `%q` 192곳, FormatFloat('f',-1) 4곳, `%g` 1곳, `%.Nf` 10곳.
- `%v`: 오류·정수·bool 외에 `[]string`, Duration, float64, JSON `any`(settingsschema) 에 쓴다.
- flag: `scripts/gen-errors`·`gen-decisions` 의 `flag.Bool("check")`+`Parse()` 만.
- OS 오류(FR-RSP-35, 조정자 추가): PathError·LinkError·SyscallError, errno 문구.

### crate `dm-gocompat` 공개 API

- `strconv`: `quote`·`append_quote`·`quote_bytes`·`quote_rune`·`is_print`(Go isprint 표), `format_float(f, fmt, prec, bits)`.
- `time`: `now_local`·`local`·`to_zone`·`Zone`(TZif·POSIX TZ, Go initLocal 규칙; Windows 는 chrono::Local)·`format_rfc3339`·`format_rfc3339_millis`·`format_rfc3339_nano`·`format_log_std`·`format_duration`·`format_std_duration`·`parse_rfc3339`·`parse_rfc3339_nano`·`ParseError`·`GoTime`·`json_time`·`json_time_opt`·`zero_time`.
- `json`: `marshal`·`marshal_indent`·`Encoder`(set_escape_html·set_indent·encode·encode_to)·`unmarshal`·`Decoder`(disallow_unknown_fields·decode·unmarshal)·`Error`(`kind()` → `ErrorKind::{Syntax, Type, Eof, UnexpectedEof, Other}`)·`RawMessage`·`is_empty`/`IsEmpty`(omitempty)·`bytes`·`opt_bytes`·`valid`·`compact`·`indent`·`append_string`·`go_type!`·`with_go_type`·`GoTyped`.
- `oserr`: `errno_string`·`path_error`·`link_error`·`syscall_error`·`raw_os_error`·`go_error_string`·`GoPathError`·`GoLinkError`·`GoSyscallError`.
- `fmt`: `v_value`(JSON any)·`v_float`·`v_float32`·`v_list`.
- `flag`: `FlagSet`(bool·get·args·usage·parse·parse_or_exit)·`ParseError`.

### 테스트

Rust 테스트 38개. go1.27.2 실측 기준값(`testdata/`)과 대조한다: IsPrint 전 rune, 시간 형식 504건, 시간대 조회 187건, FormatFloat 1820건, JSON 구문 오류 코퍼스 4586건, 디코딩 의미 46건, 오류 필드 42건, 시간 파싱 138건, errno(darwin/arm64) 142건, %v 28건, flag 25건 등. Go 단위 테스트는 관측 동작을 검증하는 quote 표만 옮겼고, 나머지는 실측 기준값으로 대신했다.

### Go 와 다르게 한 내부 결정

- JSON 은 serde Serializer·Deserializer 로 구현했다. 구문 검사는 반복식 파서(깊이 10000 까지 Go 와 같은 문구)다. 값 트리는 반복식 Drop 을 쓴다.
- 로컬 시간대는 unix 에서 Go 와 같은 규칙을 순수 Rust 로 구현했고, Windows 만 chrono::Local 을 쓴다(조정자 승인).
- Windows errno 문구는 Go 처럼 FormatMessageW(LANG_ENGLISH US) 를 직접 부른다(C-RSP-4 예외 자리, unsafe 1곳).

### 남은 위험·알려진 차이

- 디코딩 중첩 깊이 상한 512(스택 보호, 조정자 승인). 513~10000 깊이는 Go 는 성공, Rust 는 `exceeded max depth`.
- 타입 오류가 나면 Go 는 일부 채운 값을 남기지만 Rust 는 값을 돌려주지 않는다.
- 타입 오류 문구의 타입 이름: 기본값 밖의 slice·map 은 소비자가 `go_type!`+`with_go_type` 로 이름을 줘야 Go 와 같다.
- 구조체 디코딩은 `#[serde(default)]` 가 있어야 Go 처럼 없는 필드를 허용한다. 같은 필드의 중복 키 병합은 "객체끼리 합침·뒤의 null 무시"로 근사했다(`any` 필드에 객체가 중복되면 Go 는 교체한다).
- time crate 는 ±9999년 밖을 담지 못한다(Go 의 year outside of range 오류는 Rust 에서 생기지 않는다).
- errno 표 대조는 darwin/arm64 에서만 실측했다. 나머지 세 표는 Go 원본에서 기계적으로 옮겼다. Windows errno·로컬 시간대는 Windows 에서 실행해 보지 못했다(교차 check 만 통과).
- 셸 heredoc(zsh)은 `<<'EOF'` 여도 `\uXXXX` 를 풀어 버린다. Go/Rust 소스·기준값 생성 코드는 Write 도구나 python 으로 써야 한다(1.5 의 RawMessage 오보 원인).
- 2026-11-23 조정자: rust-port 에 병합(flag 65a7f2d9 까지). lib.rs mod 줄 충돌은 4.1 의 filepath 와 함께 남겨 풀었다. 다섯 대상 clippy·격리 test 통과. prod-pids 동일.

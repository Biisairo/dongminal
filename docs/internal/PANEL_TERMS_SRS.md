# SRS: 사이드 패널의 이름 — 목록 패널과 작업 패널 (IEEE 29148 준수)

> **문서 상태**: 승인·구현완료
>
> 근거: 2026-11-22 사용자 결정 — 「용어는 사이드 패널로 통일, 양쪽 패널 이름은 알아서 붙여」. 시험 `e2e/i18n.spec.ts`·`editor-tab.spec.ts`·`sidebar-tabs.spec.ts`, `scripts/check-shortcuts-docs.mjs`

## 1. 개요

### 1.1 목적
화면 양옆의 두 패널을 문서·화면 글자·CHANGELOG 가 서로 다른 이름(「사이드바」·「메인 패널」·「Activity」·「작업 패널」)으로 불렀다. 이름을 하나로 정한다.

### 1.2 범위
- 포함: 한국어 화면 글자(`web/js/i18n/ko.js`)와 그 영어 짝(`en.js`), 사용자 문서(`README.md`·`docs/external/`), `CHANGELOG.md` 의 `[Unreleased]`, 현행 개발 문서의 색인·용어 절
- 비포함: 코드 식별자(`#sidebar`·`#agents-panel`·`sidebar.*` 키·CSS 변수 `--sidebar-bg`), 보관 문서(`archive/`)와 지난 SRS 본문(당시 어휘 그대로 둔다 — 대응은 §2 의 표), 지난 판의 CHANGELOG 절

### 1.3 정의 (결정)

| # | 결정 | 이유 |
|---|---|---|
| D-PNT-1 | 두 패널을 함께 부르는 이름은 **사이드 패널**이다 | 사용자 결정 |
| D-PNT-2 | 창·저장소·채팅 목록이 있는 패널(`#sidebar`)은 **목록 패널**이다 | 패널은 끌어서 좌우를 바꿀 수 있으므로(`PANEL_DOCK_SRS`) 자리(왼쪽·오른쪽)가 아니라 하는 일로 부른다. 「탐색 패널」 은 저장소 창의 「탐색기」 와 헷갈린다 |
| D-PNT-3 | 에이전트·백그라운드 도구·Run·사용량이 있는 패널(`#agents-panel`)은 **작업 패널**이다 | 화면 글자가 이미 그렇게 부른다(`shortcut.agents_toggle`). 영어 화면에서는 `Work panel` 이다 |
| D-PNT-4 | 두 패널을 함께 칠하는 테마 색(`sidebarBg`)의 이름은 **사이드 패널**이다 | 그 색이 두 패널의 바탕이다(`--sidebar-bg`) |

## 2. 요구사항

- **FR-PNT-1** — 한국어 화면 글자에 「사이드바」·「메인 패널」 이 패널 이름으로 나오지 않는다. 목록 패널의 글자는 `목록 패널`, 두 패널을 함께 말하는 글자는 `사이드 패널` 이다.
  - 바뀌는 글자: 빈 칸 안내 `사이드바에서 창을 고르세요` → `목록 패널에서 창을 고르세요` · 글자 크기 안내의 `사이드바·탭·…` → `사이드 패널·탭·…` · 테마 색 `사이드바` → `사이드 패널` · 단축키 묶음 `사이드바 탭` → `목록 패널 탭` · 단축키 `사이드바 탭: {label}` → `목록 패널 탭: {label}` · `사이드바 접기/펼치기` → `목록 패널 접기/펼치기`
- **FR-PNT-2** — 영어 화면 글자도 같은 뜻으로 바뀐다: `sidebar` → `list panel`, 테마 색 `Sidebar` → `Side panels`.
- **FR-PNT-3** — 사용자 문서와 `CHANGELOG.md` 의 `[Unreleased]` 는 D-PNT-1~3 의 이름을 쓴다. 처음 나오는 자리에 옛 이름을 한 번 밝힌다(예: 「목록 패널(전의 사이드바)」).
- **FR-PNT-4** — 개발 문서 색인(`docs/internal/README.md`)의 용어 절에 옛 이름과의 대응표가 있다. 지난 SRS 의 「사이드바」 는 목록 패널, 「Activity 패널」 은 작업 패널이다.

## 4. 이전 동작 / 새 동작 / 이유
- 이전: 화면 글자는 「사이드바」, CHANGELOG 는 「메인 패널」, 문서는 둘을 섞어 썼고 오른쪽은 「Activity」 와 「작업 패널」 이 섞였다
- 새: 사이드 패널(둘) · 목록 패널 · 작업 패널
- 이유: 사용자 결정. 한 것을 두 이름으로 부르면 사용자는 두 개라고 읽는다

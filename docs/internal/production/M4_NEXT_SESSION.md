## 이미 정해진 것 — 다시 결정하지 마라

| 항목 | 확정 |
|---|---|
| 방식 | 브라우저는 비밀번호 + `HttpOnly; SameSite=Strict` 쿠키, 비브라우저는 `Bearer` (결정 5) |
| 왜 쿠키인가 | **프론트 수정 0** — WS·SSE 가 쿠키를 자동으로 싣는다. e2e 도 `page.request` 가 쿠키를 공유한다 |
| TLS | **`--tls-cert/--tls-key` 두 플래그만** (결정 8). 앱이 인증서를 만들지 않는다. 로컬 CA 는 보류 |
| TLS 미설정 | **기동 거부 사유가 아니다.** 평문 + 경고 한 줄 |
| 기동 거부 | **인증 미설정 + 비 loopback 바인드**에서만. `--isolated` 는 제외 (e2e 가 무너진다) |
| loopback | **인증을 면제하지 않는다.** SEC-P0 의 공격이 정확히 loopback 출발지다 |
| 리버스 프록시 | **미지원 선언.** `X-Forwarded-*` 를 읽는 코드를 넣지 않는다 |
| 멀티유저 | **미지원 선언** (결정 7) |

## 착수 순서 (로드맵이 정하지 않았으므로 제안)

  ① `TLS-2` 노출 판정 확장 — **다른 전부의 전제다.** 지금 `0.0.0.0`/`::` 만 봐서
     `DONGMINAL_HOST=192.168.x` 가 `local-only` 로 오표시되고, **인증 강제가 그
     판정에 걸리므로** 여기가 틀리면 강제가 통째로 빠져나간다. 표 기반 테스트로
     고정한다 (`127.0.0.1`·`::1`·`localhost` = 로컬 / `0.0.0.0`·`::`·`192.168.x`·
     `10.x`·`100.64.x` = 노출)
  ② `G1-2` 자격증명 (`dongminal auth init/rotate/show`, `auth.json` 0600)
  ③ `G1-1`·`G1-3` 인증 판정과 세션 — `authGate` 를 채운다
  ④ `G1-4` 무차별 대입 방어 (백오프·잠금·`crypto/subtle`)
  ⑤ `SEC-3` 기동 거부 + `dongminal auth init` 안내
  ⑥ `G1-5` TLS 두 플래그 · `TLS-1` 알림 결손 셋
  ⑦ `G10-1` 보안 경계 문서 · README 의 "인증이 없으므로" 제거

**SRS 2건이 필요하다** — ① 인증·세션 ② 전송 보호(축소). 로드맵 §M4 의 DoD 가
그 목차를 이미 적고 있다.

## 흔들림 — 목록을 물려받지 마라

전량을 **다섯 번** 쟀고 **다섯 번 다 다른 목록**이 나왔다. 실패로 남은 것은
없다(전부 재시도 또는 단독 통과). 개별 검사의 결함이 아니라 **부하 민감성**이다.

만나면 **단독으로 한 번 더** 돌려 가리고, 고정 목록으로 쫓지 마라. 고칠 자리는
개별 검사가 아니라 **시간으로 전제를 세우는 곳**이다.

## M3 에서 비싸게 배운 것 — M4 에도 그대로 걸린다

- **가짜가 실물 계약을 속이면 검사가 아무것도 재지 못한다.** `fakeWorkspaceStore`
  가 `ifMatch` 를 무시했다. **가짜를 고치는 것이 검사를 고치는 것보다 먼저다.**
  M4 는 인증 가짜를 많이 만들 것이다 — 같은 함정이 그대로 있다
- **검사가 잘못된 이유로 통과할 수 있다.** 판정의 재료를 늘렸으면 **그 전제를
  세우는 자리도 함께 늘려야 한다**
- **계약을 조이면 그 계약을 지키지 않던 자리가 함께 나온다.** `If-Match`·
  `Delete(error)`·`save() error` 마다 그랬다. M4 의 401 은 그보다 훨씬 넓게 번진다
- **전제가 거짓이 된 주석을 믿지 마라.** `FBE-03` 의 "백그라운드 도구가 재기동을
  넘지 못한다" 는 데몬 모드에서 거짓이었다
- **기계를 새로 만들기 전에 이미 있는 것을 보라.** `G4-4` 의 스냅샷은 이미 있었고
  없던 것은 되돌릴 길이었다
- **예외 갈래를 더하면 그 갈래에는 본 규칙의 보호가 걸리지 않는다.** 인증의
  예외 경로(`/`·정적·`/login`·`/api/ping`)가 정확히 그 모양이다

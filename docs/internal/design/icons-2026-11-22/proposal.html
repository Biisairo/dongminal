otterminal 아이콘 시안 비교

원칙: 한 뜻 = 한 아이콘, 한 아이콘 = 한 뜻. 지금 아이콘 54개(쓰는 곳 52개)를 쓰는 자리로 나누어 63개 뜻으로 정리했다. 고를 것은 두 가지다 — ① 스타일(A·B·C) ② 뜻마다의 아이콘 짝.

라이선스 — 지금·A: Lucide (ISC, lucide-static 1.77.0) · B: Phosphor Icons (MIT, @phosphor-icons/core 2.1.1) · C: 이 시안에서 직접 그림(빈 칸은 A 로 채움). 모든 SVG 는 이 파일 안 스프라이트에 들어 있고 밖을 부르지 않는다.

색: 아이콘은 모두 currentColor. B 의 옅은 면은 Phosphor 원본의 opacity="0.2", C 의 옅은 면은 opacity=".2" 다.

후보 셋 — 장단점

A. Lucide 선 + 짝 재정리

lucide-static 1.77.0 · stroke 2 · currentColor
라이선스: ISC License (Lucide Contributors) · 일부는 Feather(MIT) 유래
  • 지금 화면과 결이 같아 바꿔 끼워도 어색함이 없다 — 아이콘 이름만 바꾸면 된다
  • 2,400개가 넘는 목록에서 뜻에 맞는 그림을 바로 고를 수 있다
  • 선 하나라 작은 크기(16px)에서도 가장 또렷하다
  • 「귀여움」 은 거의 늘지 않는다 — 지금보다 정리된 느낌일 뿐이다
  • 선만 있어 상태(작업 중·끝남)의 무게감이 약하다
  • 라이선스가 ISC 라 SRS FR-GLY-3 의 「MIT」 표기를 고쳐야 한다

B. Phosphor Duotone (둥근 두 톤)

@phosphor-icons/core 2.1.1 · viewBox 256 · fill + 옅은 면 opacity .2
라이선스: MIT License (Phosphor Icons)
  • 옅은 면이 깔려 통통하고 부드럽다 — 「귀엽게」 에 가장 가깝다
  • 뜻마다 짝이 넉넉하다(9,000여 파일, 6가지 굵기)
  • 같은 이름으로 Fill·Bold 로 바꿔 끼울 수 있어 강조 상태를 만들기 쉽다
  • 채움 기반이라 FR-GLY-2(stroke 규약)를 고쳐야 한다 — CSS 의 stroke 지정이 먹지 않는다
  • 16px 에서는 옅은 면이 뭉개져 선 아이콘보다 덜 또렷하다
  • Git 전용 그림(저장소·워크트리)은 없어 비유(책·폴더)로 대신한다

C. 직접 그린 고유 세트 (시범)

24×24 · stroke 2.35 · 둥근 끝 · 옅은 면 한 톤 · 16개만, 나머지는 A 로 채움
라이선스: 자체 제작(이 저장소 라이선스를 따른다) · 빈 칸은 A(Lucide ISC)
  • 문제가 컸던 뜻(Repo·History·Stash·Worktree…)을 이 앱만의 그림으로 맞출 수 있다
  • 선 굵기·모서리·면 톤을 한 규칙으로 그려 묶음이 고르다
  • stroke 기반이라 지금 규약(currentColor·stroke)을 거의 그대로 쓴다
  • 시범 수준이다 — 손으로 그린 좌표라 디자이너 손질이 필요하다
  • 나머지 뜻은 A 를 섞어 쓰므로 굵기(2 vs 2.35)가 조금 다르다
  • 아이콘이 늘 때마다 직접 그려야 해 유지 비용이 든다

남는 겹침 · 쓰는 곳 없음

A 의 남는 겹침: chevron-right — 펼침 / 접힘 · 이전 / 다음 항목
B 의 남는 겹침: caret-right — 펼침 / 접힘 · 이전 / 다음 항목
▸(다음)와 ▸(접힘)은 방향 꺾쇠 관례라 남겨 두기를 권한다. 놓이는 자리(숫자 옆 단추 / 행 맨 앞 표시)로 갈린다. 꼭 가르려면 「이전/다음」 을 arrow-left/right 로 옮기고 「뒤로/앞으로」 를 undo-2 계열로 바꿔야 하는데, 그쪽이 더 헷갈린다.

쓰는 곳 없음 — 스프라이트에서 빼기를 권한다: file panel-left

화면 목업

앱의 대표 자리를 후보마다 그렸다. 에이전트 상태 색(작업 중=강조색, 끝남=초록, 기다림=노랑, 쉼=흐림)과 Discard 위험색은 테마에서 가져왔다(web/js/ui/themes.js). C 목업에서 직접 그리지 않은 자리는 A 아이콘이다.

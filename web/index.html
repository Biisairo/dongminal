브라우저 기본 단축키 차단
Ctrl/Cmd 조합의 브라우저 기본 동작(저장·인쇄·찾기·북마크…)을 막아 단축키로 쓸 수 있게 합니다. 복사·붙여넣기·전체선택과 F5·F11·F12 는 그대로 둡니다. Ctrl+T·Ctrl+N·Ctrl+W 처럼 브라우저가 페이지에 넘기지 않는 조합은 어떤 설정으로도 막을 수 없습니다.
페이지 제목
브라우저 탭에 뜨는 이름입니다. 여러 대에 띄웠을 때 탭 줄에서 구분됩니다. 비우면 'Dongminal' 로 돌아갑니다.

탭 너비 고정
탭 너비 (px)
탭의 너비를 이름 길이와 무관하게 같게 만듭니다. 이름이 길면 말줄임으로 잘리고 전체 이름은 툴팁에 뜹니다. 탭이 많아 줄이 넘치면 지금처럼 가로로 스크롤합니다(폭은 줄지 않습니다).
프로세스 이름을 탭 이름으로
터미널에서 실행 중인 프로그램 이름(vim·claude·ssh…)이 탭 이름이 됩니다. 직접 지정한 이름은 덮이지 않습니다.
떠날 때 확인
탭을 닫거나 새로고침할 때 되묻습니다. 끄면 실수로 닫아도 묻지 않고 터미널 세션과의 연결을 잃습니다(세션 자체는 서버에 남아 다시 접속하면 이어집니다). 확인 문구는 브라우저가 정하므로 바꿀 수 없습니다. 새 판을 받는 자동 새로고침은 이 설정과 무관하게 묻지 않습니다.
포커스 잃은 창 표시
알림 가장자리 점멸
주의가 필요한 도구가 하나라도 있으면 화면 가장자리가 알람색으로 2초에 한 번 숨을 쉽니다. 어느 창의 알림이든 켜지므로, 다른 창을 보고 있어도 눈에 들어옵니다. 0 으로 내리면 그리지 않습니다. 세기는 옮기는 동안 그대로 미리 보입니다. 칸·탭·목록의 기존 표시는 그대로 남고 이 띠가 그 위에 더해집니다.
이 브라우저 창이 키를 받지 않는 동안 화면 가장자리에 옅은 띠를 그립니다. 0 으로 내리면 그리지 않습니다. 세기는 옮기는 동안 화면에 그대로 미리 보입니다. 색은 그 자리에 있는 색의 반대값이라 어느 테마에서나 눈에 띄고, 화면 안쪽은 건드리지 않아 글을 읽는 데는 지장이 없습니다. 창을 여러 개 띄웠을 때 어느 쪽에 키가 가는지 눌러 보지 않고 알기 위한 것입니다.
줄 바꿈
긴 줄을 편집기 폭에 맞춰 접어 보입니다. 끄면 한 줄로 두고 가로로 스크롤합니다(기본). 이미 열려 있는 편집기에도 곧바로 적용됩니다. diff 화면은 두 축을 나란히 놓는 자리라 이 설정을 따르지 않습니다.
데스크톱 알림
사운드
데스크톱 알림은 브라우저 권한 허용이 필요합니다. 시각 강조와 탭 제목 배지는 항상 동작합니다.
숨은 브라우저 탭과 보이지 않는 화면에서는 아무것도 묻지 않고, 돌아오면 즉시 한 번 갚습니다. 창 전환·저장·git 명령처럼 결과를 곧바로 봐야 하는 순간은 주기와 무관하게 그때 갱신합니다.
허용 목록 적용
끄면 접속에 아무 제한이 없습니다(지금까지의 동작). 켜면 아래 목록에 있는 출발지만 들어옵니다. --expose 로 띄웠다면 이것을 켜지 않는 한 같은 네트워크의 누구나 이 서버의 터미널과 파일에 접근할 수 있습니다.
지금 내 주소
이 값이 목록에 없으면 저장하는 순간 이 브라우저는 끊깁니다. 서버가 돌고 있는 컴퓨터에서는 목록과 무관하게 언제나 접속되므로, 잘못 설정해도 그 컴퓨터에서 되돌릴 수 있습니다.

지금 들어온 이름
이 컴퓨터의 별명
이 컴퓨터를 부르는 이름을 넣습니다(macmini-office · macmini-office.tail5da9ae.ts.net · macmini.local). 여기 없는 이름으로 접속하면 화면은 뜨지만 /api/*·/ws 가 421 로 끊깁니다. 위쪽 허용 목록과 달리 적용 토글과 무관하게 항상 적용되며, 이름은 해석하지 않고 그대로 비교합니다. 이 칸은 DNS 리바인딩 방어의 화이트리스트입니다 — 남의 도메인을 넣으면 그 도메인이 이 서버를 가리키게 만든 웹페이지가 응답을 읽을 수 있으므로 이 컴퓨터가 불리는 이름만 넣고, 와일드카드(*)는 쓸 수 없습니다. 이미 이름으로 막힌 상태라면 그 브라우저에서는 이 칸을 고칠 수 없습니다 — 서버가 돌고 있는 컴퓨터에서, 또는 IP 로 접속해 고치세요.
허용 목록
IP(100.117.248.111) · 대역(192.168.0.0/24) · 이름(macmini, macmini.tail5da9ae.ts.net)을 넣습니다. 이름은 서버가 주기적으로 해석해 IP 와 대조하며, 해석된 주소가 줄 끝에 보입니다 — .local(mDNS)은 해석되지 않습니다. 같은 기기라도 tailscale 로 붙을 때와 같은 LAN 에서 붙을 때 주소가 다르므로, 쓰는 경로를 모두 넣으세요.
dev 이미지
포트
이미지를 비우면 dev 프로파일을 쓸 수 없고 scratch 만 남습니다. 포트는 쉼표로 구분하며, 컨테이너를 만든 뒤에는 더할 수 없어 미리 넉넉히 적는 편이 낫습니다.
기본 마운트
샌드박스 창이면 언제나 붙는 자리입니다 — 설정과 자격증명을 둡니다(~/.claude, ~/.ssh). ~ 는 홈으로 펴집니다. scratch 를 켜면 그 항목이 격리 창에도 들어가고, 그 순간 그 창은 격리 경계가 아니게 됩니다 — 읽기 전용이어도 내용은 읽힙니다.
저장하면 곧바로 반영되지만, 이미 열려 있는 샌드박스 창은 그대로입니다. 새 설정으로 열려면 그 창을 닫았다 다시 여세요 — 그때 컨테이너 안에 설치했던 것은 사라집니다.
설정 내보내기
이 창의 설정 전부(테마·단축키·상태바·프리셋·표시·알림)를 JSON 파일 하나로 내려받습니다. 창 너비 같은 화면 치수와 리포별 Git 보기 취향은 옮겨도 뜻을 잃으므로 담지 않습니다.
설정 가져오기
고른 파일의 값으로 전체 교체합니다. 파일에 없는 설정은 기본값으로 돌아갑니다. 교체가 끝나면 페이지를 다시 엽니다.
창 배치 되돌리기
창·칸·탭의 배치를 저장 직전의 판으로 되돌립니다. 설정이 아니라 배치만 바뀝니다. 되돌린 뒤에도 직전 판이 목록의 맨 앞에 남으므로, 잘못 골랐으면 한 번 더 되돌리면 됩니다.
기본값으로 되돌리기
이 창의 설정 전부(테마·단축키·상태바·프리셋·표시·알림)를 기본값으로 되돌립니다. 창 배치는 건드리지 않습니다. 되돌릴 수 없으니 먼저 파일로 저장을 눌러 지금 설정을 담아 두세요.
지금 설정을 전부 버리고 기본값으로 되돌립니다. 되돌릴 수 없습니다.

# 4.1.1 git 실행 계층: core

## 목표

git 실행 계층(exec·spawn·guard·write·unguarded·record·recovery·exclusion·errors·oid·redact 등)을 옮긴다. git 명령 인자·환경변수·타임아웃·오류 분류 문구가 Go 와 같아야 한다. 프로세스 그룹(spawn.go 의 `platform.Current().Process.NewGroup`)은 1.4.4 의 Process trait 에 맞춰 쓰고, 그 구현이 필요한 시험만 1.4.4 완료 뒤로 남긴다. 시험 보조 `gittest`·`testpath` 는 1.5 가 dev 용으로 옮긴다 — 아직 없으면 같은 동작의 시험 전용 보조를 이 crate 의 tests 안에 두고, 1.5 완료 뒤 바꾼다.

## 대상 Go 코드

- `internal/webserver/domain/git/core` (프로덕션 약 2040줄)

## 완료 조건

- 대상 Go 코드의 관측 동작을 Rust 가 동등하게 제공한다 (FR-RSP-1·3)
- 관측 동작을 검증하는 Go 테스트가 Rust 테스트로 옮겨져 통과한다 (V-RSP-1)
- `cargo fmt --check`, `cargo clippy -D warnings`, 격리 실행 `cargo test` 통과 (NFR-RSP-4)
- OS 의존 코드가 있으면 windows·linux 대상 `cargo check` 통과 (NFR-RSP-5)
- 작업 전후 `rust/scripts/prod-pids.sh` 출력이 같다 (V-RSP-5)
- 진행 기록에 공개 API 요약과 Go 와 다르게 한 내부 결정이 있다

# 1.4.5 platform IPC

## 목표

웹서버↔데몬 로컬 전송(유닉스 도메인 소켓, 0600, Exists·Remove 규약, SiblingSocket)을 옮긴다. Windows 는 Go 와 같이 AF_UNIX 를 쓴다 — std·tokio 가 지원하지 않으므로 windows-sys 로 직접 구현한다(unsafe, C-RSP-4). 공개 API 는 부모 이슈 1.4 의 진행 기록 "공개 API 안" 을 따른다. 바꿔야 하면 조정자에게 먼저 알린다.

## 대상 Go 코드

- `internal/shared/platform/ipc.go` (약 100줄, Windows AF_UNIX 구현이 더해진다)

## 완료 조건

- 대상 Go 코드의 관측 동작을 Rust 가 동등하게 제공한다 (FR-RSP-1·3)
- 관측 동작을 검증하는 Go 테스트가 Rust 테스트로 옮겨져 통과한다 (V-RSP-1)
- `cargo fmt --check`, `cargo clippy -D warnings`, 격리 실행 `cargo test` 통과 (NFR-RSP-4)
- OS 의존 코드가 있으면 windows·linux 대상 `cargo check` 통과 (NFR-RSP-5)
- 작업 전후 `rust/scripts/prod-pids.sh` 출력이 같다 (V-RSP-5)
- 진행 기록에 공개 API 요약과 Go 와 다르게 한 내부 결정이 있다

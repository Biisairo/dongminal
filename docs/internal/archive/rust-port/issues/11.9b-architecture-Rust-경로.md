# 11.9b architecture.md 본문의 Go 경로를 Rust 경로로

## 목표

조정자 결정(2026-11-24): `docs/internal/architecture.md` 는 이 브랜치의 개발 지도다. Go 가 지워진 뒤 Go 경로를 가리키면 안 된다. 본문의 Go 소스 경로를 대응하는 Rust crate·파일 경로로 바꾼다. 대응이 없으면 "Go 기준선(main)" 으로 표기한다.

- 바꾼 것: architecture.md 본문의 Go 경로 약 60곳을 대응하는 Rust 경로로 바꿨다. httpapi 핸들러 절(files·attention·settings·routes·serve·snapshot), apierr·inventory, gitapi 쓰기(`write.rs`), runtime·runtimebin·toolhub·wsentry·workspace(`parse.rs`)·hub(focus·commands·replyseat)·run(preamble)·agentadapter(claude/codex/omp.rs)·worktree·agentplugin(`assets/agentplugin`, `assets.rs` 의 `include_bytes!`)·skills 계약 시험(`runtime/src/tests.rs`)·sse·toolipc(protocol·wire·lib, 골든 `tests.rs`)·git 실행 계층(`core/src/tests/gate.rs`·`exec.rs`·`write.rs`)·seam·ws(`ws.rs` 의 `strip_snapshot_queries`)·diag_snapshot·종료 표(`serve/mod.rs` 의 `shutdown_steps`), 시험 절, 트리 주석 세 줄. 생산자 대조 시험은 `web/js/test/remote-actions.test.mjs`(브라우저)와 `httpapi/src/tests/commands.rs`(서버 종단)를 가리킨다.

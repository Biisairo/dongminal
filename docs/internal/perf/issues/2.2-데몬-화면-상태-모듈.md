# 2.2 데몬 화면 상태 모듈 (FR-TRM-1·7)

## 목표

alacritty_terminal `=0.26.0` 을 새 crate(가칭 `otter-shared-termstate`) 하나에 가두고, 도구마다 화면 상태 한 벌을 둔다. `Tool::handle_chunk` 의 `cmu` 잠금 안에서 링과 함께 에뮬레이터에 넣고, `resize_inner` 에서 크기를 바꾼다. 에뮬레이터 기록 상한은 작게(초기 1,000줄) 두고, 답장 사건(`PtyWrite`)은 PTY 에 쓰지 않는다. 비교 시험 자료(2.1 스파이크의 녹화·경계 벡터)와 `@xterm/headless 5.5.0` 기준 셀 격자 JSON·생성 스크립트를 저장소로 옮긴다.

설계: `perf/M2_DESIGN.md` §2.2. 결정: D-13, D-18. 2.3 이 쓸 줄 읽기 표면은 착수 때 먼저 정해 조정자를 거쳐 2.3 에 알린다.

## 완료 조건

- RED: 경계 벡터·vim·less·top·agent-sim 의 모든 셀·커서·대체 화면이 xterm 기준과 같다(OSC 8 밑줄 4셀은 2.4 뒤 0).
- RED: 크기 바꾸기 전후 화면이 xterm 의 재흐름 결과와 같다. 대체 화면 왕복, 스크롤 영역(DECSTBM) 스크롤.
- RED: 도구 하나에 에뮬레이터 하나 — 구독자 둘이어도 `feed` 는 한 번(FR-TRM-7).
- RED: 에뮬레이터가 답장을 PTY 에 쓰지 않는다.
- `deny.toml`·RustSec·Windows 타입 검사 통과.
- 바꾼 부분의 시험(단위·관련 e2e 한두 개)·fmt·clippy·관련 게이트 통과. 전체 시험은 마일스톤 끝에서 한 번만(2.10).
- 시험을 먼저 쓰고 RED 를 확인한 뒤 구현한다.
- 동작을 바꿨으면 이전 동작 / 새 동작 / 이유를 진행 기록과 커밋 메시지에 적는다.

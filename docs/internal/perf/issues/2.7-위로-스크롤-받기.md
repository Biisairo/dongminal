# 2.7 위로 스크롤 받기 (FR-TRM-5)

## 목표

채널 텍스트 프레임 `term.history{sid,before,count}`(브라우저→서버)와 `term.history{sid,from,lines}`(서버→브라우저), IPC 메서드(가칭 `history`). 요청은 별도 태스크에서 처리해 출력·입력을 막지 않는다. 브라우저는 기록 맨 위에서 더 올리면 같은 칸 위의 읽기 전용 xterm 기록 보기에 받은 구간을 그리고, 맨 아래로 내리거나 키를 누르면 실시간으로 돌아온다(D-20). 들어가고 나오는 조작은 착수 때 화면안을 사용자에게 보인다.

설계: `perf/M2_DESIGN.md` §2.7.

## 완료 조건

- RED(서버): 저장소 구간을 순서대로 돌려준다. 맨 위를 넘으면 있는 만큼만 주고 끝을 알린다. 기록이 지워진 뒤 옛 번호에는 빈 답.
- RED: 받는 동안 같은 sid 의 출력 프레임 간격이 늘지 않는다.
- RED(e2e): 5천 줄보다 위로 스크롤하면 그 위 기록이 보이고 글자가 원래와 같다. 그동안 입력이 막히지 않는다.
- 바꾼 부분의 시험(단위·관련 e2e 한두 개)·fmt·clippy·관련 게이트 통과. 전체 시험은 마일스톤 끝에서 한 번만(2.10).
- 시험을 먼저 쓰고 RED 를 확인한 뒤 구현한다.
- 동작을 바꿨으면 이전 동작 / 새 동작 / 이유를 진행 기록과 커밋 메시지에 적는다.

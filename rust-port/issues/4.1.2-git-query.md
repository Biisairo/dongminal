# 4.1.2 git 조회: query

## 목표

조회(status·diff·hunks·이미지 diff·blame·log·refs·branch·tag·remote·commit 상세·서명·operation·preflight)를 옮긴다. git 명령 인자와 출력 파싱 결과가 Go 와 같아야 한다. editorlimit·mimeprobe·textenc(1.2)를 쓴다. 한 crate 라 더 나누지 않는다(3000줄을 조금 넘는다). 시험 보조는 4.1.1 과 같은 방침이다.

## 대상 Go 코드

- `internal/webserver/domain/git/query` (프로덕션 약 3400줄)

## 완료 조건

- 대상 Go 코드의 관측 동작을 Rust 가 동등하게 제공한다 (FR-RSP-1·3)
- 관측 동작을 검증하는 Go 테스트가 Rust 테스트로 옮겨져 통과한다 (V-RSP-1)
- `cargo fmt --check`, `cargo clippy -D warnings`, 격리 실행 `cargo test` 통과 (NFR-RSP-4)
- OS 의존 코드가 있으면 windows·linux 대상 `cargo check` 통과 (NFR-RSP-5)
- 작업 전후 `rust/scripts/prod-pids.sh` 출력이 같다 (V-RSP-5)
- 진행 기록에 공개 API 요약과 Go 와 다르게 한 내부 결정이 있다

## 이 세션이 배운 것 (6.1.1·6.1.2 를 하며)

- **Go 참조 바이너리 정답 대조가 가장 값이 크다.** `rust/scripts/hermetic.sh go build -o rust/target/go-ref/dongminal ./cmd/dongminal` 로 빌드해 두었다(있으면 다시 안 해도 된다). 정답 자료 `rust/crates/ctl/cli/testdata/go_cli_golden*.json` 과 검사 `src/tests/golden.rs` 가 있다. 만든 스크립트는 `/tmp/dm-611-gen/gen.sh <bin> <cases.txt> <hermetic.sh> <out.json>`(cases 는 줄마다 탭으로 가른 인자). /tmp 라 사라졌을 수 있다 — 그러면 jq 로 다시 짠다(인자는 NUL 로 묶어 `jq --rawfile` 로 넣는다. `--args` 는 `--` 로 시작하는 인자에서 깨진다)
- 환경은 `env::Env`(crate 내부)로 주입한다. 검사는 `tests::Vars` + `with_env`. 공개 `run_x` 는 프로세스 환경, 내부 `run_x_in` 이 `&Env` 를 받는다. 분기 표(`actions.rs`)는 `run_x_in(&o, env, …)` 를 부른다
- 프로세스 제어·포트 관측은 `proc::Procs{proc, pids_on_port}` 로 주입한다. 검사의 `tests::proc::FakeProc`·`live_socket`(답하는 IPC 소켓)·`write_pid` 를 다시 쓴다
- 플랫폼 `ipc.exists` 는 **실제 소켓만** 참이다. 일반 파일로 흉내 내면 안 된다 — `live_socket` 을 쓴다
- 검사용 HTTP 서버는 `tests::fake_http::FakeServer`(`start(status, reply)` 는 bind POST 기록, `/api/ping`·`/` 200 / `start_health(body)` / `dead_port()`)
- 동기 폴링은 `wait::poll_until(max, every, cond)`(pollwait::until 과 같은 의미). CLI 는 비동기 런타임을 쓰지 않는다. HTTP 는 `http.rs`(`ping`·`get`·`post_json`, reqwest current-thread + gocompat neturl_err 문구)
- 타입 별칭의 `dyn Fn` 은 기본 수명이 `'static` 이다 — `Serve<'a> = dyn Fn(..) + 'a` 처럼 수명을 단다
- crate 내부에서 안 쓰는 항목은 clippy dead_code 로 막힌다. 쓰는 묶음에 함께 넣는다
- `cargo fmt --all` 뒤에는 `git status` 로 다른 crate 를 건드리지 않았는지 본다
- Go `%-10s` 폭은 글자 수(룬)로 세고, Rust `{:<10}` 도 글자 수다 — 같다. Go `len()` 은 바이트다(`layout_list`)
- 보안 리뷰 훅이 권한(0644 등)을 지적하면 FR-RSP-6(사용자가 알아챌 수 없는 보안 강화는 고친다)에 따라 고치고 기록한다
- int(rust-port)의 이슈 파일은 고친 뒤 커밋하지 않는다

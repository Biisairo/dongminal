브라우저 기본 단축키 차단
Ctrl/Cmd 조합의 브라우저 기본 동작(저장·인쇄·찾기·북마크…)을 막아 단축키로 쓸 수 있게 합니다. 복사·붙여넣기·전체선택과 F5·F11·F12 는 그대로 둡니다. Ctrl+T·Ctrl+N·Ctrl+W 처럼 브라우저가 페이지에 넘기지 않는 조합은 어떤 설정으로도 막을 수 없습니다.
페이지 제목
브라우저 탭에 뜨는 이름입니다. 여러 대에 띄웠을 때 탭 줄에서 구분됩니다. 비우면 'Dongminal' 로 돌아갑니다.
슬롯 방향
두 창을 나란히 볼 때(⧉ Slot · Ctrl+Shift+S) 칸을 어느 축으로 나눌지 정합니다.
Display Mode
Mobile Breakpoint (px)
'Auto' 모드에서 창 너비가 Breakpoint보다 작으면 모바일 레이아웃으로 전환됩니다.
프로세스 이름을 탭 이름으로
터미널에서 실행 중인 프로그램 이름(vim·claude·ssh…)이 탭 이름이 됩니다. 직접 지정한 이름은 덮이지 않습니다.
데스크톱 알림
사운드
에이전트 패널 새로고침 주기
데스크톱 알림은 브라우저 권한 허용이 필요합니다. 시각 강조와 탭 제목 배지는 항상 동작합니다.
설정 내보내기
이 창의 설정 전부(테마·단축키·상태바·프리셋·표시·알림)를 JSON 파일 하나로 내려받습니다. 창 너비 같은 화면 치수와 리포별 Git 보기 취향은 옮겨도 뜻을 잃으므로 담지 않습니다.
설정 가져오기
고른 파일의 값으로 전체 교체합니다. 파일에 없는 설정은 기본값으로 돌아갑니다. 교체가 끝나면 페이지를 다시 엽니다.

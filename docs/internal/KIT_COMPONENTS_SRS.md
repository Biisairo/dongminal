## 1. 개요 (Introduction)

### 1.1 목적 (Purpose)

B2 가 끝난 뒤 남은 것은 **킷에 자리가 없어서** 각 화면이 스스로 그린 것들이다.
성격이 B2 와 정반대다 — B2 는 *"세워 놓고 안 옮겼다"* 였고 여기는 *"세운 적이
없다"* 다.

| 역할 | 지금 몇 가지인가 | 킷에 | 세울 것 |
|---|---:|---|---|
| 불리언 설정 | **3** (맨 체크박스 · 알약 토글 · 체크박스+글자) | 없다 | `.ui-switch` |
| 섹션 머리글 | **9규칙**이 `text-transform:uppercase` | 없다 | `.ui-section-head` |
| "지금 선택된 것" | **3** (밑줄 · 테두리+배경 · 글자색) | 탭만 있다 | `.ui-segment` |
| 개수 표기 | **4** (알약 배지 · `(8)` · `Run 0개` · `백그라운드 도구 0개`) | 탭 배지만 | 배치 규칙 |
| 분할 버튼 | **2**곳이 각자 모서리 규칙 | 없다 | `.ui-split` |
| 인라인 알림 | **12규칙** (`.fe-note`·`.fe-offer`·`.git-*-note` …) | 없다 | `.ui-notice` |
| 빈 상태 | **13개** 클래스, 누를 것이 **하나도 없다** | 없다 | `.ui-empty` |
| 키캡 | `.sc-key` 36개가 버튼 행세 | 없다 | `.ui-key` |

## 2. 현재 상태 (조사로 확정한 사실)

실측 2026-09-20, 커밋 `7f7f2b8c`. CSS 는 주석 제거 후 규칙 단위 파싱, JS·HTML 은
줄 단위.

### 2.1 감사의 수치가 또 표본이다 — 두 자리

> **정정 ①: 빈 상태는 다섯이 아니라 열셋이다.** `AUDIT-uiux.md` §4.1 은 편집기 ·
> Agents · Runs · Background · 저장소 사이드바 **다섯**을 표로 적었다. 그것은
> 그때 화면에 있던 것이고, `-empty` 로 끝나는 클래스를 전수로 세면 **13**이다:
> `.ed-empty` · `.lsp-empty` · `.git-hist-empty` · `.git-br-empty` ·
> `.git-stash-empty` · `.git-wt-empty` · `.git-sub-empty` · `.git-rm-empty` ·
> `.slot-empty` · `.ag-empty` · `.bg-empty` · `.runs-empty` · `.git-con-empty`.
>
> **정정 ②: 머리글은 여섯 자리가 아니라 아홉 규칙이다.** §1.2 는 자리 여섯을
> 표로 적었으나 `text-transform:uppercase` 를 쓰는 규칙은 **9**다 —
> `.git-files-sect`(style-git.css:399) · `.git-refs-head`(195) ·
> `.gc-target-sect`(406) · `.git-stash-sect`(552) · `.ag-head`(687) ·
> `.ag-group`(693) · `.mtab`(825 부근) · `.ce-title`(870) · `.sc-group-title`(879).
>
> 이것으로 이 저장소에서 **다섯 번째** 같은 모양이다 (§7.6 잔여표 · FR-A11Y-28 ·
> FR-A11Y-16 · 버튼 "6종 98개"). **화면을 보고 센 수는 표본이다.** 그래서 이
> 문서의 대상은 열거가 아니라 **파싱으로 파생한다** (FR-CMP-2).

### 2.2 불리언 컨트롤 — 세 모양이 한 모달 안에 있다

| 모양 | 자리 | 실측 |
|---|---|---|
| 맨 `<input type=checkbox>` | 설정 ▸ Theme·Display·Terminal·Code … | `index.html` 에만 여러 자리 |
| 알약 토글 (`.ds-switch`) | 설정 ▸ Display "분할 방향" | **1자리** (`index.html:334`) |
| 체크박스 + 글자 | 설정 ▸ Access · Status Bar · git 옵션 | `app-settings-access.js:25` · `app-statusbar.js:427` 외 |

`input[type=checkbox]` 는 **22자리 · 8파일**이다. 그중 설정 모달 밖(git 커밋
amend · 콘솔 필터 · diff 옵션)은 성격이 다르므로 §6 이 가른다.

**알약이 하나뿐인 것이 요점이다.** `SETTINGS_CONTROLS_SRS` FR-SCT-4 가 *"흔히 보는
토글 스위치다"* 라며 세웠는데 **한 자리에서 멈췄다** — 패턴 A 의 또 다른 사례이며,
다른 점은 그것이 킷이 아니라 도메인 CSS 에 섰다는 것뿐이다.

### 2.3 인라인 알림 — 12규칙이 같은 일을 한다

`.fe-note` · `.fe-offer` · `.git-job-note` · `.git-job-auth-note` ·
`.git-job-opts-note` · `.git-stale-note` · `.git-partial-note` · `.sbx-rt-note` ·
`.ver-held` · `.git-blame-note` · `.git-diff-note` · `.git-con-note`.

공통 모양이 있다: `padding` + `font-size:var(--fs-sm)` + 상태색(`--attn-text` 또는
`--text-muted`) + 때로 배경. 다른 것은 **동작 영역이 있는가**뿐이고, `.fe-offer`
하나만 버튼을 갖는다 (§1.6 이 본 그 줄이다).

### 2.4 분할 버튼 — 규칙이 이미 "자리" 로 적혀 있다

```
style-git.css:102  .git-head-remote>.ui-btn:nth-child(odd){border-radius:… 0 0 …}
style-git.css:103  .git-remote-more{padding:0 4px;border-left:0;border-radius:0 … … 0}
style-git.css:298  .git-commit-go>.ui-btn:first-child{border-top-right-radius:0;…}
style-git.css:299  .git-commit-more{padding:0 6px;border-left:none;…}
```

`DESIGN_TOKENS_SRS` §7.5 가 *"원격·커밋의 **붙은 한 쌍** 모서리는 … 이름이 아니라
자리다"* 로 남긴 자리다. **두 벌이고 값이 다르다** (`padding:0 4px` vs `0 6px`).
셋째 쌍이 생기면 셋이 된다.

### 2.5 왜 게이트가 못 막았나

B2 가 세운 검사 둘은 *"킷을 달았는가"* 를 묻는다. 이 묶음의 결손은 **달 킷이
없는** 자리이므로 그 물음에 걸리지 않는다. 새 검사는 다른 것을 물어야 한다 —
*"같은 역할을 하는 자리가 서로 다른 값으로 그려지는가"*.

## 3. 요구사항 (Requirements)

### 3.0 이 묶음 전체에 걸리는 것

| ID | 요구 | 등급 |
|---|---|---|
| FR-CMP-1 | **새 hex 를 넣지 않는다.** 여덟 컴포넌트 전부 기존 토큰과 그 파생만 쓴다 (FR-TOK-16 · 사용자 결정 2026-09-20) | 필수 |
| FR-CMP-2 | **대상 목록을 손으로 적지 않는다.** 각 묶음의 대상은 CSS·JS 파싱으로 **파생**하고, 파생 결과가 §2 의 실측과 어긋나면 §2 를 먼저 고친다. 이 저장소가 같은 함정에 다섯 번 빠졌다 (§2.1) | 필수 |
| FR-CMP-3 | **옛 이름을 지우지 않는다** (D-5 / FR-UIK-10). 킷 클래스를 함께 붙이고, 옛 규칙에서는 킷과 **같은 선언만** 걷는다. 배치·상태·뜻은 남긴다 (D-TOK-11) | 필수 |
| FR-CMP-4 | **킷은 `!important` 를 쓰지 않는다** (FR-UIK-11). 킷이 `<link>` 순서상 먼저 오고 옛 규칙이 덮을 수 있는 구조를 유지한다 | 필수 |
| FR-CMP-5 | 동작이 바뀌면 **이전 / 새 / 이유** 셋을 같은 변경에 적는다 (규약 4) | 필수 |

## 4. 설계 결정

- **D-CMP-1 `.ui-switch` 는 껍데기만 바꾼다 — DOM 은 체크박스로 남는다.**
  대안은 `.ds-switch` 의 `<button role="switch">` 로 수렴시키는 것이었다.
  버린 이유 셋: ① 체크박스는 브라우저가 `aria-checked`·폼 의미론·키 조작을
  **공짜로** 준다 ② 상태 읽기·쓰기 경로 22자리를 전부 고쳐야 하고 그 변경은
  외형이 아니라 **동작**이다 ③ `_settingsA11y` 가 이름을 **구조에서 파생**하므로
  (FR-A11Y-13) 요소 종류가 바뀌면 그 파생이 흔들린다.
  **대가는 `.ds-switch` 한 자리가 예외로 남는 것**이고, §6-예외표가 그것을 적는다.

- **D-CMP-2 대문자를 걷는 것은 외형이고, 낱말을 고치는 것은 B4 다.**
  §1.2 는 둘을 한 항목으로 적었지만 게이트가 다르다 — 대문자는 CSS 파싱으로
  0을 셀 수 있고 낱말은 i18n 카탈로그의 일이다. 한 변경에 섞으면 빨개졌을 때
  어느 쪽인지 말할 수 없다 (FR-TOK-45 가 같은 이유로 분리를 요구했던 것과 같은
  규약).

- **D-CMP-3 빈 상태의 주동작은 있는 것만 가리킨다.**
  감사는 다섯 자리에 각각 주동작을 제안했다. 그중 *"Agents → 에이전트 안내 보기"*
  는 **그런 화면이 없다** — 만들면 이 묶음이 컴포넌트 작업에서 기능 작업이 된다.
  FR-CMP-62·63 이 경계를 긋는다: 버튼은 **선택**이고, 있는 것만 가리킨다.

- **D-CMP-4 페이드는 한 벌이다.**
  §4.2(설정 모달 넘침)와 §5A.4(`.ed-tree` 9px 넘침)가 같은 장치를 기다린다.
  두 벌로 만들면 다음에 세 번째 자리가 생긴다 — 이 문서가 고치려는 바로 그
  모양이다.

- **D-CMP-6 설정 모달의 높이는 **고정을 유지한다**.** (사용자 결정 2026-09-20)

  착수 시 이 문서는 `AUDIT-uiux.md` §4.2 의 제안(*"고정 높이를 주는 자기 규칙을
  걷고 내용에 맞춰 늘게 둔다"*)을 FR-CMP-83 으로 옮겨 적었다. **그것이 뒤집는
  대상이 사용자 접수였다** — `UI_KIT_SRS` FR-UIK-12(2026-09-08): *"설정 모달의
  크기는 탭에 따라 달라지지 않는다. 폭과 높이가 고정이며, 내용이 짧은 탭에서도
  상자가 줄지 않는다."*

  **전량 e2e 가 그것을 잡았다.** `poll-interval.spec.ts` 의 PIS19(V-11)가 그
  요구를 지키고 있었고, 부분 실행 49건에서는 보이지 않던 자리다 — 묶음 경계마다
  전량을 도는 규약(사용자 결정 2026-09-20)이 값을 한 자리다.

  사용자 확인(2026-09-20): *"설정모달은 기존 고정을 유지"*. FR-CMP-83 과
  TC-CMP-17 을 철회했다.

  **§4.2 의 관찰이 틀린 것은 아니다.** 긴 탭에서 마지막 행이 잘리는 불편은
  실재하고, 그 원인은 높이가 아니라 **잘린 것이 안 보이는 것**이다 —
  FR-CMP-84(넘침 페이드)가 그 절반을 고친다. 짧은 탭의 빈 자리는 FR-UIK-12 가
  의도한 것이므로 결함이 아니다.

- **D-CMP-5 게이트를 한 검사에 몰지 않는다.**
  B2 의 검사 둘은 각각 **하나의 물음**을 가졌고(`overflow` 는 스크롤바를 갖는가 ·
  `<button>` 은 등급을 갖는가) 그래서 오탐을 판정할 수 있었다. 여덟 컴포넌트의
  적용을 한 검사에 몰면 실패 메시지가 *"어딘가 킷을 안 썼다"* 가 되어 고칠 자리를
  말하지 못한다.

건드리므로 각자 전량 1회, 나머지는 B3 전체가 끝난 뒤 1회 (FR-TOK-38 의 규약).

## 6. 비목표 (Non-goals)

1. **낱말·번역·존댓말 등급.** 영문 리터럴 113개 · 낱말 통일 · 조사 헬퍼 —
   **B4**. 이 묶음은 외형과 구조까지다 (D-CMP-2 · FR-CMP-33·64).
2. **색 위반 25건.** B4.
3. **`.ds-switch` 를 체크박스로 바꾸는 것.** D-CMP-1 · §6-예외표 E-1.
4. **키보드 도달.** `KIT_APPLICATION_SRS` D-KIT-8 로 별도 접근성 작업이다.
   이 묶음은 **새 컴포넌트가 그 결손을 늘리지 않게만** 한다 (FR-CMP-12·23).
5. **설정 모달 밖의 체크박스** (git 커밋 amend · 콘솔 필터 · diff 옵션).
   그것들은 설정이 아니라 **한 번 쓰는 옵션**이고, 스위치로 바꾸면 "저장되는
   설정" 으로 읽힌다.
6. **성능.** B6.
7. **새 기능.** 빈 상태의 주동작은 **있는 것만** 가리킨다 (D-CMP-3).
8. **팔레트 값 변경.** FR-TOK-16.

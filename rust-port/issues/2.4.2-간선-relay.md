# 2.4.2 간선 relay: edgerelay

## 목표

서버(TCP 노드 포트)와 데몬(노드 소켓·dial.sock) 사이의 중계를 옮긴다. 2.3 의 `Listener::use_listen`(Acceptor)·`Client::via`(Dial)에 붙는다. Go 서버·데몬과 섞어 써도 중계가 되어야 한다.

## 대상 Go 코드

- `internal/shared/edgerelay` (프로덕션 약 395줄)

## 완료 조건

- 대상 Go 코드의 관측 동작을 Rust 가 동등하게 제공한다 (FR-RSP-1·3)
- 관측 동작을 검증하는 Go 테스트가 Rust 테스트로 옮겨져 통과한다 (V-RSP-1)
- `cargo fmt --check`, `cargo clippy -D warnings`, 격리 실행 `cargo test` 통과 (NFR-RSP-4)
- OS 의존 코드가 있으면 windows·linux 대상 `cargo check` 통과 (NFR-RSP-5)
- 작업 전후 `rust/scripts/prod-pids.sh` 출력이 같다 (V-RSP-5)
- 진행 기록에 공개 API 요약과 Go 와 다르게 한 내부 결정이 있다

  - **crate `dm-shared-edgerelay` 공개 API**
    - 상수 `NODE_SOCKET_FILE`·`DIAL_SOCKET_FILE`, `node_socket_path(home)`·`dial_socket_path(home)`
    - 서버 노드 포트: `Port::new(node_sock)`, `apply(enabled, bind, port)`(tokio 런타임 안), `status() -> dm_shared_edge::Status`, `close()`
    - 데몬 노드 소켓: `listen_node(path) -> io::Result<NodeListener>` — `NodeListener` 는 `dm_shared_edge::Acceptor` 다. 2.4.3 에서 `Listener::use_listen(Box::new(move |_, _| listen_node(&p).map(|n| Box::new(n) as Box<dyn Acceptor>)))` 로 붙인다. 놓으면 소켓을 닫는다
    - 발신 소켓: `serve_dial(path) -> io::Result<DialServer>`(Go ListenDial+ServeDial, 놓거나 `close()` 로 멈춤), `dialer(sock) -> dm_shared_edge::Dial`(`Client::via` 에 넘김)
  - **시험**: 단위 13개(Go relay_test 7개·e2e_test 3개 대응 + 와이어 줄·SplitHostPort·소켓 재사용). Go 상호 운용 4개(`tests/go_interop.rs`, `DM_PARITY_GO_RELAY_BIN` 게이트, Go 참조 프로그램 `testdata/goref` 가 `internal/shared/edgerelay` 를 직접 부름): Rust dialer→Go 발신 소켓, Go Dialer→Rust 발신 소켓, Rust 노드 포트→Go 노드 소켓(프리앰블 출발지 확인), Go 노드 포트→Rust 노드 소켓. 실행 방법은 파일 머리 주석.
  - **Go 와 다르게 한 결정**
    1. platform IPC 가 블로킹이라, IPC 연결은 스레드 둘이 tokio duplex 와 잇는 다리(bridge)로 감싼다(연결당 스레드 2). tokio 쪽이 끝나면 쓰기를 닫고 상대 끝을 DRAIN_TIMEOUT(20s)까지 기다린 뒤 닫는다 — Go splice 와 같은 규칙.
    2. 블로킹 accept 는 멈출 때 자기 소켓에 한 번 붙어 깨운다(Go 는 Listener.Close).
    3. Go `Dialer` 의 network 인자(tcp 아님 → errNotTCP)는 없다 — edge `Dial` 은 주소만 받고 늘 TCP 다. Go TestDialerRejectsNonTCP 는 옮기지 않았다. ctx 마감 대신 고정 시한(DIAL_TIMEOUT+5s)을 쓴다(edge Client 가 전체 시한을 따로 건다).
    4. 이름 해석 실패 문구는 `dial tcp: lookup <host>: no such host` 로 고정(Go 는 리졸버 문구).
  - **남은 위험**: 교차 대상 clippy 는 edge→rustls→ring 때문에 이 기계에서 못 함(8.3). OS 분기는 시험의 unix 죽은 소켓 만들기뿐. 연결당 스레드 2개라 연결이 아주 많으면 비용이 크다(간선은 최대 64).

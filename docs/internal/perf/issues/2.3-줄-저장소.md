# 2.3 줄 저장소 (FR-TRM-2, NFR-PRF-10)

## 목표

에뮬레이터 기록 상한을 넘은 줄을 줄 단위 압축 저장소로 옮긴다. 줄 = 글자 + 속성 구간 + OSC 8 링크 구간, 블록마다 deflate, 최근 블록은 풀린 채로. 줄 단위는 감싼 행을 합친 논리 줄이고 꺼낼 때 지금 폭으로 다시 감싼다(D-28). 줄마다 절대 줄 번호를 붙인다. 상한(기본 50,000줄)을 넘으면 오래된 블록부터 버리고, ED3 를 받으면 비우되 번호는 이어 간다. 넣기 전에 줄바꿈 수로 나눠 넣어 줄을 잃지 않는다. 구간 읽기 `lines(from, count)` 를 낸다.

저장소 자체는 2.2 없이 만들고, 에뮬레이터에서 옮기는 연결은 2.2 의 표면을 쓴다. 설계: `perf/M2_DESIGN.md` §2.3, `perf/EMULATOR_2026-11-24.md` §6. 결정: D-14, D-28.

## 완료 조건

- RED: 넣은 줄을 꺼내면 글자·속성·링크가 같다(왕복). 다른 폭으로 꺼내면 xterm 재흐름과 같다.
- RED: 64 KB 청크 하나로 수천 줄을 밀어도 줄을 잃지 않는다 — 에뮬레이터 기록 + 저장소 = xterm 기준 기록.
- RED: 상한을 넘으면 오래된 줄부터 사라지고 번호는 단조 증가한다. ED3 뒤 비고 번호가 이어진다.
- 측정 시험(`--ignored`): 터미널 12개 × 5만 줄 뒤 데몬 RSS 증가분이 터미널당 8 MB 이하.
- 바꾼 부분의 시험(단위·관련 e2e 한두 개)·fmt·clippy·관련 게이트 통과. 전체 시험은 마일스톤 끝에서 한 번만(2.10).
- 시험을 먼저 쓰고 RED 를 확인한 뒤 구현한다.
- 동작을 바꿨으면 이전 동작 / 새 동작 / 이유를 진행 기록과 커밋 메시지에 적는다.

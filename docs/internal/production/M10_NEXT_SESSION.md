## 6. 변하지 않는 규약

- **로컬 전량은 `make e2e`.** 이제 **동시 워커의 곱을 먼저 본다** — `E2E_JOBS ×
  E2E_WORKERS ≤ ⌈코어/3⌉` 이고 넘으면 **시작하지 않고 그 수를 말한다** (FR-M10-5).
  이 기계는 코어 10 → 상한 4 이고 기본이 `4 × 1` 이다. 벽시계 **13~17분**
- **판정은 `unexpected 0`** (D-M9-11). flaky 는 `report.json` 을 먼저 읽어라 —
  `make` 의 종료 코드 2 는 병렬 하네스가 flaky 를 실패로 올린 것이다
- **전량이 도는 동안 제품 소스를 건드리지 마라 — Go 도 포함이다.** 문서는 된다
- **`make e2e-rebalance` 는 전량 직후다**
- **`pgrep` 으로 폴링 루프를 만들지 마라** — 그 루프가 자기 패턴에 걸려 다음
  `make e2e` 가 `BUSY` 로 시작조차 못 한다. `run_in_background` 로 띄워라
- **RED 를 실제로 보아라.** 둘 중 하나다 — `git stash push <바꾼 파일>` → 실행 →
  **`stash pop`**(잊으면 커밋에서 조용히 빠진다), 또는 고침에 `if(1) return;
  // TEMP-PROBE` 를 심고 → 실행 → `git checkout` → **`grep -c TEMP-PROBE` 로 0 확인**.
  프로브 쪽이 **고침의 일부만** 무력화할 수 있어 어느 조각이 초록을 만드는지 가른다
- **검사가 무엇을 *재는지*도 대상이다.** 증상을 재는 검사는 그 증상을 없애는 아무
  경로에나 초록을 준다. **그리고 헤드리스가 못 만드는 증상은 아무 경로도 없는데
  초록을 준다** — 그때는 조항이 **명시한 수단**을 잰다 (D-M10-4). 다만 **수로는
  가를 수 없다** — 발화 횟수 대신 **고유한 궤적**을 봐라 (§2-5)
- **"없다" 를 인상으로 판정하지 마라.** `grep` 을 돌리되 `-av '_test'` 로 **검사를
  걸러 내지 마라** — 이번 세션이 그래서 있는 검사를 또 썼다 (§2-15)
- **출력을 자르지 마라.** `LC_ALL=C grep -a` 로 읽어라
- 동작을 바꾸면 근거 문서를 같은 변경에서 고친다 (이전/새/이유)
- **상태를 올릴 때 근거를 그 자리에 적는다** (D-M10-5). `check-srs-status` 는 enum 만
  보고 값의 참은 재지 않는다. **검증 갭이 있으면 갭으로 적어라** — 있다고 적으면
  그것이 다음 감사의 위양성이 된다
- 새 문구는 `t('ns.key')` — ko·en 둘 다 (`check-i18n.mjs`)
- 설정 키는 `SETTINGS_SCHEMA`·`SETTINGS_ACCESS` + `helpers.js` + `index.html` + ko·en
- 오류 코드는 `apierr/codes_core.go`·`codes_doc.go` → `go run ./scripts/gen-errors`
- 스펙에 D-… 를 더하면 `go run ./scripts/gen-decisions` · dmctl 을 바꾸면 `commands.md`
- e2e 의 고정 대기에는 **`TEST-16` 표식과 사유**가 필요하다
- **e2e 는 `app.testing.<이름>` 만 쓴다** (`check-e2e-private`)
- **`commands/` 에는 명령만 둔다** — 그 디렉터리의 `.md` 는 **전부** 슬래시 명령이
  된다. 참조 문서는 저장소로 (V-M10-11 이 지킨다)
- SRS 머리의 문서 상태는 **enum 안**이어야 한다
- z-index 는 층 토큰에서 온다 — 숫자 리터럴 금지
- 커밋 메시지에 AI 서명 금지
- dmctl 주의: **`new-tab` 은 `--at` 없이 포커스 칸에 연다** — 부르는 쪽의 칸이 아니다
- **운영 인스턴스는 사용자가 `start --foreground` 로 띄운다.** 재시작이 필요하면 직접
  죽이지 말고 사용자에게 요청하라

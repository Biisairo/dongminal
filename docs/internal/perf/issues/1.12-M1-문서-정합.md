- 코드 확인 중 발견한 문서 외 문제(고치지 않음):
  1. `hub::CommandHub::broadcast` 는 큐가 찬 구독을 닫고 "클라이언트가 재연결해 다시 받는다" 고 로그를 남기지만, 채널의 cmd 펌프(`channel/cmd.rs` `pump`)는 구독이 닫히면 조용히 끝나고 채널은 열린 채 남는다 — 그 탭은 이후 cmd 를 받지 못하고 재연결 계기도 없다. 확인 필요(MEDIUM).
  2. `GitWatcher::attach`·`detach` 는 제품 경로에서 불리지 않는다(SSE 제거 뒤). 그래서 `note_for(…, clientId)`·`note_scoped(…PINS_SCOPE)` 의 `clientId` 임차는 언제나 TTL 표명과 같다. 브라우저는 여전히 `clientId` 를 싣는다(`git/git-poll.js:259` 주석도 "SSE 구독이 임대를 쥔다" 로 낡음). 죽은 경로 정리 여부는 별도 결정.
  3. `attach_sse_leases(…, presence: bool)` 의 `presence` 인자는 늘 false 로 불린다(`channel/cmd.rs`). 이름·인자·주석이 SSE 시절 것이다.
  4. `otter-webserver-sse` 의 스트림 작성기(`start`·`Stream`)는 쓰는 곳이 없다(`payload` 만 쓰인다).

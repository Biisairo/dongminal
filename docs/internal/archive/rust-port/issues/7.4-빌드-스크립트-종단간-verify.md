### Go 와 다르게 한 결정
- 출력 자리: Go 는 저장소 루트 `./dongminal` 에 쓴다. Rust 판은 `rust/dist/` 에 쓴다. 운영 checkout 에서 돌렸을 때 돌고 있는 Go 바이너리를 덮지 않게 하려는 것이다.
- 지문 정의역이 Go 보다 넓다(crate 안의 시험 파일도 센다). 대상마다 값이 같다 — Rust 는 OS 별 코드를 crate 안 `cfg` 로 나누므로 대상별 파일 목록이 같다.
- **Go 판 결함(보고만, C-RSP-2)**: Go `scripts/daemon-fingerprint.sh` 의 `xargs sum` 은 셸 함수 `sum`(shasum)을 부르지 못하고 `/usr/bin/sum`(16비트 BSD 체크섬)을 부른다. Go 지문의 파일별 값은 sha256 이 아니다. Rust 판은 배열로 고쳐 sha256 을 쓴다.

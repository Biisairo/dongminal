# 1.18 SSE 제거 뒤 죽은 경로 정리

## 목표

1.12 에서 발견. 사용자 결정(2026-11-24): 정리한다.

- `GitWatcher::attach`·`detach` 를 부르는 제품 코드가 없다. `clientId` 로 잡는 임대가 늘 시간 만료 임대와 같다. 브라우저는 여전히 `clientId` 를 보낸다 — 임대 의미를 바꾸지 않는 선에서 쓰이지 않는 경로를 지운다(브라우저가 보내는 값도 쓸모가 없으면 함께).
- `attach_sse_leases` 의 `presence` 인자는 늘 false.
- `otter-webserver-sse` 의 스트림 작성기를 쓰는 곳이 없다(crate 째 지울 수 있는지 확인).
- 지우기 전에 LSP/Serena 로 참조 0 을 확인한다. 동작이 바뀌면 이전/새/이유.

## 완료 조건

- 바꾼 crate 의 lib 시험·fmt·clippy, 관련 node 시험·게이트, cargo deny/workspace 빌드 확인(crate 를 지우면). 전체 시험 금지.

- 동작 변경
  - 이전: 브라우저가 git status·repos 요청에 `clientId` 를, Repo 탭을 떠나면 `observe=0` 을 실었다. 서버는 그 신원으로 임대를 잡으려 했지만 신원을 결선하는 `GitWatcher::attach` 를 부르는 제품 코드가 없어 늘 TTL 표명과 같았다.
  - 새: 요청은 `clientId`·`observe=0` 을 싣지 않는다. 서버는 TTL 표명(`note`)과 토픽 임대만 안다. 옛 브라우저가 보내는 값은 무시된다.
  - 이유: 죽은 경로(D-11·FR-CON-10). 임대 의미(토픽 구독 동안 유지, 놓으면 그때부터 TTL)는 그대로다.

# 1.2 잎 패키지 묶음

## 목표

내부 의존이 없는 작은 패키지들을 옮긴다. mimeprobe 는 Go `net/http.DetectContentType` 의 판정 알고리즘을 그대로 구현한다. textenc 는 encoding_rs 를 쓴다. sysstat 은 OS 별 시스템 통계라 platform 을 쓰지 않고 직접 OS 를 호출하므로, unsafe 가 필요하면 조정자에게 알린다(C-RSP-4 예외 승인 필요).

### 옮긴 테스트

Go 테스트 중 관측 동작을 검증하는 것은 모두 같은 입력·기대값으로 옮겼다. Rust 테스트는 모두 135개다. apipath 의 서버 라우트 대조 시험은 Rust 서버가 아직 없으므로 Go 기준선 서버 소스(`internal/webserver/{httpapi,gitapi}`)를 대조한다. outbuf 의 링 대조 시험은 Go 와 같은 구조로 옮기고, 난수만 splitmix64 로 바꿨다. mimeprobe 는 Go `net/http/sniff_test.go` 의 표를 옮겼다. 할당 횟수를 세는 Go 시험(`AllocsPerRun`)은 용량과 버퍼 주소가 그대로인지 보는 시험으로 바꿨다.

### Go 기준선과 대조한 결과 (go1.27.2)

- textenc·mimeprobe·termtext·uuid 오류 문구: 1~2바이트 입력 전부, 무작위 입력 2만 개, 모든 코드 포인트의 인코딩을 Go 와 대조했다. 차이는 0건이다(353만 줄 + 116만 줄).
- termtext 의 Cf 표: Rust 표준 라이브러리에 없으므로 go1.27.2 의 `unicode.Cf`(Unicode 17.0.0)를 그대로 옮겼다.
- decidx: `docs/internal` 전체(결정 1385건)로 만든 색인이 저장소의 `decisions.md` 와 바이트 단위로 같다. 이것을 시험으로 걸어 두었다.
- sysstat: 이 기계에서 Go 와 Rust 의 총메모리·부팅시각·디스크 사용률·statfs 오류 문구가 같다.

### Go 와 다르게 한 내부 결정

1. **pollwait·fanout 은 tokio async 다.** Go 의 `context.Context` 는 `tokio_util::sync::CancellationToken` 으로 옮겼다. `Signal` 은 `tokio::sync::watch` 위에 만들었다. `notify` 는 런타임 밖에서도 부를 수 있다. 대기 함수는 tokio 런타임 안에서 불러야 한다. Go `Background()` 로 부르던 CLI 쪽은 취소하지 않는 토큰(`CancellationToken::new()`)을 넘긴다. `on_or_at` 의 시각은 `std::time::Instant` 다(Go 는 벽시계 `time.Time`).
2. **fanout 의 future 는 호출한 task 안에서 함께 돈다**(FuturesUnordered). goroutine 처럼 스레드를 나누지 않는다. 동시 개수 상한, 취소 뒤 시작하지 않기, 반환 전에 모두 끝내기는 Go 와 같다. CPU 를 오래 쓰는 일은 호출자가 `spawn_blocking` 으로 넘긴다.
3. **textenc**: x/text 대신 encoding_rs 를 쓴다. 두 인코더가 다른 자리는 기준선과 전수 대조해 예외 표로 덮어썼다. Shift_JIS 377자(NEC 선정 IBM 확장 글자는 ED/EE 행으로 인코딩한다. ¥·‾·−·U+0080 은 거절한다)와 windows-1252 미정의 5자다. UTF-16 인코더는 직접 썼다. `Unmappable` 의 글자 필드 이름은 `ch` 다. JSON 으로 낼 때는 `char` 키로 내야 한다.
4. **diagtail** 은 바이트판을 기본으로 둔다. Go 문자열은 잘못된 UTF-8 을 담을 수 있고, 자르지 않은 진단은 그 바이트 그대로 나가기 때문이다.
5. **sysstat**: macOS 릴리즈 빌드는 cgo 가 켜져 있다(운영 바이너리도 `CGO_ENABLED=1`). 그래서 Rust 판은 macOS 에서 언제나 mach 경로를 쓰고, cgo 를 끈 빌드의 `Unsupported` 경로는 두지 않는다. `mach_host_self`(libc 에서 deprecated)와 `host_page_size`(libc 에 없다)는 os 모듈 안에서 extern 으로 직접 선언했다. Sampler 는 goroutine 대신 std 스레드 하나로 돈다. `Stopper` 를 떨어뜨리거나 `stop()` 하면 멈춘다. 부팅 시각은 `Option<SystemTime>` 이다(`boot_valid()` 가 있다). 메모리 부분 성공은 `MemError{total, error}` 로 나타낸다.
6. **decidx**: Go RE2 의 `\s` 는 ASCII 공백이므로 `[\t\n\f\r ]` 로 풀어 썼다. 정렬은 안정 정렬이다(Go `sort.Slice` 는 안정 정렬이 아니지만, 출처+ID 가 같은 항목이 없으므로 결과는 같다).
7. **uuid**: 난수원은 `rand::rngs::SysRng`(운영체제 난수)다. 해석 오류 문구는 Go `encoding/hex` 의 `%#U` 형식까지 맞췄다.

### 남은 위험

- decidx 의 `collect` 는 파일 읽기 오류를 `std::io::Error` 로 돌려준다. 문구가 Go(`open <경로>: <errno>`)와 다르다. 이 문구는 8.4 의 `gen-decisions` 가 stderr 로 찍을 때만 보인다. 그때 dm-gocompat 의 Go 오류 문구 규칙으로 맞추어야 한다.
- sysstat 의 Os 오류 문구는 Go 와 비슷하게 맞추었지만 전부 같지는 않다. 다만 Sampler 가 오류를 버리므로 밖으로 드러나지 않는다.
- textenc 의 차이 대조는 go1.27.2 의 x/text 판을 기준으로 했다. go.mod 의 x/text 판이 바뀌면 다시 대조해야 한다.
- toolaccess 는 trait 만 정의한다. 실제 구현의 동작은 5.2(adapters)에서 검증한다.
- 2026-11-23 조정자: rust-port 에 병합(e297d26d). fmt·clippy·격리 테스트 135개 통과. prod-pids 동일. pollwait·fanout 의 tokio async 결정을 SRS FR-RSP-36 으로 올렸다.

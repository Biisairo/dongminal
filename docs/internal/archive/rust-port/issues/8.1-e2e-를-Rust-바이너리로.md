### 결과 요약

- **실행 방법** (모두 hermetic, `E2E_PORT_BASE=61000`, `DM_E2E_KEEP_PEERS=1`, 워커 2):
  `PLAYWRIGHT_BROWSERS_PATH=~/Library/Caches/ms-playwright rust/scripts/hermetic.sh env DM_E2E_PREBUILT_BIN=<bin> E2E_PORT_BASE=61000 DM_E2E_KEEP_PEERS=1 npx playwright test`.
  hermetic 이 HOME 을 바꾸므로 브라우저 경로를 실제 캐시로 넘긴다. Rust 바이너리는 `rust/scripts/hermetic.sh rust/scripts/build.sh`(rp/7@088cf2ba 의 7.4 스크립트를 병합)로 만들었다. Go 기준선은 같은 worktree 에서 `go build ./cmd/dongminal`(127ff7d9 와 Go 코드 차이 없음).
- **결과 (darwin, 2317 항목)**

  | 바이너리 | 통과 | 실패 | flaky | 건너뜀 |

- **고친 결함** (Go `r.Context().Done()` 에 해당하는 끊김 감지가 없었다. 구독이 닫혀도 다음 인사(15초) flush 가 실패할 때까지 포커스 소유권·git·fs 임대를 쥐고 있었다)
  - `ae10bf2b port(1.3)`: `dm-webserver-sse` 에 `Stream::closed()` 추가. 본문 수신자가 버려지면 끝나는 `'static` future 다(Sender 복제의 `closed()`). 테스트 1 추가.
  - `4688c7f7 port(5.5.2)`: `httpapi` commands SSE pump 가 full·presence 구독 모두 `closed()` 를 select 해 곧바로 끝나고 임대를 푼다. Go `TestFocus_SubscriptionCloseReleasesOwnership` 대응 테스트 1 추가(수정 전 RED 확인).
  - 게이트: `cargo fmt --all --check`, `cargo clippy -p dm-webserver-sse -p dm-webserver-httpapi --all-targets -D warnings`, hermetic `cargo test` (httpapi 649, sse 9) 통과. 교차 clippy 는 httpapi 가 ring 을 끌어와 건너뛰었다(8.3). sse 는 OS 의존 코드가 없다.
  - 수정 후 `focus-owner.spec.ts`·`window-slots.spec.ts` 57/57 통과, 전량 재실행에서도 두 항목 통과.
- **남은 위험**
  - `dm_webserver_sse::start` 를 쓰는 다른 곳(gitapi `remote.rs` 의 진행 스트림)은 끊김 감지를 살펴보지 않았다. e2e 에는 드러나지 않았다. Go 쪽 동작과 대조가 필요하면 그 이슈(gitapi)에서 본다.
  - darwin 만 돌렸다. linux·windows e2e 는 8.3 의 교차 빌드 뒤에 가능하다.
  - 7.4 스크립트를 병합(ce13c0ed)해 썼다. rust-port 로 병합할 때 rp/7 과 같은 커밋이라 충돌은 없어야 한다.

# 12 e2e 가치 낮은 시험 정리

## 목표 (사용자 지시 2026-11-24)

11.10 의 e2e 전량 1회 전에, 가치가 낮은 e2e 시험을 골라 지운다. 대상: 쓸데없는 시험, 시간만 많이 먹고 의미가 없는 시험, e2e 의 뜻(브라우저로 실제 사용자 흐름을 검증)이 아닌 시험(단위·정적 검사로 충분한 것, 구현 세부·문구 스냅샷만 보는 것), 다른 시험과 겹치는 시험.

## 절차

1. 12.0 분석(코드 수정 없음): spec 251개·test 약 2,323개를 훑어 시험마다 가치·비용을 매기고 지울 후보를 사유와 함께 보고서로 낸다.
2. 조정자가 보고서를 사용자에게 요약해 확인을 받는다.
3. 확인된 것만 지운다. 지운 시험이 지키던 요구(SRS V-* 연결)가 다른 시험이나 단위 시험으로 덮이는지 확인한다.

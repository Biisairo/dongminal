# 3.3 찾기 일치 계산을 16 ms 아래로 (FR-SPA-5, OQ-2)

## 목표

- `edFindHits`(js/ui/cm-find.js) 가 2만 3천 줄 파일에서 글자마다 50~60 ms 를 쓴다(`perf/SPA_PROFILE_2026-11-24.md` §2·§3).
- 먼저 입력 지연(디바운스)과 보이는 구간 먼저·나머지는 나눠 계산을 넣는다. 그래도 한 작업이 16 ms 를 넘으면 Worker(문서 사본 유지, 변경분만 전달)로 옮긴다 — Worker 로 갈 때는 조정자에게 먼저 알린다.

## 완료 조건

- 시험: 2만 줄 파일에서 찾기 입력 글자마다 메인 스레드 작업 16 ms 이하(측정 방법을 진행 기록에 적는다), 일치 수·현재 일치 이동 등 기존 찾기 동작 유지. 관련 단위·e2e 한두 개. 전체 시험 금지.

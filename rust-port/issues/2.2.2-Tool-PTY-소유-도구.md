# 2.2.2 Tool(PTY 소유 도구)

## 목표

PTY 하나를 소유하는 도구 한 개의 수명을 옮긴다. StartTool·readPTY(출력 → outbuf, 모드·주의·cwd 관측), 주의·활동 상태 기계, Freeze/Thaw, 종료·크기 변경·쓰기, cwd, 기록. 블로킹 PTY 읽기는 전용 스레드나 spawn_blocking 에서 돈다 (FR-RSP-33·36).

## 대상 Go 코드

- `internal/shared/toolhub` 의 tool.go, tool_attention.go, tool_control.go, tool_cwd.go, tool_records.go, freeze.go(Tool 부분), termmodes.go(Tool 부분) (약 1500줄)

## 완료 조건

- 대상 Go 코드의 관측 동작을 Rust 가 동등하게 제공한다 (FR-RSP-1·3)
- 관측 동작을 검증하는 Go 테스트가 Rust 테스트로 옮겨져 통과한다 (V-RSP-1)
- `cargo fmt --check`, `cargo clippy -D warnings`, 격리 실행 `cargo test` 통과 (NFR-RSP-4)
- OS 의존 코드가 있으면 windows·linux 대상 `cargo check` 통과 (NFR-RSP-5)
- 작업 전후 `rust/scripts/prod-pids.sh` 출력이 같다 (V-RSP-5)

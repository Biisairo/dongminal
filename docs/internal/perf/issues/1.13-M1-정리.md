# 1.13 M1 정리

## 목표

M1 중에 생긴 겹침과 빈 껍데기를 없앤다(D-11 — 같은 일을 하는 구현을 두 벌 두지 않는다).

1. e2e 에서 토픽에 가짜 값을 넣는 헬퍼가 셋이다: `stubTopic`(1.10.2), `refetchClaudeAccounts`(C2b), `refetchChat`(1.10.1). `stubTopic` 하나로 합치고 나머지를 쓰는 스펙을 옮긴다. `refetchClaudeAccounts` 의 `seq > 0` 기다림(첫 full 이 seq 0 이면 끝나지 않을 수 있음)도 함께 없어진다. `stubEmptyLimits` 처럼 `page.route` 로 지금은 토픽으로 오는 GET 을 비우는 헬퍼가 남아 있으면 같은 방식으로 옮긴다.
2. `stopConsolePoll` 헬퍼는 이제 아무 일도 하지 않는다 — 지우고 쓰는 곳을 정리한다.
3. 설정 `gitStatusInterval`·`gitReposInterval` 이 C4 이후 아직 무엇을 정하는지 확인한다. 아무것도 정하지 않으면 지우지 말고 진행 기록에 근거를 적어 조정자에게 알린다(삭제는 사용자 결정).

## 완료 조건

- 바꾼 스펙만 돌려 통과, `tsc -p e2e`, 관련 node 시험, 관련 게이트. 전체 시험 금지.

- 3. 설정 확인(지우지 않음, 사용자 결정 대상):

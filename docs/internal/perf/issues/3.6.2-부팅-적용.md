# 3.6.2 프레임 스케줄러 적용 — 부팅 (D-40)

## 목표

- `_afterLayout`(`renderer-layout.js`)의 `open`·`doFit` 은 `normal`, `syncGpu(true)` 는 칸마다 `idle`(키 `gpu:<id>`) — 첫 페인트는 DOM 렌더러, WebGL 은 뒤 프레임.
- `tabsFit` 을 ResizeObserver·패널에서 곧바로 재지 않고 `frame(…, {key:'tabsFit:'+id})` 로 합친다.
- 렌더러 파일 병합 순서: 3.5.1 → 3.4.3 → **3.6.2**.

## 완료 조건

- RED 단위: 탭 줄 하나에 ResizeObserver 콜백이 한 프레임에 다섯 번 와도 `tabsFit` 은 한 번. 보이는 터미널 셋이면 GPU 붙이기가 서로 다른 프레임에서 돈다.
- e2e: WebGL 로 바뀐 뒤 화면 비교로 깜빡임 없음 확인(깜빡이면 멈추고 보고). 측정: 3.4.1 의 부팅 16 ms 초과 작업 수가 줄었음(착수 때 기준선을 다시 재고 목표를 진행 기록에 적는다). 전체 시험 금지.
- 동작을 바꿨으면 이전 동작 / 새 동작 / 이유를 진행 기록과 커밋 메시지에 적는다.

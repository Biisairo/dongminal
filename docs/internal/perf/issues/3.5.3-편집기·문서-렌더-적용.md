**동작 변경**

- 이전: 다른 탭 뒤에 가려진 편집기도 찾기를 끝까지 셌고 진단·변경 표시를 그렸다. 그 문서는 바깥 변경을 감시해 곧바로 다시 읽었고, git 신호마다 변경 표시 기준을 다시 받았다. 가려진 렌더 탭은 편집마다 타이머를 걸었다.
- 새: 가려지고 2초 뒤 잠들면 놓는다. 다시 보이면 남은 찾기를 끝내고 밀린 것을 한 번 그리며, stamp 를 물어 바깥 변경을 받는다. 같은 파일을 깬 칸이나 git Diff 뷰가 보고 있으면 문서는 계속 관측한다. dirty 문서는 지금처럼 다시 읽지 않고 저장할 때 경합 확인창이 뜬다.
- 이유: FR-SPA-3·D-36.

**남은 위험**

- LOW: 깰 때의 stamp 묻기는 다른 묻기가 진행 중이면(`_edStampsBusy`) 건너뛴다. 그때 바깥 변경은 다음 계기(`_edTick`·`fs_changed`)까지 늦다.

# 2.2.3 ToolManager·tools.json·허브

## 목표

도구 집합을 다루는 ToolManager 를 옮긴다. 생성(상한·배치)·복원·삭제, tools.json 저장·적재(형식은 Go 와 바이트 단위로 같다), 허브 표면(Write·Resize·Snapshot·Background), 주의·활동·크기 알림과 sweeper, 전경 이름 갱신, handover(Export/Adopt), FreezeAll/seal, 붙여넣기, 브라우저 WebSocket 쓰기 창구 SafeConn.

## 대상 Go 코드

- `internal/shared/toolhub` 의 manager*.go, persist.go, handover.go, freeze.go(Manager 부분), foreground.go, bracketpaste.go, conn.go(SafeConn), hub.go(인터페이스) (약 1800줄)

## 완료 조건

- 대상 Go 코드의 관측 동작을 Rust 가 동등하게 제공한다 (FR-RSP-1·3)
- 관측 동작을 검증하는 Go 테스트가 Rust 테스트로 옮겨져 통과한다 (V-RSP-1)
- `cargo fmt --check`, `cargo clippy -D warnings`, 격리 실행 `cargo test` 통과 (NFR-RSP-4)
- OS 의존 코드가 있으면 windows·linux 대상 `cargo check` 통과 (NFR-RSP-5)
- 작업 전후 `rust/scripts/prod-pids.sh` 출력이 같다 (V-RSP-5)
- 진행 기록에 공개 API 요약과 Go 와 다르게 한 내부 결정이 있다

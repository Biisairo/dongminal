# 3.6.3 프레임 스케줄러 적용 — 파일 열기

## 목표

- `edOpenFile` 67~74 ms(`tabsFit`·`apiSend`·`_placeLayout`, 3.7 기록)를 트레이스로 나눠 잰 뒤, 레이아웃 읽기를 같은 프레임의 쓰기 뒤로 모으고 비필수 일을 `idle` 로 미룬다.

## 완료 조건

- RED: 3.7 의 측정 스크립트(2만 3천 줄 파일)로 `edOpenFile` 작업이 16 ms 초과 목록에서 빠지거나 줄었음을 이전/새 바이너리로 번갈아 잰다. 단위: 바꾼 자리의 합치기·순서.
- 관련 편집기 e2e 한두 개. 전체 시험 금지.
- 동작을 바꿨으면 이전 동작 / 새 동작 / 이유를 진행 기록과 커밋 메시지에 적는다.

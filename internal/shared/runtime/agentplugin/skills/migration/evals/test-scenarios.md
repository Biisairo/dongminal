# migration 스킬 테스트 시나리오

사용자가 직접 돌려보고 실제 동작 여부를 검증하기 위한 프롬프트 모음. 각 시나리오는 **넘기는 쪽 세션이 돌고 있는 도구에서 사용자가 치는 메시지**다.

대전제:
- dongminal 서버 실행 중, 브라우저 열림, SSE 연결됨
- 넘기는 세션은 **한 도구** 에서 돈다. 받는 탭은 스킬이 **그 pane 에** 새로 만든다
- 검증의 1차 근거는 **`dmctl list-workspace` 와 `dmctl status --at <uuid>`** 다. 화면은 "왜 막혔는가" 를 볼 때만 읽는다

---

## 시나리오 1 — 규약이 있는 작업의 인계 (문서 있음)

진행 중인 작업에 이미 인계 문서의 자리가 정해져 있는 경우. 이 스킬의 기본 경로다.

### 프롬프트
> 이 단계 끝났다. 다음 단계는 새 세션이 맡게 인수인계해줘.

### 검증 포인트

- [ ] **기존 문서를 다시 쓴다.** 새 파일을 만들지 않는다 — 작업의 규약이 정한 그 파일이 다음 세션의 착수 문서가 된다
- [ ] 문서에 **남은 일의 순서**와 **먼저 읽을 것**이 경로·절 번호까지 들어 있다
- [ ] 문서에 이 세션이 **값을 치르고 배운 것**이 들어 있다 (다음 세션이 같은 조사를 되풀지 않는다)
- [ ] `dmctl new-tab -n` 이 `--at` **없이** 불린다 — 새 창을 만들지 않는다
- [ ] 응답의 `newTabs[0]` 를 그대로 쓴다 (`list-workspace` 재조회 없음)
- [ ] `dmctl rename-tab` 으로 탭 이름이 **이어갈 일**을 말한다
- [ ] `dmctl wait --for ready` **뒤에** `dmctl msg` 가 불린다 (순서가 뒤집히지 않는다)
- [ ] 엔벨로프가 **짧다** — 문서 경로·직전 커밋 해시·시작 지점. 맥락 본문이 엔벨로프에 들어가지 않는다
- [ ] `dmctl msg --to` 에 **toolId** 가 들어간다 (`W?.P?.T?` 라벨이 아니다)
- [ ] `dmctl status --at <새 탭>` 이 `working` 을 준다
- [ ] 마지막 명령이 `dmctl close-tab --at <자기 uuid> --force` 다
- [ ] **사용자의 다른 창·탭이 바뀌지 않는다** — 전후로 `dmctl list-workspace` 를 비교해 새 탭 하나 외 차이 0

---

## 시나리오 2 — 규약이 없는 작업의 인계 (문서 없음)

인계 문서의 자리가 정해지지 않은 작업. 스킬이 한 장을 만들어야 한다.

### 프롬프트
> 지금 하던 리팩터링, 컨텍스트 차서 더 못 간다. 새 탭 열어서 이어가게 해줘.

### 검증 포인트

- [ ] **묻지 않고 만든다** — 규약이 없으면 스킬이 한 장을 만드는 것이 규칙이다
- [ ] 새 문서가 **저장소 안**에 서고, 이름이 이어갈 일을 말한다
- [ ] 문서에 여섯이 들어 있다: 어디까지 왔나 · 남은 일과 순서 · 먼저 읽을 것 · 배운 것 · 변하지 않는 규약 · 유효한 사용자 결정
- [ ] 커밋되지 않은 변경이 있으면 **그 사실이 문서에 적힌다** (다음 세션이 깨끗한 트리를 전제하지 않는다)
- [ ] 나머지는 시나리오 1 과 같다

---

## 시나리오 3 — 새 탭이 준비되지 않는다 (`wait` 실패)

받는 쪽이 권한 확인을 묻거나 기동이 늦은 경우. **이 스킬이 조용히 실패하지 않는지**를 보는 시나리오다.

### 준비

받는 탭이 처음 기동될 때 확인을 묻도록 만든다 (신뢰 확인이 아직 없는 디렉터리에서 인계).

### 프롬프트
> 인수인계해줘.

### 검증 포인트

- [ ] `dmctl wait` 가 `rc=5` 로 돌아오면 **엔벨로프를 보내지 않는다**
- [ ] `dmctl read-screen --at <새 탭>` 으로 **무엇을 묻는지 읽는다**
- [ ] 답을 넣은 뒤 `dmctl wait` 를 **다시** 건다 — 화면 모양으로 준비완료를 판정하지 않는다
- [ ] 끝내 준비되지 않으면 **자기 탭을 닫지 않는다.** 사용자에게 무엇이 막혔는지 보고하고 멈춘다
- [ ] 준비되지 않은 탭에 `dmctl msg` 를 보낸 흔적이 없다 (보냈다면 셸 입력줄에 문자열로 남아 있다)

# 2.5 깨움·잠듦 — 구독/해지, 버퍼 비우기, 스냅숏 적용 (FR-TRM-3·4)

## 목표

서버: `term.open` 에 깨움 표시가 있거나 `since` 가 없으면 바이트 재생 대신 스냅숏을 `OUTPUT` + `SEQ(SNAP)` 로 보낸다(D-19). 같은 `end` 의 스냅숏은 여럿이 깨워도 한 번만 만든다. 화면 상태 기능이 없는 데몬이면 지금 경로(D-27).
브라우저: 터미널은 처음 보일 때 붙는다. `vis` 를 잃고 2초 뒤 `term.close` 하고 버퍼를 비운다(D-15·D-16). 다시 보이면 `term.open{snap}` 으로 스냅숏을 그리고, `SNAP` 이면 넛지를 걸지 않는다. 깬 터미널 스크롤백은 5,000줄. cwd 는 스냅숏 머리에서 받는다. 숨은 터미널 버퍼를 읽던 e2e 를 고친다.

설계: `perf/M2_DESIGN.md` §2.5.

## 완료 조건

- RED(서버): 깨움 `term.open` 의 프레임 순서 `TOOLID` → `SIZE` → 좌석 → 스냅숏 `OUTPUT` → `SEQ(SNAP)` → 실시간. `SEQ` 오프셋 뒤 출력에 빠짐·겹침 없음.
- RED(프론트): 숨긴 터미널은 2초 뒤 `term.close` 하고 그 sid 의 프레임을 받지 않는다. 깨면 `term.open{snap}`. `SNAP` 에는 넛지가 없다. 한 번도 안 보인 터미널은 연결하지 않는다.
- RED(e2e): 출력이 흐르는 터미널을 숨겼다 깨우면 화면이 숨기지 않은 것과 같다(TUI·줄 출력). 잠든 터미널로 가는 바이트 0(NFR-PRF-6).
- 깨워 그려질 때까지 p95 100 ms 이하(NFR-PRF-14, 로컬)를 잰다.
- 바꾼 부분의 시험(단위·관련 e2e 한두 개)·fmt·clippy·관련 게이트 통과. 전체 시험은 마일스톤 끝에서 한 번만(2.10).
- 시험을 먼저 쓰고 RED 를 확인한 뒤 구현한다.
- 동작을 바꿨으면 이전 동작 / 새 동작 / 이유를 진행 기록과 커밋 메시지에 적는다.

**남은 위험 / 다음 이슈가 알아야 할 것**

# 3.5.4 브라우저 탭 숨김 규칙 (D-36)

## 목표

- 브라우저 탭이 숨으면(창 최소화·완전히 가림 포함) 터미널 밖 화면은 2초 뒤, 터미널은 30초 뒤 잔다. 30초는 상수다(설정으로 내지 않는다).
- 터미널의 잠듦·깨움 자체(`term.close`·`term.open{snap}`)는 2.5 의 것을 쓴다.

## 완료 조건

- RED 단위(가짜 시계): 숨김 1.9초 → 화면 깸, 2초 → 화면 잠, 터미널 29초 깸 → 30초 잠. 그 사이 다시 보이면 취소.
- e2e: 새 탭을 앞으로 띄워 실제로 숨긴 뒤 위 규칙대로 잠들고, 돌아오면 화면이 서버와 같다. 전체 시험 금지.
- 동작을 바꿨으면 이전 동작 / 새 동작 / 이유를 진행 기록과 커밋 메시지에 적는다.

# 1.21 게이트 실패·낡은 시험 정리

## 목표

마일스톤 끝 전체 시험 전에, 통합 브랜치(perf-m1)에 남은 실패를 걷는다. 각각 원인을 확인하고, 시험이 낡았으면 지금 동작을 재도록 고치거나(성질이 없어졌으면 근거와 함께 지운다), 코드가 규칙을 어기면 코드를 고친다. 예외 목록에 넣어 넘기지 않는다.

1. e2e `git-polling.spec.ts` GWL1 "status 요청이 SSE 와 같은 clientId 를 싣는다" — 1.18 이 git status·repos 요청의 clientId 를 지웠다(성질이 없어짐).
2. `check-file-size`: `web/js/ui/runs-panel.js` 508줄(3.5.2 로 506→508), `web/js/core/timer-hub.js` 501줄(3.6.1).
3. `check-e2e-private.sh`: 다른 스펙 6곳의 `app._x` 위반(activity-runs-refresh·git-repaint·perf-statusbar·run-view-live 등, 1.16 때부터).
4. `check-i18n`: 쓰이지 않는 키 `core.off`.
5. 그 밖에 `scripts/check-*` 를 모두 돌려 실패하는 것이 있으면 목록에 더하고 같은 방식으로 처리.

## 완료 조건

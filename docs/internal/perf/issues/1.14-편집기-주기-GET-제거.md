# 1.14 편집기·탐색기의 3초 주기 GET 을 토픽으로

## 목표

탐색기(편집기)가 보이는 동안 `editor-pane.js:29` 의 `visiblePoll(gitReposInterval)` 이 `_edTick` 을 돌려 열어 둔 파일의 stamp 조회(`edStampTick`)와 감시 집합 안전망(`edWatchSync`)을 한다. D-9(상태용 주기 GET 전부 제거, 사용자 결정 2026-11-24 재확인)에 따라 이것을 없앤다.

- 서버의 파일 감시(`fs_watch`, `fs` 사건 토픽)가 열린 파일·감시 디렉터리의 변경을 민다. 브라우저는 그 사건으로 stamp 를 다시 본다(사건에 1:1 인 요청은 폴링이 아니다).
- 감시 집합(어떤 디렉터리를 볼지)은 탐색기 상태가 바뀔 때 보내고, 안전망 주기는 두지 않는다. 채널이 다시 붙으면(`chan:open`) 한 번 맞춘다.
- `gitReposInterval` 설정이 이 틱만 정하고 있었다면, 이 일이 끝난 뒤 그 설정이 아직 무엇을 정하는지 확인해 진행 기록에 적는다(삭제는 사용자 결정).
- 남는 서버 내부 주기가 있으면 이유와 주기를 `CHANNEL_PROTOCOL.md` 에 적는다(FR-SRV-2).

## 완료 조건

- 시험 먼저(RED 확인). 바꾼 crate 단위 시험, 관련 node 시험, 편집기 stamp·외부 변경 반영 e2e 한두 개, fmt·clippy·관련 게이트. 전체 시험 금지.

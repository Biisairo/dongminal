# 3.7 큰 파일 열기

## 목표

2만 3천 줄 JS 를 편집기로 열 때 CodeMirror 언어 파서 79 ms, 미니맵 `edMinimapScale`+canvas `fillText` 38 ms, 첫 트랜잭션 21 ms 작업이 생긴다(`perf/SPA_PROFILE_2026-11-24.md` §2·§3). 언어 파서의 시간 나눔(작업 예산) 설정을 확인·적용하고, 큰 파일에서 미니맵 그리기를 나누거나 늦춘다.

## 완료 조건

- 큰 파일 열기의 16 ms 초과 작업 감소 측정(이전/새), 편집·미니맵 동작 유지 시험 한두 개. 3.3 과 같은 편집기 영역이므로 cm-find.js 는 건드리지 않는다. 전체 시험 금지.

### Go 와 다르게 한 내부 결정
- grep 의 Go 폴백은 줄 단위 `bufio` 대신 파일(≤2MiB)을 한 번에 읽고 `\n` 으로 나눈다. 조각 규칙(마지막 빈 조각·col 은 `\r` 떼기 전)·이진 판정(앞 8000바이트)·읽기 실패 시 그때까지의 내용은 같다.
- 순회는 Go `filepath.WalkDir` 처럼 이름 바이트 순·심링크 미추적·`FS_SKIP_DIRS` 절단이다. 읽기 실패한 디렉터리는 통째로 건너뛴다(Go 는 부분 목록이 있으면 그것을 걷는다 — 권한 오류 한가운데서만 갈린다).
- zip 은 `spawn_blocking` 에서 쓰고 32KiB 조각을 채널로 본문에 흘린다. 동시 자리는 쓰기가 끝날 때 놓인다(Go `defer` 와 같다). 받는 쪽이 끊기면 쓰기를 멈춘다(Go 는 실패하는 쓰기를 끝까지 시도한다 — 관측 없음).
- `strings.ToLower` 는 글자마다 첫 소문자 하나 + 잘못된 바이트는 U+FFFD 로 흉내 낸다(5.5.6 과 같은 방식).
- `exec.LookPath("rg")` 는 PATH 를 직접 훑는다(상대 경로에서 찾은 것은 Go `ErrDot` 처럼 버린다).
